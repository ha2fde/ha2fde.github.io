## 一、组织逻辑：为什么是这条线

不按时间讲，不按技术清单讲。全章只有一条主线：

> **八十年里只发生了一件事：人把「供给知识」这份活儿，一段一段交给了机器。**

拆成**四次移交**，每一次都由同一个瓶颈逼出来 —— **人的产能**：

| 移交 | 人不再供给 | 人改为供给 | 落地成什么 |
|---|---|---|---|
| 一 | 规则：一条条 if-then | 例子：输入 + 期望输出 | 机器学习 |
| 二 | 特征：该看哪几个量 | 网络结构 | 深度学习（2012 后） |
| 三 | 连接：哪个位置该看哪个位置 | 一层几乎不预设结构的通用算子 | Transformer（2017） |
| 四 | 任务与标注 | 数据配比 + 算力 + 一个自监督目标 | 预训练大模型（2018 后） |

这张表在第 2 页立起来，后面**四幕各兑现一行**，第 26 页横竖两个方向结清。
每一幕都问同样三个问题：**上一格具体卡在哪 / 交出去的是什么 / 换走的是什么。**

### 第二条暗线（贯穿全章，第 27 页收口）

**归纳偏置从来没有消失，它一直在搬家：**
规则里 → 人挑的特征和模型里 → 网络结构里 → 数据配比里。
能力单调上升，可见度单调下降。这条线解释了今天两件最常被讨论的事 ——
为什么模型难解释，为什么数据成了核心壁垒。

### 为什么这么组织（吸取了 ch2-versions 里的三次翻车）

- v0 输在**编年史**：知道发生过什么，不知道为什么非得是这样 → 所以历史全章**只占一页图**（p3），之后不再出现年份主线。
- v1 输在**只有顺序没有必然性** → 所以每一幕的第一页都先把上一代**具体卡死在哪**摆出来。
- v2 输在**把形式当逻辑** → 所以没有任何编号代号，靠一道贯穿的题和排除法。
- v3 真正管用的那条：**题一直在眼前，每一步都是在题上排除掉一条路** → 第三幕（p14–p19）全程挂同一句话：
  「那只猫没跳上桌子，因为**它**太胖了 / 太高了」，p15 整页是排除法（固定窗口 / 语法树 / 全连接，三条路都因同一个原因死掉）。

## 三、两件需要你拍板的事

**1. 章节边界变了。**
提示词里 ch2 的边界是「止于架构定型，不讲预训练语料、不讲对齐」，而 ch3《从 chat 到 agent》
现在占着 预训练 → 对齐 → CoT → ReAct → tool call 一整条。
但你这次明确要求「一个大模型是怎么练出来的，最重要的工序是啥」要进来。
**这一版的处理：ch2 吃下预训练本身**（自监督 / 分词 / 数据 / scaling law / 训练循环），
**停在 base model**（p25、p28 把边界写成正面的自我限制：「从会续写到会办事，本章不讲」）。
好处是 ch3 拿到一个更干净的起点；代价是 ch3 得删掉预训练那一段。**要不要这么改，你定。**
