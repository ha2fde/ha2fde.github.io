从 Agent 到 AGI

出发点：今天的模型缺什么

今天的模型是这么造出来的：拿存量文本训一遍，再调教一遍，然后把权重冻住上线。四个缺口都长在这条链上。
1 · 料要见底
人写过的高质量文字是个固定的数，训完就没了。
→ 继续 scaling
2 · 没有后果
语料里全是别人做完的结果，没有「我动一下会怎样」。
→ 世界模型 · 具身智能
3 · 没有信号
写作、研究、决策做完了，也不知道做得对不对。
→ RL + 可验证环境
4 · 不会变强
上线之后权重就是常数，用一万次和用一次一样聪明。
→ 连续学习
四个缺口其实只有两类
1、2 是没有料——缺第一人称的、带后果的经验；3、4 是没有回路——不知道自己做得对不对，也没有通道把「对不对」写回权重。后面五个主题，往回追都会落到这两类里的一类。

这一章要讲的主题，一张图

五个主题，每个补一个缺口。它们不是五个互相竞争的选项，而是同一件事的五个方向。RSI 和 AGI 不是第六、第七个主题——一个是机制，一个是终点。
每个主题都按同一个格式讲
它在补哪个缺口 → 它卡在哪 → 什么信号出现，说明它真的动了。第三条最有用，可以拿去对照将来看到的每条新闻。
读的时候把这三层分开
「AGI 什么时候到」是在问终点，「AI 会不会自己加速」是在问机制，「哪个方向更快」是在问能力来源——三个问题，不能混着答。

主题一 · 继续 scaling：红利没结束，但换了一根轴

继续加算力，还灵不灵？要看你说的是哪一根轴——今天有两根，形状完全不一样。
两根曲线的形状完全不同。蓝的在变平——不是失效，是每多一分能力要付的算力在指数上涨；橙的刚起步，同一个模型多想一会儿就能明显更准。「scaling 撞墙了」这句话只对蓝的成立。
为什么蓝线会变平
要让能力再上一个台阶，模型和数据得同步放大，于是算力大致按平方往上涨。而数据那一头根本跟不上。
数据是存量，不是流量
算力可以造，芯片可以扩产，但人类写过的高质量文本是个固定的数。合成数据、多模态、私域数据是三种续命方式，都不改变量级。
「多想一会儿」是真的新轴
让模型多想、多试几遍、自己检查，准确率就会往上走。它把知识存在权重里换成答案现场搜出来——绕开了数据墙，代价是每次用都要付钱。
这一轴现在的量级还剩多少空间成本结构
预训练算力前沿训练约 1e26 FLOPs 量级还能涨，卡在电力、芯片供给和建设周期一次性投入，之后每次推理都便宜
高质量数据公开文本约 1e13 token 量级接近见底，靠合成与多模态续，量级不变买不来也造不出，是硬约束
推理时算力一次回答 1e2 ~ 1e6 token刚开始，曲线还很陡每次调用都付，规模化后是大头
为什么「撞墙了」和「根本没撞」的人都对
他们说的不是同一根轴。预训练那根确实在变平，同样的投入换来的提升一年比一年小；而模型的总能力还在快速涨，因为增量来自另外两根——多想一会儿，以及下一页要讲的「可验证奖励」。所以「scaling 还灵不灵」是个坏问题。

主题二 · RL + 可验证环境：奖励从哪来

强化学习不是新东西，卡了十年的从来不是算法，是奖励。这个主题的全部内容就一句话：把「学出来的奖励」换成「算出来的奖励」。
RLHF：奖励是一个学出来的模型
人标注偏好 → 训一个 奖励模型 R̂ 模型去追 R̂ 的高分，而不是追真实的好坏 于是： R̂ 越被优化，它越不准
这就是「钻空子」的来源：R̂ 只在人标注过的那一小片范围里靠谱，而模型为了拿高分，会主动往那片范围外面跑。所以只能拿绳子把它拴住——拴住的同时，也限死了它能学多远。
人标注还有一个规模问题
标注质量的上限是标注者的水平。模型一旦在某个领域超过人类标注者，人类偏好就不再是有效信号——这是 RLHF 无法把模型带到超人水平的根本原因。
RLVR：奖励是一段代码算出来的
模型给出答案 → 跑一个 检查器 → 0 / 1 检查器可以是： 单元测试　编译器　数学答案比对 形式化证明检查器　游戏胜负　仿真器
奖励糊弄不了（除非检查器本身有洞），不要人参与，可以无限量生成。模型比人强也没关系——检查器不是人，它只判对错。这三条合起来，才是这个主题被押注的原因。
瓶颈已经从算法挪到了环境
算法这一侧基本定型了。真正稀缺的是「能自动判分、难度可调、够多样」的环境。环境工程正在变成新的数据工程——这是当前投入最集中的地方。
只给对错，学得动吗
办法是同一题一次做很多遍，再比较这几遍之间谁好谁差——信息就出来了。
检查器有洞就一定会被钻
模型会写出「让测试通过但没实现功能」的代码。检查器的严密程度，就是这个主题的天花板。
难度必须跟着能力走
全对或全错都没有梯度。环境要能自动调难度，把通过率稳在中间——这部分工程量往往比算法本身大。
这个主题最大的未解问题：能判分的地方练出来的本事，能带到别处去吗
在数学和代码上练出来的推理能力，看起来会部分溢出到没练过的领域——但溢出多少、为什么会溢出，目前没有定论。溢出很强，这个主题就直通 AGI；只在能判分的地方管用，它就只是一个很强的专用放大器。这个问题的答案，决定其余四个主题的相对权重。

「可验证」的边界在哪：AGI 要的能力大半在右边

这个主题能扩多远，取决于一件很具体的事：这个任务，能不能写一段程序来判对错。照这个标准，任务分成三格。
左边这格已经不是瓶颈
数学和代码上，模型在标准评测上已经很难再拉开差距。继续往这格投，边际收益在降。
中间这格是当前主战场
办法是把模糊的判分变成能跑的判分：写细则、拆检查点、让模型当评委再互相核对。
右边这格才决定 AGI
「什么值得做」没有检查器。人靠很久以后的后果学会它——而这正是今天最缺的信号。
可验证 ≠ 简单
奥数题在最左边，它一点也不简单。「难」和「难验证」是两回事——所以模型能在奥数上超过人，却在「写得好不好」上还很平庸。
这个主题真正的问题：能把多少任务挪到左边
每挪过来一类任务，就等于给它开了一条无限量的训练通道。过去两年的进展大半来自这种「挪」，而不是更好的算法。

主题三 · 连续学习：权重不再是只读的

今天的模型上线之后，权重就是一个常数。它服务一亿次，和第一次一样聪明——因为从「用得怎么样」回到权重的那条路，根本不存在。
外挂记忆：便宜、可控、上限明确
RAG、记忆文件、长上下文都属于绿线。好处是可审计、可删除、不会训坏；代价是每次都要重新读一遍。
红线真正难的地方：学新的会冲掉旧的
学新的就容易忘旧的。改一次动的是整套参数，没法只动「关于这件事」的那一小块。
还有一个安全问题
权重能被在线改，就意味着被投毒的输入可以永久改变模型。这是连续学习没被大规模上线的真实原因之一。
写到哪一层写入方式保持多久容量量级能不能改变模型的「直觉」
上下文窗口直接塞进 prompt一次会话1e5 ~ 1e6 token不能
外部记忆 / RAG写文件、存向量库永久无上限不能，只是检索得更准
权重本身训练时更新参数永久1e11 量级参数能——只有这一层能
这个主题的判据很简单：有没有真的动到第三行
大部分叫「记忆」「自我进化」的产品，做的都是前两行。它们让模型「查得到」，但没让模型「学会」——分辨方法：把检索关掉，看它还会不会。而要真动第三行，先得有一个信号告诉它「这次该不该学」，那个信号正是上一个主题要造的东西。

主题四 · 世界模型：在脑子里试，不用真试

世界模型学的是一件事：给定现在的状态和我要做的动作，接下来会变成什么样。学会它，模型就能在脑子里把方案跑一遍，不用真付代价。
这就是「规划」的全部含义——把试错从真实世界搬进模型内部。AlphaGo 走的是这条路，只不过它的世界模型是围棋规则，规则是精确的、免费的。难点在于：真实世界没有规则书，模型必须自己学，而学出来的一定不准。
卡点：误差会滚雪球
每步误差 ε，往后展开 T 步： P(至少错一次) = 1 − (1−ε)^T ε=1%　T=20 　→　18% ε=1%　T=100　→　63% ε=5%　T=20 　→　64%
想象得越远越是在编故事。可用长度被单步精度卡死。
所以真正的用法是「短程想象 + 频繁校准」
在模型里只往前推几步，然后拿真实反馈拉回来。把 T 压小，是目前唯一有效的对策。
LLM 算不算世界模型
它学的是「人接下来会怎么写」，不是「事情接下来会怎样」。token 级，不是状态级。
为什么现在忽然热起来
视频生成模型被发现顺带学到了物体恒存、遮挡、重力。世界模型也许能从视频里学。
它和主题二是同一件事的两面
一个够准的世界模型本身就是仿真器，也就是检查器——主题二缺的那种环境，它能批量造。
最容易被跳过的一句话：世界模型不解决「该做什么」，只解决「做了会怎样」
它给的是状态转移，不是价值判断。知道每条路通向哪里，和知道哪条路值得走，是两个独立的问题——后者仍然要回到第 6 页最右边那一格。把世界模型当成 AGI 的完整答案，是把「预测」和「取舍」混成了一件事。

主题五 · 具身智能：唯一还能自己造数据的地方

前四个主题争的都是怎么把存量数据榨得更干净。它不一样——这是唯一一个能凭空生出新数据的方向，因为动作真的会改变世界。
它补的是「没有后果」那个缺口
语料里全是别人行动的结果。具身给的是第一人称的因果：我推了，它倒了。
卡点一：真机数据贵得离谱
一条轨迹要一台机器、一个场地、一段真实时间。这部分不能靠买卡加速。
卡点二：仿真和真实之间有缝
仿真里可以刷无限数据，但摩擦、形变、光照都对不上。缝有多宽，决定仿真数据值多少钱。
数据来源今天的量级是存量还是流量带不带因果
公开高质量文本1e13 token存量，接近见底没有——记录的是别人行动的结果
网络视频1e9 小时量级存量，还有余量有物理，但没有动作标签
仿真轨迹想刷多少有多少看着像流量，但只在仿真里有因果，但物理对不准
真机交互轨迹1e6 条量级流量，机器越多数据越多有，而且是第一人称的
这个主题的时钟和别的不一样：它受物理时间约束
前四个主题的瓶颈是算力和数据，加钱能换速度；它的瓶颈里有一段是真实时间——一台机器一天只能试那么多次，一个抓取动作就是要花三秒。所以它大概率是最慢的一条，但也是唯一一条越走数据越多、不会枯竭的路。上面表里那道数量级的鸿沟，就是它今天的全部处境。

RSI：那个「递归」到底是什么意思

RSI 是「递归自我改进」。日常说的「AI 自己改进自己」，其实混着三件难度差很远的事——分开这三件，这个话题就清楚了一大半。
说的是哪一件AI 在做什么谁在改进它下一轮会更快吗
自动化按人给好的方法去做事：写代码、跑实验、整理资料人不会
自我改进参与改进自己：造训练数据、挑超参、出题目人定方向，AI 出力不一定
递归自我改进改的是「怎么改自己」这件事本身AI 自己会 —— 这才是 R
R 就是这个形状的差别：不是「AI 在做事」，也不是「AI 变强了」，而是这一轮变强，让下一轮变强得更快。注意前半段两条线几乎贴在一起——所以早期的快慢，看不出是哪一种。
一句话就能分辨
问：第 N 轮的改进，有没有让第 N+1 轮改得更快？答不上来，那就还在上面两行里。
最容易上当的一个说法
「AI 已经在写下一代 AI 的代码了」——是真的，但它落在第二行：方向还是人定的，下一轮不会因此变快。
今天卡住它的不是算力，是两件很朴素的事
要让这个圈转起来，AI 得能判断「这次改动到底算不算变好」（第 5–6 页在解这件事），还得有通道把改动真正留在自己身上（第 7 页在解这件事）。这两件今天都没解决，所以现在看到的「自我改进」，几乎都停在第二行。

AGI 这个词，有三派互不兼容的定义

前面都在讲「怎么走」。但终点画在哪儿，会反过来决定该走哪条路——而这个终点，从来没谈拢过。
一 · 能力覆盖式
什么算到了：人能干的有价值的活，它都能干。
它指向：继续 scaling 和 RLVR——先把覆盖面拉满。
二 · 自主式
什么算到了：没人盯着，也能把一件事从头做完。
它指向：可靠性、长程一致性、世界模型。
三 · 学习式
什么算到了：进到一个全新领域，能从零学会。
它指向：连续学习和 RSI，别的都是绕路。
为什么这条线三派都认
覆盖式看「能干多少活」，自主式看「能撑多久不用人管」，学习式看「会不会自己学」——任务越长，三样都得同时成立。
但它有一个测不到的盲区
它测的是已经会的任务能扛多久，测不出「换个全新领域，它会不会学」。第三派最在意的那件事，这条线看不见。
AGI 不是一个开关
三派量的都是连续的东西。争「到没到」不如争「哪个数在涨」。
过了某个考试不等于到了
题会泄漏，也会被针对性刷。分数涨了，不一定是能力涨了。
ASI 是另一个问题
超过人 ≠ 通用。竞赛数学和编程上已超过绝大多数人，通用性没多。

五个主题各自卡在哪：一页对照

五个主题讲完了，并排放在一起。最后一列是这张表里最有用的东西——它是判据，不是描述。
主题卡在哪什么信号出现，说明它真动了
继续 scaling高质量数据是存量；电力、芯片、建设周期同等算力下，预训练效果还按老速度往上走
RL + 可验证环境环境不够多；判分做不了的地方过不去过去难判对错的任务上，也能稳定判出对错
连续学习学新的容易忘旧的；改一次动的是整套参数；投毒风险上线模型的权重按周更新且不退化
世界模型一步的小误差会滚成大误差，想不远想象 100 步之后，仍然和真实对得上
具身智能数据、硬件、仿真对不准，还有真实时间同一套模型换台机器、换个场景也能直接用
RSI（横跨以上全部）验证和写回这两格都还是空的模型产出的改进，让下一轮改得更快
中间那列会过时，最后一列不会
「卡在哪」半年就要重写一遍，但「什么信号说明它动了」是稳定的——大部分被宣布的突破，都对不上最后那一列。
这张表上没有的一行：对齐与可控
上面讲的都是「能力从哪来」。它不是第六个主题，是每个主题各自要交的作业——而它没有自己的 scaling 曲线。

它们不是竞争关系：真正的瓶颈只有两个

把这些主题的依赖关系画出来，会看到它们其实是一条供料链上的不同环节——决定整体速度的，从来不是最快的那一环。
箭头是有方向的
上游不动，下游就拿不到料。具身不动，世界模型能拿到的因果数据就只剩视频；底座不动，好的判分器也训不出来，验证那一格只会更紧。
两个红格子是同一件事的两半
一个负责判断「这次改好了没有」，一个负责把改动留在权重里。缺任何一个，环都闭不上——RSI 那一格就永远亮不起来。
RSI 不是旁边多出来的一条路
它在这条链的末端：前面两个红格子都通了，RSI 那一格才亮得起来。所以谈 RSI，绕不开先谈判分和写回。
这张图的读法：不是挑一个主题站队，而是找链上最紧的那一环
整体速度由最紧的一环决定，而今天最紧的两环都是红的：既没有足够多、足够严的判分器，也没有把学到的东西写回权重的通道。其他主题的所有进展，最后都要经过这两格，才能变成「模型自己会变强」。如果只盯一件事，就盯这两格什么时候不再是红的。
