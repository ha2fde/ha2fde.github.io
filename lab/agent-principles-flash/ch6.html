AGENT 原理与实践 · 第六章

从 Agent 到 AGI

不预测「何时到」，只梳理「有几条路」。每条路摆证据、说瓶颈，并把预测换成一张可证伪的观察清单。

五条路线只讲已发生硬约束：不给时间表
开场为什么本讲不预测：AGI 没有公认定义

AGI（Artificial General Intelligence，通用人工智能）这个词没有公认定义。同一个词，三种口径各说各话：

经济定义

能干人类所有经济工作，且不比人差、不比人贵。源自对人类劳动替代的测算研究（GPTs are GPTs，2023）。

能力基准定义

在几乎所有测试里达到人类水平。DeepMind 给出过可操作的分级框架，把「智能」拆成等级表（Levels of AGI，2024）。

自主性定义

能自主完成长程目标，不需要人拆步骤。对应 Agent 的「自主行动」一极——正是本讲从今天 Agent 出发的理由。

既然目标没有公认标尺，「预测何时到」就没有意义——每个定义都能给出自己的「到了」。所以本讲不拿 AGI 当目标，只问：从今天的 Agent 出发有哪几条路，各自的证据与瓶颈是什么，怎么判断哪条在走通。

定义之争是前提不是重点；本讲只使用可核实的「已发生」事实，推断部分一律明确标注。

方法方法：每条路线固定四栏
① 主张是什么

这条路假设了什么机制、相信能力从哪来。一句话能讲清，讲不清就等于没主张。

② 目前有什么证据

只摆已发生的：已发表的论文、已跑出的实验、已在用的产品。每条注明出处、年份、链接。

③ 已知瓶颈

这条路硬约束在哪：数据、算力、可验证性、成本、物理世界。瓶颈决定路能走多长。

④ 走通的信号

如果它对了，我们先看到什么。写实、可观察、可证伪——「看到 X 算走通，看到 Y 就不算」。

硬约束：本讲不给时间表。不出现任何年份预测。一旦给「AGI 在哪年到」的年份，这一讲就从「可证伪的路径梳理」变成算命，前面可核实的部分会被连坐。

后文每条路线按同一四栏展开；证据厚的给两页，单薄的一页讲完。最后一栏留给反复对照。

路线一 · 继续 Scaling更大模型 + 更多算力与数据 → 能力继续涨
主张

能力随参数、数据、算力的规模增大而提升，且提升遵循可预测的规律——「大力出奇迹」是一条可复现的路。

证据

标度律（scaling laws）有可复现的观察：损失随规模按幂律下降（Kaplan 2020）；「数据/参数」存在最优比例（Chinchilla 2022）。

瓶颈

数据墙：人类文本总量有上限；算力成本随规模陡增；评测饱和：榜单越做越挤不出差距；「继续涨还是收益递减」本身有争议。

信号（可证伪）

① 新能力出现在没被针对性优化过的任务上；② 榜单被普通任务饱和主导，前沿差距缩小到难以测量；③ 算力投入继续单调增长，但性价比明显下降。

信号①对照「涌现」：不是玄学，是「没优化过的任务也变好」，可直接测试。信号③是警示灯：投入涨而回报不涨，说明单靠 scaling 的路正在见顶。

路线一 · 继续 Scaling深挖：标度律的观察与争议
证据厚在哪：两个可复现的观察
  • 幂律损失曲线：模型大小、数据量、算力与损失之间是平滑幂律（Kaplan 2020），训练可以「预算化」。
  • 最优分配：Chinchilla（2022）指出当时主流模型「参数过剩、数据不足」，按计算量最优比例分配能显著提效。
  • 后续兑现：o 系列、DeepSeek-R1（2025）等前沿模型仍以「规模 + 更大投入」为底座，标度律至今没被证伪。
争议在哪：涌现是真实还是度量假象
  • 涌现（emergence）：Wei 等（2022）观察到某些能力跨规模「跳变」出现，像质变。
  • 争议：Schaeffer 等（2023）指它可能是非线性度量造成的假象——换线性度量曲线就平滑。两派都有人支持。
  • 怎么裁决：不看话术，只看「跳变」是否在多种度量下都成立，是否出现在没针对性优化的任务上。
一句话：标度律的「观察」是实的（损失曲线可复现），「解释」是有争议的（涌现是不是度量假象）。这就是「证据厚」与「证据仍需验证」同时成立的来源。
路线二 · RL + 可验证环境在可验证反馈里强化学习，推理能被直接训练出来
主张

在可验证奖励（verifiable rewards）的环境里做强化学习（reinforcement learning，RL），推理能力能被直接训练出来，而不是等着涌现。

证据

AlphaGo（2016）在可验证的棋类环境用 RL 击败人类冠军；AlphaProof（2024）数学接近 IMO 金牌；DeepSeek-R1（2025）与 o 系列证明 RL 能提升通用模型推理。

瓶颈

可验证的任务空间有限：能自动打分的只有数学、代码、棋类、定理证明；真实世界绝大多数任务没有自动裁判。RL 的天花板 = 裁判能判的边界。

信号（可证伪）

① RL 训出的推理迁移到非形式化任务（写方案、做规划）并带来可测提升；② 训练算力分配明显转向 RL，而不是只堆预训练；③ 「长思考」在更多任务上带来系统性收益，而非时好时坏。

信号①最关键：如果 RL 只提高「考试类」成绩、出了考场就没用，它只是刷题工具；走通的标志是推理迁移出可验证领域。

路线二 · RL + 可验证环境深挖：RLVR 生成 → 打分 → 强化
三步闭环

生成候选：模型对同一道题（或同一个代码/数学任务）产出多个解答。

规则/程序打分：确定性规则判对错——代码跑测试看通过率，数学看答案与标准是否一致，博弈看胜负。全程无人评分，所以可海量做。

强化：用 RL 把「得分高」的思维路径强化出来、把「得分低」的淘汰掉，反复多轮。

优点 vs 天花板

优点：信号干净、可自动化、样本可无限扩充；因此 RLVR（reinforcement learning with verifiable rewards，基于可验证奖励的强化学习）让 DeepSeek-R1（2025）用相对小成本把推理拉到前沿。

天花板：它把「智能」压缩进「可验证任务的求解器」。离开可验证领域，信号从「对/错」退化成「人觉得好不好」，这套就失效了。

判读点：RLVR 证明了「可验证反馈 → 直接强化出推理」这条因果链成立（o 系列、R1、AlphaProof 都是已发生证据）。它能不能通向 AGI，取决于「可验证任务」的边界能不能扩大——这正是第四栏在盯的。
路线三 · 连续学习与记忆会记住、会更新、不遗忘，才算会学习
主张

智能不能每次从头开始。模型要持续从新经验学习（continual learning）、长期记住、按需更新，而不是只靠一次预训练 + 一个上下文窗口。

证据

上下文与记忆系统已落地：RAG 检索增强、MemGPT（2023）的「换页式内存」；长程任务有基准可测（GAIA 2023）。

瓶颈

灾难性遗忘（catastrophic forgetting）是早有记录的老问题：学新忘旧；权重不稳定，微调后旧能力回退；模型分不清该记住还是该忘记。多数「记忆」只是外挂检索，不是真在学。

信号（可证伪）

① 跨天 / 跨会话的长程任务完成率显著提升（不只是单轮）；② 记忆被跨会话复用——新会话主动利用旧结论，而不是每次重塞上下文；③ 微调后旧能力不回退，可复现地保持。

信号②是分水岭：今天多数「记忆」是把文档塞进上下文，靠「读得快」不是「记得住」。看到复用才算真记忆。

路线三 · 连续学习与记忆深挖：现在的「记忆」其实是三种东西
① 上下文记忆

材料塞进窗口，读一遍、用完即忘。最便宜，也是今天的默认形态；缺点是长、贵、每次重读整段。

② 外挂记忆

检索增强（RAG）、MemGPT（2023）式换页内存：模型本身没变，存取由外部系统管。已是成熟工程，但「记得」不等于「在学」。

③ 权重记忆

把经验写进模型参数，才是真持续学习。问题正是灾难性遗忘：学新忘旧，且模型无法区分「该记」与「该忘」。

分界点：①②是工程问题，③是学习问题。第四栏信号里「记忆跨会话复用」「微调后旧能力不回退」盯的正是 ③ 是否真正出现。
路线四 · 多 Agent 分工与经济体单个不够，就上一群；协作里涌现能力
主张

单个 Agent 做不动的任务，交给一堆 Agent 分工协作（multi-agent systems，多 Agent 系统）；交互中涌现（emergence）出单个体没有的能力，像经济体一样自我组织。

证据

多智能体辩论（Du 2023）提升答案一致性与事实性；A2A 协议（2025）让不同厂商的 Agent 互相通信成为互操作标准。

瓶颈

通信开销与延迟；错误经分工被放大传播；token 成本随 agent 数量爆炸；没有统一目标时，各 agent 的行动会互相抵消。

信号（可证伪）

① 多 agent 在单 agent 必失败的任务类上稳定达标；② 出现未被显式编程的协作行为（自发分工、自行排优先级）；③ 通信/协调开销占比下降，规模变大反而更划算。

信号①是硬门槛：如果只是「单 agent 也能做、多 agent 更贵」，这条路就不成立。目前多 agent 的优势大多仍停留在演示层。

路线五 · 世界模型与具身智能来自与世界持续交互：世界模型 + 身体
主张

真正智能要接触真实世界：在体内建一个能预测下一步的世界模型（world model），再靠身体（embodied，具身）去验证和修正，而不是只读文本。

证据

世界模型在视频预测落地：Genie（2024）从视频学到可交互环境；机器人从大模型学动作（RT-2 2023）。

瓶颈

真实世界反馈慢、贵、有危险（试错成本高）；仿真到现实（sim-to-real）有鸿沟——仿真里学的在真机打折扣；物理数据量远小于文本数据。

信号（可证伪）

① 机器人训练从「预训练 + 微调」转向持续在线学习；② 长时程预测一致性改善（预测未来几十步不出戏）；③ 行为在未见过的场景里泛化，而不是记住训练环境。

信号③最难也最真：世界模型的价值 = 对「没见过的情况」预测得有多准，这可以直接测。

对照五条路对照：证据厚薄 × 一句信号速览
路线证据厚薄一句话信号（可证伪）
继续 Scaling 厚 · 观察可复现 新能力出现在没针对性优化的任务上；榜单饱和到前沿差距难测。
RL + 可验证环境 厚 · 多组实验 RL 训出的推理迁移到非形式化任务；训练算力明显转向 RL。
连续学习与记忆 中 · 记忆系统 长程任务完成率提升；记忆跨会话复用而非每次重塞上下文。
多 Agent 分工 薄 · 多为演示 单 agent 必失败的任务类上稳定达标；协作行为未经显式编程。
世界模型与具身 薄 · 早期阶段 训练转向持续在线学习；行为在未见过的场景里泛化。
读法：厚 ≠ 正确，薄 ≠ 没希望。证据厚说明「机制已部分兑现」；证据薄说明「还在演示层」。这张表只回答「现在站在哪」，不回答「什么时候到」。
对照怎么判断「哪条在走通」：看信号，不听营销
看什么：第四栏的观察清单
  • 每条路线都写了「走通信号」，它必须可证伪（falsifiable）：看到 X 才算走通，看到 Y 就不算。
  • 把信号做成检查表，按「已出现 / 未出现 / 反例」三格记账，隔一段时间对一次。
  • 信号要可测：基准、完成率、开销占比、迁移得分——能查数，别凭感觉。
不看什么：三类话术
  • 口号式：「我们领先一个数量级」——没给出可复现的测法。
  • 到达式：「已经具备通用智能」——没有任何公认定义支撑。
  • 预测式：「还有 X 年就 AGI」——给了时间表却给不出可证伪的信号，这正是不该听的。
判断口诀：信号优先于声明。先看有没有可复现的观测，再看它符不符合「走通」的定义；营销口径不进入判断。
组合交叉与组合：五条路不是单选题
今天的产品大多是组合

主流 Agent 产品 = 继续 scaling 的底座 + 记忆（检索/上下文）+ 多 agent 分工（1+3+4）。单一路线是教学切分，现实是拼装。

路径之间互相喂养

scaling 给 RL 提供更好的底座；RL 的推理给多 agent 提供「会干活的个体」；记忆给长程任务提供连续性。

判断也要组合着看

一条路走通，往往会放大另一条路的信号；反过来，一条路的瓶颈可能拖累别的路——比如数据墙同时压着 scaling 和世界模型。

判读提示：与其问「哪条路通往 AGI」，不如问「组合里哪些瓶颈正在被解决」——记忆真被解决，多 agent 的长程协作自动变强。
收尾回到开头：为什么不能给时间表
原因一：定义不统一，时间无从谈起

三个定义各有各的「到了」：经济定义看劳动替代，能力定义看测试全过，自主性定义看长程自治。没有统一终点，就没有统一的倒数。

原因二：一给年份，本讲就变成算命

「X 年到 AGI」没有可证伪的检验——信号由第四栏决定，时间由算命决定。一旦给了年份，前面可核实的路径梳理会被连坐，整讲失去可信度。

替换方案：把时间换成语境

把「什么时候」换成「在什么条件下」：当可验证任务边界扩大、记忆跨会话复用、单 agent 必失败的任务被多 agent 稳定接管时，就是「组合在走通」——我们只描述条件，不押日期。

收尾

不预测，只给你一套对照表

五条路 · 四栏结构 · 证据与瓶颈 · 可证伪的观察清单。

本讲做完了三件事：

  • 不做预测：AGI 没有公认定义，预测「何时到」没有标尺。
  • 只做梳理：摆证据、讲瓶颈、写信号。信号栏留着反复对照。
  • 以后看到任何「快到 / 到了」的说法，先问一句：你对照的是哪个信号？
