从图灵到 Transformer

每一代技术都在解决上一代的瓶颈。三大流派交替主导、两次寒冬、最后 Transformer 把架构定型。

不需要 AI 前置知识能徒手画出 Transformer 的一个 block
开场主线与边界
一条主线

看历史，别只看"谁发明了什么"，要看每一代在解决上一代的什么瓶颈。

  • 坐标系：三大流派——符号主义 / 连接主义 / 行为主义
  • 主体叙事：符号与连接交替主导，中间夹着两次寒冬
  • 终点：Transformer 把架构定型
本讲边界（讲到哪为止）
  • 止于"架构定型，但通用能力还没长出来"
  • 预训练语料怎么来、模型怎么对齐，不是本讲内容
  • GPT-3 之后的事，不是本讲内容
  • 结尾"三派合流"只作一页收束
读完你该能做到两件事：讲清两次寒冬分别是被什么问题打死的；照本讲图徒手画出 Transformer 一个 block 的组成。
三大流派起点：图灵与图灵测试
图灵测试（Turing Test, 1950）

艾伦·图灵在《Computing Machinery and Intelligence》里提出：如果一台机器在对话中骗过人类评判者，让人分不清它是人还是机器，那么就可以说它"能思考"。

关键：它是个"行为"判据

图灵不讨论"机器内部到底有没有意识"，只问外部行为像不像。它不要求你说清内部机制——

这一点，其实暗合后来的行为主义 Behaviorism：看行为，不看内里。

注意这个思路的转向：在讨论"机器能否思考"之前，先把"思考"变成了一个可操作、可检验的问题。后面每一次进展，都是把问题变得更可检验。
三大流派计算的底座：图灵机
图灵机（Turing Machine, 1936）

一个抽象的"计算器"：一条纸带 + 一个读写头 + 一组规则。规则决定看到什么符号、写什么、往哪走。

图灵证明：只要遵循规则，它能算任何"可计算"的东西。

为什么 AI 需要它

图灵机给出三样底料：

  • 输入与输出——问题进去，答案出来
  • 状态——程序"进行到哪一步"可以被记下来
  • 存储程序——规则和数据分开存放，程序本身也是可读写的东西
还有一面：图灵也证明了不可判定性——有些问题任何图灵机都答不了。AI 后来的很多挫折，根源就是低估了"规则算得完吗"这个问题。
三大流派三大流派登场：坐标与立场
符号主义 Symbolicism

智能 = 用符号和逻辑规则做推理。知识写成规则，推理就是规则的推导。

信条：把智慧写进程序。

连接主义 Connectionism

智能 = 大量简单单元（神经元）连成网络，靠调节连接权重学会模式。

信条：从数据里"长"出来。

行为主义 Behaviorism

智能 = 感知—行动—反馈的回路。与环境不断交互、根据后果调整行为。

信条：世界就是最好的模型。

理解全章的一句话：这部历史，主要是符号主义与连接主义交替主导——一方上台把另一方打到寒冬，然后带着新工具回来。行为主义一直当"第三股"，偶尔走上前台。

三大流派符号主义黄金期（1956–1970s）
AI 学科诞生

1956 达特茅斯会议（Dartmouth Workshop）正式把"人工智能 Artificial Intelligence"定名。1958 约翰·麦卡锡发明 LISP——专为符号处理而生的语言。

当时的口号很乐观：把推理交给逻辑。

代表作
  • 定理证明：把公理写成规则，程序自己推结论
  • 通用问题求解器 GPS（1959）：把任何问题转成"目标—手段"推导
  • 逻辑编程（Prolog）："声明事实 + 询问目标"，由机器做推理
它解决的是什么：把"思考"这件事形式化——假设智能 = 符号运算，那么写出规则就等于装进智能。这是第一次给"机器有智慧"一个工程路线图。
寒冬第一次寒冬（约 1974–1980）：被什么打死
组合爆炸

规则一多，推理路径指数级增长。例子：十来个事实的简单问题，穷举组合就远超当时机器能力。规则写法看着优雅，跑起来是天文数字。

知识获取瓶颈

"常识"没法手工编码。写规则的人可以写"鸟会飞"，写不出"企鹅不会飞但也是鸟""飞≠起飞"……常识是无穷无尽的，靠人一条条写不完。

两个报告

ALPAC 报告（1966）：判定机器翻译失败，拨款转走；Lighthill 报告（1973）：英国政府据此大幅削减 AI 经费。

一句话死因：符号主义假设"世界能写成有限条规则"——而真实世界是开放的、充满例外的。写死规则，处理不了常识。
寒冬连接主义回归（1980s）
前史：感知机

1958 年 Perceptron（感知机）用一层神经元学模式，轰动一时；随后被证明单层网络算不了异或这类问题（Minsky & Papert, 1969），连接主义随之沉寂。

复活的节点
  • Hopfield 网络（1982）：把记忆建模成能量最小化
  • 反向传播 Backpropagation（Rumelhart et al., 1986）：让多层网络也能训练，一举突破感知机的天花板
它解决的是什么：不再手工写规则，而是从数据里学——给大量例子，网络自己调权重。代价：从此离不开数据和算力。
寒冬行为主义插曲：智能从行动里长出来
强化学习（Reinforcement Learning）

不给定答案，只给奖励/惩罚。智能体靠"试错 + 最大化长期奖励"学策略。

它今天已长成主角——但这一讲先点到为止。

机器人与包容架构

Shakey the Robot（1966）：第一个能感知、推理、规划的移动机器人。

Brooks 包容架构（1986）：反对"先建完整世界模型再行动"，主张"世界就是自己的模型"——用一层层感知—行动回路堆出行为。

行为主义给全章的提醒：智能不一定要先在脑子里建一个"完整世界"，在真实环境里不断试错，也可能是条正路。
寒冬第二次寒冬（约 1987–1993）：被什么打死
专用硬件崩塌

符号时代带动了一整片 Lisp 机（专用 AI 工作站）市场；PC 崛起后这个市场一夜崩塌，靠它吃饭的实验室与公司成批倒下。

可扩展性之墙

连接主义回来时，网络太浅、数据量级太小——一层层加宽收益有限，数据不到规模，学不出像样的东西。

梯度消失

Vanishing Gradient（梯度消失）：层一深，误差信号反向传播到浅层就衰减到零，深层网络训不动。当时没有解决办法。

难复现

实验依赖玄学式调参，结果经常复现不了，学术声誉受损，"AI 已死"的论调一度占上风。

寒冬专家系统：写规则这条路的两连败
它的繁荣

专家系统 Expert Systems（1980s）是符号主义最后一次商业化高峰：规则引擎 + 知识库，把领域专家的话变成 if-then 规则，用于诊断、配置、审核。

像 XCON（DEC 的电脑配置系统）真赚了钱，企业争相上马。

它的死法
  • 规则维护成本失控：规则涨到几千上万条，改一条牵一发动全身
  • 边界脆弱：没写进规则的情况一来就崩
  • 知识转述失真：专家嘴上说的和写进规则的不是一回事
同一句话第二次出现：写规则这条路，走一次死在"常识编不完"，走一次死在"规则维护不起"。这给后面的连接主义让出了位置。
转折与引爆转折（1990s–2000s）：机器学习登场
换个目标

研究者们不再追求"让机器像人一样推理"，而是追求"让机器预测得准"。名字也从"人工智能"悄悄换成 机器学习 Machine Learning。

新工具
  • 支持向量机 SVM（1990s）：数学漂亮、能泛化的分类器
  • 概率图模型（贝叶斯网络、隐马尔可夫）：把不确定性和概率放回模型
  • 核心转向：用统计、用数据，而不是用规则
这十年是"退一步海阔天空"：目标从"证明它像人"降到"让它在数据上更准"，工程的容错空间反而变大。它攒下了后一场革命的群众基础。
转折与引爆解锁的钥匙：算力 · 数据 · 算法
算力

摩尔定律让硬件持续变快；真正改变局面的是 GPU——原本为图形设计的并行处理器，恰好多层网络每层可以并行算。

数据

互联网带来海量文本与图片。ImageNet（2009，约 1400 万张标注图片）把"大规模标注数据集"变成标准动作。

算法

反向传播早就有了，缺的是把它用到足够大的网络与数据上。三样齐了，深度学习 Deep Learning才真正起飞。

这一页是整个转折的钥匙：连接主义不是第一次赢——它只是第一次同时拿到"够快的算力 + 够多的数据 + 成熟的训练算法"这三样。上一轮缺的不是理念，是条件。
转折与引爆引爆点：AlexNet（2012）
发生了什么

2012 年 ImageNet 竞赛，Krizhevsky 等人的 AlexNet（深度卷积神经网络，跑在 GPU 上）把图像分类错误率断崖式拉低，碾压所有手工特征方案。

为什么是分水岭
  • 第一次证明：端到端学习 End-to-End Learning——原始像素进去，类别出来，中间特征全是网络自己学的
  • 学术界连夜转向深度学习，"机器学习"变成了"深度学习"
  • 连接主义正式回归并成为绝对主角
它解决的是什么："特征靠人设计"的瓶颈。特征 = 数据 + 算力学出来的，不再靠专家手挑。代价同样清晰：没有大算力和大数据就无从谈起。
序列与注意力语言带来的新瓶颈：序列
语言是序列

图片是一大块像素，语言是一个接一个的词，顺序本身就携带意义。"我打你"和"你打我"完全是两件事。

此前的解法
  • n-gram 统计语言模型：只看前 n-1 个词，靠马尔可夫假设取巧
  • RNN / LSTM（LSTM, 1997）：把"已读过的内容"压进一个隐藏状态，逐词推进
三个死结：① 必须串行——读完一个词才能读下一个，慢、没法并行；② 长距离依赖衰减——隔得远的词之间的关联会"稀释"；③ 全部信息被压进一个向量，内存有上限。
序列与注意力注意力：不再只靠一个压缩向量
Attention（Bahdanau et al., 2015）

机器翻译里，生成每个输出词时"回看"输入序列的全部位置，给每个位置一个权重，加权拼出当下要用的信息。

不再是"把整句压成一个向量再展开"，而是按需取用。

解决了什么
  • 长距离信息：隔再远也能直接"看到"
  • 信息瓶颈：不用把一切塞进固定大小向量
  • 翻译质量立竿见影，成为标配

代价/局限：它仍寄生在 RNN 上——循环的串行瓶颈还在。

TransformerTransformer（2017）：去掉循环，全靠注意力
出生证明

"Attention Is All You Need"（Vaswani et al., 2017）——不再用循环，直接用注意力搭起整个网络，因此得名 Transformer（变换器）。

三个核心设计
  • 自注意力 Self-Attention：序列里每个词同时看所有词，一次算完
  • 位置编码 Positional Encoding：没有循环了，得把"位置信息"显式注入
  • 残差连接 + 层归一化（Residual + LayerNorm）：让深层网络训得动
它一次性解决了上一页的三个死结：不再串行（可并行）、长距离天然直达（注意力直接连任意两个位置）、不再有"压缩向量"瓶颈。代价：注意力要算"每两两词"的关系，复杂度 O(n²)，越长越贵。
Transformer徒手画一个 Transformer block
TransformerSelf-Attention 怎么算

直觉：一个词要"看"全句——它用自己（Q）去问每个位置"你和我像不像"（K），像就给高分，再按分数（softmax）加权取走每个位置的信息（V）。

代价：每个词要跟每个词打分，复杂度 O(n²)。句子越长，计算涨得越凶——这是长文本昂贵的根源。
Transformer多头注意力 Multi-Head Attention
为什么多组头：单一"相似度"不够用。有的头抓句法结构、有的头抓指代关系、有的头抓语义相似——并行分工，模型就同时看到多个角度。这是它的表达力来源。
Transformer并行与规模：它赢在"能变大"
为什么比 RNN 快

RNN 必须读完词₁才能读词₂——串行。Transformer 一次把所有词同时送进注意力——无顺序依赖，可并行。同一块 GPU 上，Transformer 对同样长度的序列能利用的算力多得多。

由此带来的规模

训练效率上去了，才养得起更大的模型、更多的数据。

于是"规模"第一次成为主角——这也是后面一切（大模型、预训练）的起点。至于"大"怎么变成"强"、怎么训练、怎么用——那是后续阶段的事，本讲讲到架构定型为止。

一句话记住这个转折：注意力让模型"看得更全"（O(n²) 也认了），可并行让模型"练得动"——架构的定型，本质是让"大"成为可能。
Transformer架构定型：Encoder–Decoder

之后的走向（一句话）：翻译要"读全句再写"，所以是 Encoder–Decoder；后来的大模型发现只要"一直往下写"，只用解码器（Decoder-only）就够——这是下一阶段的事，本讲不展开。

这一页的意义：从图灵到 2017，架构之争在这一刻定型——之后不是换架构，而是把 Transformer 越做越大。
收尾三派合流（一页收束）
符号的影子

结构、推理、知识表示的想法还在——今天的很多系统里仍能看见"把知识显式组织起来"的意图。

连接的胜利

主角是它：可学习的网络、数据驱动、端到端——从 AlexNet 到 Transformer 一脉相承。

行为的复归

"目标 + 反馈 + 不断调整"的强化学习思想，会在后面的阶段重新走上前台。

合流的含义：历史不是"谁取代谁"，而是三股思路在今天的系统里各占一格、互相配合。记住这一点，比记住任何单个年份都重要。

收尾

架构定型，能力未满

你记住这条线：图灵把问题变成可检验的 → 符号主义把智能当规则写 → 两度被常识与维护成本打死 → 连接主义拿数据与算力复活 → 注意力与可并行让 Transformer 定型。

本讲讲到这里为止：

  • 能徒手画出 Transformer 一个 block：Embedding+位置编码 → 多头注意力 → Add&Norm → 前馈 → Add&Norm
  • 能讲清两次寒冬分别死于什么（组合爆炸与常识编码；专用硬件崩塌、浅网络与梯度消失）
  • 预训练语料、对齐、GPT-3 之后——那不是本讲的地盘
