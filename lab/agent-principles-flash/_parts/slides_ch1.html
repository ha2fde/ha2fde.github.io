开场Agent 和聊天机器人差在哪
聊天机器人（Chatbot）

你问一句，它答一句。输出就是终点，下一步永远由你来做。

例：客服问答、随手查个定义。

Agent（智能体）

给它一个目标，它自己拆步骤、自己动手，做完才算完。

例：读完整份项目、改完代码、跑完测试再汇报。

差别不在"会不会说话"，而在"会不会自己把事做完"。

两个零件客户端和模型是两回事

客户端负责"把话说出去、把结果摆出来"。它决定你怎么跟模型交流，但不决定模型是谁。

模型负责"真正想问题"。它通常不直接出现，你通过客户端或 API（Application Programming Interface，应用程序接口） 跟它对话。

同一个客户端可以接不同模型，同一个模型也可以被不同客户端调用。谁跟谁组合，完全由你决定。类比：遥控器换了，播放器照播；播放器换了，遥控器照用。

两个零件客户端有哪些（一）：对话聊天
ChatGPT · OpenAI

对话、写作、读文档、看图；有免费档和订阅档。

chatgpt.com

Claude · Anthropic

长文档、写作、代码分析见长；订阅里还带编程 Agent。

claude.ai

Gemini · Google

和 Google 全家桶（Gmail、Docs）结合紧密。

gemini.google.com

DeepSeek · 深度求索

网页对话免费额度大，推理模型便宜，适合日常用。

chat.deepseek.com

这类客户端的特点是开箱即用：浏览器打开就能聊。适合对话式任务——问、答、改、总结。

两个零件客户端有哪些（二）：代码三兄弟别搞混
代码补全

在光标处接着写几行，你按 Tab 接受。作用范围 = 一小段代码。

例：GitHub Copilot、Cursor 的 Tab 补全

编程 Agent

给它一个任务，它读仓库、改代码、跑测试，做完才停。作用范围 = 整个项目。

例：Claude Code、Codex CLI

AI 编辑器

把前面两者装进"房子"里，边写边用。作用范围 = 你的开发环境。

例：Cursor、Windsurf、Zed

一句话分界：补全帮你"打几个字"；Agent 帮你"把一个任务做完"；AI 编辑器是它们住的房子。三者经常一起出现，但不是一回事。
模型模型从哪来（一）：云端，三种买法
① 按量 API

充钱、按 token 用量付费。适合自己写程序、做自动化。OpenAI API、Anthropic API。

② 订阅

月费买额度和产品功能，人直接用。例：Claude Pro（$20/月，含 Claude Code）、ChatGPT Plus。

③ 借别人的产品

不直接接触模型，工具商已经接好。例：办公软件、笔记、搜索里的"AI 按钮"。

一句话选法：想自己造 → 按量 API；想省事 → 订阅；只是想用 → 借。

三条路都会把数据发到厂商服务器，用之前看一眼隐私条款。

模型模型从哪来（二）：本地自己跑
Ollama

命令行工具，一行命令下载并运行开源模型，几乎零门槛。

ollama run qwen3:8b

ollama.com

LM Studio

带图形界面：下载模型、聊天、调参数都不碰命令行。

lmstudio.ai

为什么值得跑本地：数据不出机器、断网可用、不按量烧钱（只花电费）。

代价：能力明显弱于云端前沿模型；速度取决于硬件。

开源模型（Llama、Qwen、DeepSeek 等）在 ollama.com/library 免费下载。

模型硬件对号入座：你的机器能跑多大
模型规模（Q4 量化）约需显存常见配置能干什么
3–4B≈2–3 GB笔记本 CPU 也能扛轻量问答、起草
7–8B≈4–6 GB8 GB 显存 / 16 GB 内存日常聊天、翻译、总结
13–14B≈8–10 GB12–16 GB 显存写代码、较复杂任务
32B≈20 GB24 GB 显存（如 RTX 4090）复杂推理
70B≈40 GB48 GB 显存或双卡接近前沿，速度慢

估算口诀：Quantization（量化）到 Q4 后，参数每 10 亿 ≈ 0.6 GB。7B ≈ 4–5 GB，70B ≈ 40 GB。

Apple 用户：统一内存 = 显存，M 系列 16 GB 能舒服跑 13B。

能跑 ≠ 跑得快。显存不够会把数据挤进内存，速度掉 5–20 倍；CPU 单跑大模型会很慢。

口径：Q4 量化、单用户。核对 2026-07。详细数据见 ollama.com/library 与 LM Studio 文档。

用起来怎么换模型（一）：在客户端里换
网页 / App

对话框附近或设置里的模型选择器，点一下切换（ChatGPT、Claude、Gemini 都有）。

对话历史通常不丢——只换大脑，不换本子。

本地（Ollama）

直接指定要跑哪个模型：

ollama run qwen3:32b

LM Studio 在侧栏下拉里换，即换即用。

关键点：换的是模型，客户端不用换。这正是"客户端与模型分离"的第一个体现。
用起来怎么换模型（二）：API 里换 = 改一行

写程序时，换模型就是改 model 参数这一行：

from openai import OpenAI
client = OpenAI()

resp = client.chat.completions.create(
    model="gpt-4.1-mini",   # 改这一行，就换了模型
    messages=[
        {"role": "user", "content": "把这份材料总结成三条要点"}
    ],
)
print(resp.choices[0].message.content)
背后的道理

程序只负责"把话递过去、把结果拿回来"，模型是谁不重要。

同一条消息，今天发给 GPT、明天发给 Claude、后天发给本地模型，代码几乎不动。

（各家接口略有差异，切换时需小改——接口细节不在这讲展开。）

成本要花多少钱（一）：token 计价
怎么计价

Token（词元）是模型读写文本的基本单位，中文一个字通常 1–2 个 token。

账单 = 输入价 × 输入量 + 输出价 × 输出量。输出普遍贵 4 倍上下。

模型（参考价）输入 $/百万输出 $/百万
GPT-4.1（OpenAI）2.008.00
GPT-4.1-mini0.401.60
Claude Sonnet 52.00（促销期）10.00
Claude Haiku 4.51.005.00
算一笔真实的账

让模型写 1000 字 ≈ 1500–2000 个输出 token。

用 GPT-4.1-mini：0.2 万 × $1.60/百万 ≈ $0.003

用 Claude Sonnet 5：0.2 万 × $10/百万 ≈ $0.02

单次很便宜；贵在频率和输出长度。高频批量跑一天也就一杯咖啡钱，但别不记账。

价格随时变动，以官网当日为准（核对 2026-08）：openai.com/api/pricing · platform.claude.com。

成本要花多少钱（二）：上下文越长越贵，缓存帮你打折
上下文（Context）

每次提问，模型都把整段对话连同提示词重读一遍，这一段按输入计价。

对话越长、塞的材料越多 → 每次付的钱越多。模型没有"只记重点"这回事。

提示词缓存（Prompt Caching）

重复出现的前缀会命中缓存，命中部分大幅打折：

Claude 命中约按 10% 计价；OpenAI 命中约按 50% 计价。

固定说明、长文档当"背景"反复引用时，缓存能省一大截。

省钱习惯：别把海量材料塞进每次提示词；系统说明、长文档放前缀，让它吃缓存；一个任务结束就开新对话，别让上下文无限堆长。
成本要花多少钱（三）：按量 vs 订阅
按量 API订阅
怎么付用多少 token 付多少固定月费，$20 上下起步
适合谁写程序、批量任务、自己做 Agent个人日常对话、想稳定用产品功能
上限钱花完为止，无软性限额有额度，超出会限速或等窗口
典型例子OpenAI API、Anthropic APIChatGPT Plus $20 · Claude Pro $20
经验法则：自己写程序 → 按量（可控、可算）；人直接对话 → 订阅（省心）。订阅也常把 Agent 工具打包进来——例如 Claude Pro 就含 Claude Code。

价格核对 2026-08；免费额度与促销随时变，以官网为准。

写文档、汇报的

对话客户端：ChatGPT / Claude 网页

重点在长文、总结、改写。

先跑通流程，再决定要不要投入。

重隐私 / 常离线

Ollama / LM Studio 跑本地开源模型

数据不出机器，代价是能力打折。

开始怎么开始（二）：0 成本也能跑
  • 免费聊天客户端：ChatGPT、Claude、Gemini 都有免费档，够日常对话和大部分写作。
  • 新账户赠金：OpenAI / Anthropic 的新 API 账户通常会送少量额度（约 $5），够把第一个程序跑通。
  • 本地开源模型：Llama、Qwen、DeepSeek 在 Ollama / LM Studio 里免费下载，3–8B 多数笔记本带得动。
  • 开源客户端：免费的编程 Agent、聊天界面层出不穷，基础能力够用。
0 成本 ≠ 0 能力。本地 7–8B 模型足够体验"给任务 → 看它做 → 修问题"的完整循环。先把流程跑起来，再谈投入。
开始怎么开始（三）：第一次上手，三步
①

装一个客户端。网页版就行，零安装。

②

选一个模型。先用默认推荐，别纠结。

③

给一个真实任务。越小、越具体越好。

一个能直接抄的任务：

读一下这个文件夹里的三份文档，
用三句话总结每份的内容，
再列出一条你觉得被遗漏的重点。

任务要"具体 + 有交付物"。别问"你能帮我吗"，直接说"把 X 做成 Y"。

开始安全底线：喂之前先想三件事
① 不喂什么

密钥、API Key、密码、身份证号、未脱敏的个人与客户数据。

② 数据去哪

云端模型 = 数据进入厂商服务器，先看隐私条款；本地模型 = 数据不出机器。

③ 授权什么

让 Agent 读写文件、发消息、花钱之前，先看清它的工具权限和你的确认机制。

④ 渠道

只用官方渠道。来路不明的"破解版""赠送额度"往往是钓鱼。

记住：发给模型的，默认等于"贴到公网上"。敏感内容先脱敏，再让 Agent 处理。
