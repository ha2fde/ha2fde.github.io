HOW TO USE

怎么读这份索引

三步查阅法

  • 按组找 —— 六组主线：大模型基础 → Agent 范式 → 工程架构（Harness）→ 协议生态 → 落地实践 → 课程路径，先定位组，再定位条目。
  • 按编号引 —— 全册 01～23 连续编号，讲义、讨论中直接引用编号即可互相对应。
  • 点链接即达原文 —— 所有链接为精确 URL，放映时可直接点击打开原始出处。
本册只做"一句话导读"，不解释资料内容：它是参考文献，不是教程。

权威性标准

  • 收录：官方文档（厂商官方 / 标准组织）、正式论文与预印本（arxiv 等）、公认权威人物经典文章（Lilian Weng、Simon Willison、Andrej Karpathy、Rich Sutton）。
  • 国内来源：仅限厂商官方文档（如 DeepSeek、阿里云百炼官方帮助中心）。
  • 剔除：个人微信 / 知乎 / 公众号文章、自媒体、民间课程笔记、个人技术博客、国内中转站、产品下载页、纯营销文章。
