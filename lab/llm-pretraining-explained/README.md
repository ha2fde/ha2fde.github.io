## 贯穿全篇的三条主线

1. **模型 = 一堆待确定的数字。** 训练就是回答"这几十亿个数字该填什么"。
2. **起点可精确预测。** 初始 loss = `ln(词表大小)` = 11.76,终点约 1.8 —— 几个月和几百万美元买到的就是这段距离。
3. **能力在预训练,体验在后训练。** 99% 算力形成知识,不到 1% 决定你实际用起来的感受。
