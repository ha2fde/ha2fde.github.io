# 第二章 · 从机器学习到 Transformer（内部归档）

22 页。**倒着筛，顺着讲。**

## 这一版的写法

先把 Transformer 拆开，看每个零件往前挂着哪些深度学习的东西；那些东西又挂着哪些机器学习的东西。
筛出这条链上的知识点，再从头顺过来讲一遍。**链条以外的，一概不讲。**

- 第 2 页：倒着筛的骨架图（六行零件 × 三段来源，每格标着它在哪一页展开）
- 第 3–7 页：① 机器学习 —— f(x;W)、三件事、概率分布、梯度下降、数据与 batch
- 第 8–14 页：② 深度学习 —— 矩阵乘、激活、输出层与损失、训练循环、残差、归一化、Embedding
- 第 15–21 页：③ Transformer —— 序列的难处、注意力五步、多头与掩码、位置编码、装配图、形状与参数量、训练 vs 生成
- 第 22 页：把同一条链顺着读一遍，并列出这一章刻意没讲的东西

## 刻意没讲

CNN / RNN 的内部结构、偏差方差与正则化、决策树与集成、预训练与后训练流程、RLHF 与对齐、
评测体系、推理部署优化、Agent 怎么搭 —— 都在这条链之外。
