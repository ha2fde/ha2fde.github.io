## 全章的论点

1. 要看的不是模型有多强，而是**回路转不转得起来**——今天真实发生的自我改进几乎全在外壳，不在权重。
2. 回路的上限由**验证**决定，不由算力决定。可验证 / 不可验证那条线，同时解释了 AI 在哪些事上快到失真、在哪些事上原地不动。
3. g&gt;1 和 g=1 在早期看起来一样，所以**要看加速度，不看速度**——这也是全章不给任何时间表的原因。

全章第 23 页明确写了这三句各自最强的反驳，以及本章的回应；第 22 页明确说明「现在到底是哪一种」在当下不可判定。
