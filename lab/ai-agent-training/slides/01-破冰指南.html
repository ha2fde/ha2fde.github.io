第 1 章 · 它们跟 ChatGPT 有啥不一样？

破误解：Agent 是"干活"，不是"回答"

💬 入门者原话："我用过 ChatGPT，这些 Agent 不就是更强的聊天机器人吗？"
直接回答：不是。ChatGPT 给你一段"回答"，Agent 替你"把活干完"——读文件、改代码、跑命令、调工具，从头做到尾。
聊天机器人（ChatGPT 类）AI Agent（Claude Code 类）
你给它一个问题一个任务
它给你一段文字回答干完的结果（文件改好了 / 命令跑完了）
动手能力没有，只能说有：读写文件、跑命令、调工具
工作方式一问一答思考→行动→看结果→再思考，循环到干完
一句话顾问实习生
✅ 你现在可以做什么：回想一件你最近想让电脑"自己干完"的杂活——那就是 Agent 的用武之地。

第 5 章 · 大脑从哪来（云端）

云端的三种"买脑"方式：专卖店 / 超市 / 全球代购

💬 入门者原话："都说要配 API，API 到底去哪买？"
直接回答：云端大脑有三个"货架"，区别不在"国内 / 国外"四个字，而在你能买到什么模型、谁开票合规、网络稳不稳：① 厂商直供＝单点直连、最透明；② 国内云聚合＝一个 Key 买齐多家国产模型；③ 全球中转网关＝一个 Key 用上 Claude / GPT / Llama 等全球模型。

形态一 · 厂商直供（专卖店）

单点直连，一家一个 Key

  • DeepSeek / Kimi（月之暗面）
  • GLM（智谱）/ MiniMax …
  • 每家用各家的 Key
  • 最透明、最可控、可精挑模型

形态二 · 国内云聚合（超市）

一个 Key 买齐多家国产模型

  • 火山引擎方舟（字节）
  • 阿里云百炼（通义）
  • 统一接口、一个 Key 管多种
  • 合规稳、国内网络快，但仍是国产模型

形态三 · 全球中转网关（代购）

一个 Key 接全球几百个模型

  • OpenRouter 等
  • 能用上国内拿不到的 Claude/GPT/Llama
  • 统一计费、自动路由
  • 代价：走中转、延迟与合规要权衡
三家都有"免费入口"：注册赠送 / 免费额度 / 免费模型（额度以各平台官方为准）。记住：形态二 ≠ 形态三——前者只聚国产模型，后者才通向全球模型。
✅ 你现在可以做什么：先不用注册任何账号——看完第 11 章"免费资源地图"再决定办哪家的"卡"。

第 5 章 · 大脑从哪来（云端）

三个名词：API Key、Base URL、模型名

💬 入门者原话："教程里老出现 API Key、Base URL，都是啥意思？"
直接回答：记住三句话：API Key 是付款凭证，Base URL 是接口地址，模型名是选哪个大脑。把用云端大脑想成"打电话叫外援"。

📞 Base URL

= 电话号码（打给哪家平台）

厂商的 / 云平台的 / OpenRouter 的，各不一样

🔑 API Key

= 话费账户（付款凭证）

谁拿到都能花你的钱 → 别泄露、别发群聊

🧠 模型名

= 点名要哪个大脑接电话

同一家店里也有很多模型可选

⇒ 任何 Agent 工具配置云端大脑，填的都是这三样。看到教程先找这三个词，找到就看得懂。
✅ 你现在可以做什么：以后看到任何配置教程，先找这三个词——找到就看得懂。

第 6 章 · 自己搭大脑：本地运行大模型（重点）

把大脑装在自己电脑上：为什么有人要这么干

本地跑的好处要付的代价

离线：断网也能用模型文件占硬盘（几个 GB 起）
完全可控：想换就换、想删就删第一次要下载模型，要等

第 6 章 · 自己搭大脑：本地运行大模型（重点）

配置三档对号入座 + 在哪下、怎么装

💬 入门者原话："我这台电脑跑得动吗？要去哪下模型？"
直接回答：重点看"主流能跑的"——高配 Mac / 高配显卡的个人电脑，或企业的华为昇腾 NPU，都能跑实用的中大模型；纯 CPU 小模型只适合尝鲜，不推荐做主力。
① 配置三档（个人 / 企业视角）
档位你的硬件能跑什么
个人·高配 MacApple M2/M3 Max·Ultra，64–128GB 统一内存14B–70B 量化版，体验接近云端、静音省电
个人·高配显卡RTX 4090/3090（24GB）、4080（16GB）14B–34B 量化，写代码 / 推理流畅
