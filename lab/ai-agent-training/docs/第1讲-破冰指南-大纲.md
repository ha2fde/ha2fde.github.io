## 第1章 它们跟 ChatGPT 有啥不一样？（P3–P4）

### P3 破误解：Agent 是"干活"，不是"回答"

- ① 原话疑问："我用过 ChatGPT，这些 Agent 不就是更强的聊天机器人吗？"
- ② 直接回答：不是。ChatGPT 给你"一段回答"，Agent 替你"把活干完"——它能读你的文件、改你的代码、跑命令、调工具，自己把一件事从头做到尾。
- ③ 对比表：

| | 聊天机器人（ChatGPT 类） | AI Agent（Claude Code 类） |
|---|---|---|
| 你给它 | 一个问题 | 一个任务 |
| 它给你 | 一段文字回答 | 干完的结果（文件改好了/命令跑完了） |
| 动手能力 | 没有，只能说 | 有：读写文件、跑命令、调工具 |
| 工作方式 | 一问一答 | 思考→行动→看结果→再思考，循环到干完 |
| 一句话 | 顾问 | 实习生 |

- ④ 你现在可以做什么：回想一件你最近想让电脑"自己干完"的杂活——那就是 Agent 的用武之地。

### P4 Agent 的三要素：有手、有脑、有循环

- ① 原话疑问："那它凭什么能'干活'？"
- ② 直接回答：因为它比聊天机器人多了三样东西：手（工具）、脑（大模型）、循环（干一步看一步）。
- ③ 字符图：

```
        ┌──────────────────────────┐
        │         一个任务          │
        │   "帮我把这堆文件整理好"   │
        └────────────┬─────────────┘
                     ▼
        🧠 有脑：大模型想"下一步该干嘛"
                     ▼
        ✋ 有手：读写文件 / 跑命令 / 调工具
                     ▼
        🔁 有循环：看结果 → 不对就换个法子 → 再干
                     ▼
              干完，向你汇报
```

- ④ 你现在可以做什么：记住口诀——"有手、有脑、有循环"，后面所有工具都是这三样的不同包装。

## 第2章 一个壳 + 一个大脑（P5–P6，全篇主线）

### P5 通用架构图：所有 Agent 工具都是同一张图

- ① 原话疑问："Claude Code、OpenCode、WorkBuddy……这么多工具，是一个个学吗？"
- ② 直接回答：不用。它们结构一模一样：一个"壳"（装在你电脑上的工具）+ 一个"大脑"（大模型）。学会一张图，就懂了所有工具。
- ③ 核心字符图（全篇最重要的一张）：

```
            你（说人话：我要什么）
                    │
                    ▼
        ┌───────────────────────┐
        │        工具壳          │  ← 装在你电脑上，大多开源免费
        │ Claude Code / OpenCode │
        │ Cline / WorkBuddy …    │
        └───────────┬───────────┘
                    │ 把你的话 + 上次执行结果，打包发给大脑
                    ▼
        ┌───────────────────────┐
        │         大脑           │  ← 两种来源，后面第5、6章细讲
        │  云端 API（按量付费）    │
        │  或 本地模型（免费自跑）  │
        └───────────┬───────────┘
                    │ 返回"下一步做什么"（一段文字指令）
                    ▼
        壳去执行：读文件 / 写文件 / 跑命令 / 调工具
                    │
                    └── 执行结果喂回大脑 → 再想下一步 → 循环，直到干完
```

- ④ 你现在可以做什么：把"壳"和"大脑"在心里分开——这是理解后面所有章节（免费、换模型、本地跑）的钥匙。

### P6 为什么能免费装一堆：壳免费，大脑可买可自造

- ① 原话疑问："这些东西要花多少钱？"
- ② 直接回答：壳大多开源不要钱，随便装；大脑要么用免费额度/免费模型，要么在自己电脑上自跑——第一次上手完全可以一分钱不花。
- ③ 拆解图：

```
  一个 Agent 工具 = 壳 + 大脑

  壳（工具本体）          大脑（大模型）
  ─────────────          ──────────────────────────
  很多开源免费            路线 A：云端 API，按量付费
  直接下载安装            · 但有：注册赠送 / 免费额度 / 免费模型
  （第 3、4、8、9 章）     路线 B：本地自跑（第 6 章）
                          · 完全免费、离线、隐私
                          · 代价：吃你电脑的硬件

  ⇒ 0 成本公式 = 免费的壳 + 免费的大脑（额度赠送 或 本地自跑）
```

- ④ 你现在可以做什么：放下"要不要掏钱"的顾虑——第 11 章会给你一张完整的免费资源地图。

## 第3章 终端编程 Agent（P7）

### P7 Claude Code / Codex / OpenCode：在黑窗口里干活的 Agent

- ① 原话疑问："程序员朋友圈里刷屏的 Claude Code 到底是个啥？"
- ② 直接回答：它是一类"住在终端（命令行黑窗口）里的编程 Agent"——你用大白话说要做什么，它直接改代码、跑命令、看报错、再修，循环到搞定。
- ③ 对比表：

| 工具 | 一句话定位 | 开源？ | 在哪跑 | 最擅长啥 |
|---|---|---|---|---|
| Claude Code | 终端编程 Agent 的标杆，生态最成熟 | 闭源（Anthropic） | 本地终端 | 复杂编程任务，工具生态丰富 |
| Codex | OpenAI 的编程 Agent，有云端版 | 闭源（OpenAI） | 本地终端 + 云端 | 与 ChatGPT 生态联动，云端跑长任务 |
| OpenCode | 开源平替，配置灵活，社区活跃 | 开源 | 本地终端 | 想自由换模型、不想绑死一家的人 |

- ④ 你现在可以做什么：如果你写代码，三选一记住名字就行——第一次建议从开源的 OpenCode 入手（免费、随便换大脑，详见第 12 章）。

## 第4章 编辑器里的 Agent（P8）

### P8 Cline：不想碰命令行？Agent 也能住在编辑器里

- ① 原话疑问："我看到黑窗口就发怵，有不打命令的吗？"
- ② 直接回答：有。Cline 是 VS Code 编辑器里的插件，点鼠标就能用——它先在侧边栏给你列计划（plan），你点头它才动手（act）。
- ③ 形态对比表：

| | 终端形态（Claude Code 等） | 编辑器形态（Cline） |
|---|---|---|
| 长什么样 | 命令行黑窗口，打字交流 | VS Code 侧边栏，有按钮有界面 |
| 适合谁 | 习惯命令行的人 | 喜欢图形界面、想看着代码被改的人 |
| 干活方式 | 边说边干 | plan 模式出方案 → 你批准 → act 模式执行 |
| 共同点 | 都是"壳 + 大脑"，都能读写文件、跑命令 | 同左 |

- ④ 你现在可以做什么：打开你电脑里的 VS Code（没有就装一个，免费），在插件市场搜 "Cline"——这就是你的第一个候选。

## 第5章 大脑从哪来（云端）：模型市场三种形态（P9–P10）

### P9 云端的三种"买脑"方式

- ① 原话疑问："都说要配 API，API 到底去哪买？"
- ② 直接回答：云端大脑有三个"货架"：模型厂商自己开的店、国内云平台开的大超市、以及全球模型的中转站。
- ③ 三形态对比图（必配）：

```
  形态一：厂商直供              形态二：国内云聚合平台           形态三：中转站/聚合网关
  ─────────────────          ─────────────────────         ─────────────────────
  DeepSeek / Kimi(月之暗面)    火山引擎方舟(字节)              OpenRouter 等
  GLM(智谱) / MiniMax …       阿里云百炼(通义) …              一站接入全球几百个模型

  每家一个独立 API Key        一个平台聚合多家模型             一个 API 用全球模型
  想用几家办几个 key          统一接口、一个 Key 管多种         统一计费、自动路由

  像去品牌专卖店              像逛超市，一站买齐               像找全球代购
```

| 形态 | 代表平台 | Key 的数量 | 适合谁 |
|---|---|---|---|
| 厂商直供 | DeepSeek、Kimi、GLM、MiniMax | 一家一个 | 认准某一家模型的人 |
| 国内云聚合 | 火山引擎方舟、阿里云百炼 | 一个 Key 多家模型 | 想省事、要国内访问稳的人 |
| 中转站/网关 | OpenRouter | 一个 Key 全球模型 | 想一个入口试遍全球模型的人 |

（注：各平台均有注册赠送或免费模型，具体额度以官方为准。）

- ④ 你现在可以做什么：先不用注册任何账号——看完第 11 章"免费资源地图"再决定办哪家的"卡"。

### P10 三个名词：API Key、Base URL、模型名

- ① 原话疑问："教程里老出现 API Key、Base URL，都是啥意思？"
- ② 直接回答：记住三句话就够了——API Key 是付款凭证，Base URL 是接口地址，模型名是选哪个大脑。
- ③ 类比图：

```
  把"用云端大脑"想象成"打电话叫外援"：

  📞 Base URL  = 电话号码（打给哪家平台）
                 例：厂商的 / 云平台的 / OpenRouter 的，各不一样

  🔑 API Key   = 你的话费账户（付款凭证）
                 谁拿这个 key 都能花你的钱 → 别泄露、别传群聊

  🧠 模型名     = 点名要哪个大脑接电话
                 同一家店里也有好多模型可选

  ⇒ 任何 Agent 工具配置云端大脑，填的都是这三样。
```

- ④ 你现在可以做什么：以后看到任何配置教程，先找这三个词——找到就看得懂。

## 第6章 自己搭大脑：本地运行大模型（P11–P13，本版重点）

### P11 为什么把大脑装在自己电脑上

- ① 原话疑问："模型还能装在我自己电脑上？为什么有人要这么干？"
- ② 直接回答：能。本地跑模型 = 把大脑下载到自己电脑上运行——免费、离线、数据不出本机；代价是吃硬件，能力一般弱于云端旗舰。
- ③ 取舍对照表：

| 本地跑的好处 | 要付的代价 |
|---|---|
| 隐私：数据不出本机 | 要硬件：内存/显存决定能跑多大的模型 |
| 免费：没有按量计费，随便用 | 能力一般弱于云端旗舰模型 |
| 离线：断网也能用 | 模型文件占硬盘（几个 GB 起） |
| 完全可控：想换就换、想删就删 | 第一次要下载模型，要等 |

- ④ 你现在可以做什么：看看自己电脑的内存和显存（任务管理器 → 性能），下一页对号入座。

### P12 配置三档 + 在哪下、怎么装

- ① 原话疑问："我这台旧电脑跑得动吗？要去哪下模型？"
- ② 直接回答：大概率跑得动——按配置分三档，最小的一档纯 CPU 都能跑（只是慢）；装一个 Ollama，一条命令自动下载并运行。
- ③ 配置三档表（个人视角）：

| 档位 | 你的硬件 | 能跑什么 | 体验 |
|---|---|---|---|
| 入门档 | 8GB 内存 | 1B~3B 小模型 | 纯 CPU 也能跑，慢，能尝鲜 |
| 主流档 | 16GB 内存 + 6~8GB 显存 | 7B~8B 量化模型 | 日常可用，多数人的甜区 |
| 进阶档 | 24GB+ 显存 | 14B~30B 模型 | 本地体验接近云端中等水平 |

> 内存不够就选"量化版"（Q4/Q8）：牺牲一点精度，换来体积大幅缩小。

下载渠道与安装方式：

| 渠道 | 一句话 | 怎么装 |
|---|---|---|
| Ollama（最推荐新手） | 装好后一条命令 `ollama run 模型名`，自动下载并运行 | Windows/Mac 下载安装包；Linux 一条命令 |
| LM Studio | 图形化界面，点鼠标选模型 | 官网下载安装包 |
| ModelScope 魔搭 | 国内模型仓库，下载快 | 网页下载，配合工具使用 |
| Hugging Face | 全球最大模型仓库 | 国内可用 hf-mirror 镜像加速 |

（通用原则：Windows/Mac 下载安装包，Linux 用命令装；具体以各官网为准。）

- ④ 你现在可以做什么：去 Ollama 官网下载安装包——这就是你本地大脑的地基。

### P13 个人可选模型清单 + 本地大脑接进壳里

- ① 原话疑问："模型名字一大堆，我下哪个？本地大脑能给我那些 Agent 工具用吗？"
- ② 直接回答：中文日常选 Qwen，写代码选 Qwen-Coder，超低配选 MiniCPM/Phi 量化版；本地模型完全可以当壳的大脑——OpenCode、Cline 等可直接指向本机的 Ollama，实现完全离线（具体配置以各工具官方文档为准）。
- ③ 模型清单表：

| 模型 | 出身 | 一句话 | 常见规模 |
|---|---|---|---|
| Qwen 系列 | 阿里 | 中文最强之一，日常对话首选 | 1.5B / 7B / 14B |
| DeepSeek 蒸馏小模型 | DeepSeek | 本地跑的是蒸馏版（不是原版） | 1.5B~14B |
| GLM 系列 | 智谱 | 国产老牌，中文好 | 数 B 级 |
| Llama | Meta | 全球最流行的开源模型家族 | 1B~数十 B |
| Mistral | 法国 Mistral | 欧洲代表，小巧高效 | 数 B 级 |
| Phi | 微软 | 小巧，低配友好 | 数 B 级 |
| MiniCPM | 面壁智能 | 端侧友好，小钢炮 | 2B~8B |

本地当大脑的架构图：

```
  ┌──────────────┐      指向 localhost（本机地址）      ┌──────────────┐
  │   工具壳      │  ───────────────────────────────►  │    Ollama     │
  │ OpenCode/    │                                      │  在本机运行    │
  │ Cline 等     │  ◄───────────────────────────────   │               │
  └──────────────┘      返回"下一步做什么"              │  本地模型文件  │
                                                        │ (Qwen 7B 等) │
        全程离线，数据不出本机，0 费用                     └──────────────┘
```

- ④ 你现在可以做什么：在 Ollama 里跑 `ollama run qwen` 类的命令（按你档位选规模），和它说第一句话。

## 第7章 一个壳，多个大脑（P14–P15）

### P14 换模型两条路：改环境变量 vs 路由工具

- ① 原话疑问："我装好了一个工具，但不想用它默认的模型，能换吗？"
- ② 直接回答：能，而且这是常态。两条路：简单的直接改环境变量；复杂的（或想随时切换多家）用路由工具 CC Switch。
- ③ 两条路对比：

```
  路线 A：改环境变量（直连）
  ────────────────────────────
  例：Claude Code 设两个变量即指向别家
      ANTHROPIC_BASE_URL   = 新大脑地址
      ANTHROPIC_AUTH_TOKEN = 新大脑的 Key
  适合：只换一家、换完不常动

  路线 B：CC Switch 本地路由
  ────────────────────────────
  有的工具"语言不通"——比如 Codex 原生只认 Responses 协议，
  需要一个"翻译"。CC Switch 在本机做协议翻译，
  并在多个供应商之间一键切换。
  适合：手里有好几个 Key，想随时换着用
```

- ④ 你现在可以做什么：先记住"能换"这个事实，具体配置等你真装了工具，照官方文档/速查表抄即可。

### P15 全局关系：货源 × 操作面板

- ① 原话疑问："第 5 章云平台、第 6 章本地模型、这章的 CC Switch……它们啥关系？"
- ② 直接回答：一句话——云端三形态和本地自跑是"大脑的货源"，CC Switch 是"换大脑的操作面板"。
- ③ 关系图：

```
            ┌───────────── 大脑的货源 ─────────────┐
            │                                      │
   云端：厂商直供 / 云聚合平台 / 中转站     本地：Ollama 自跑
   （第 5 章，按量付费，有赠送）           （第 6 章，免费离线）
            │                                      │
            └──────────────┬───────────────────────┘
                           ▼
              ┌──────────────────────┐
              │  CC Switch：操作面板   │  ← 协议翻译 + 一键切换
              │ "今天用哪个大脑？"     │
              └──────────┬───────────┘
                         ▼
                    工具壳（随便哪个）
                         ▼
                        你
```

- ④ 你现在可以做什么：把这张图拍下来——以后看到任何"配置教程"，都能对上号：它在讲货源，还是在讲面板。

## 第8章 生活里的私人助理（P16）
