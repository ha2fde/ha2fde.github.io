AGI 路线图：从语言模型到通用智能还需要几步

2026-07-25 · 约 30 分钟 · 未来展望 ⑪
本文核心逻辑
  • AGI 的实现路径可以分解为 6 个递进阶梯，后一步建立在前一步之上
  • 当前我们正处于 第③阶（LLM-based Agent）——这是语言模型能力向通用智能扩散的关键一步
  • 第③阶的核心是把语言模型从"对话工具"变成"自主行动体"：以语言为推理介质，挂载工具、记忆、感知模块
  • 第③阶之后面临的最大瓶颈是 持续学习——突破它之后，AI 可能进入自我加速的"奇点"阶段
  • 最终形态是具身智能：AI 走进物理世界

一、AGI 的六阶梯：一个总览

人工智能正在经历一场从"对话"到"行动"、从"工具"到"智能体"的转变。但很少有人能清晰地回答：AI 到底会沿着怎样的路径走向通用人工智能（AGI）？

综合当前学术界的主流共识和产业界的前沿实践，我们可以提炼出一条清晰、递进的 AGI 路线图。这条路从语言模型出发，经过推理能力的增强、自主行动能力的获得、持续学习机制的建立，最终走向自我进化和物理世界的具身化。

六阶递进：①②已基本完成，③是当前阶段，④是下一个瓶颈，⑤⑥为远期目标。全部使用竖直箭头，干净清晰。

这六阶不是并行的技术方向，而是递进的依赖关系：Agent 要用到 CoT 推理，CoT 需要语言模型基础，持续学习需要 Agent 作为执行载体，自我迭代需要持续学习积累的经验数据，具身智能需要 AI 先具备完整的认知能力。没有一步是白走的。

二、第一阶：语言模型基础

一切的起点。大规模语言模型（LLM）通过在海量文本上的预训练，学会了语言的语法、知识、推理模式，再通过指令微调（Instruction Tuning）和人类反馈强化学习（RLHF）与人类对齐。

这个阶段的产出是一个能理解语言、能生成语言、能执行简单指令的"对话模型"。它已经具备了知识储备和基本的推理能力，但有两个根本局限：

  • 缺乏行动能力——只会"说"，不会"做"
  • 缺乏自主性——每次都需要人类给出完整的指令，不能主动规划

这两个局限，正是下一阶要解决的问题。

三、第二阶：Chain-of-Thought 推理

思维链（CoT）的发现是 AI 发展中的一个转折点。研究人员发现：让模型在输出最终答案之前，先输出中间推理步骤，可以显著提升复杂推理任务的准确率。

这看似简单，但意义深远——它意味着模型学会了一种"内省"的能力：不是直接跳到一个结论，而是先"思考"（生成中间推理步骤），再给出答案。这种"先想后说"的模式，与人类解决问题的方式高度一致。

关键突破：CoT 让语言模型从"一步预测器"变成了"多步推理器"。这种能力上的飞跃，是后续 Agent 范式的必要前提——因为 Agent 本质上就是一个"持续推理直到完成任务"的循环。

CoT 的变体包括 Self-Consistency（多次采样取多数）、Tree-of-Thoughts（树状搜索推理路径）、Graph-of-Thoughts（图结构推理）等。它们在推理深度和探索广度上不断提升，但核心思想不变：把推理过程外显化，让模型在每一步都能"看到"自己的思考。

四、第三阶：LLM-based Agent（当前阶段）

这是本文的核心，也是当前 AI 发展的主战场。LLM-based Agent 的本质可以概括为一句话：

核心定义：LLM-based Agent = 语言推理引擎（LLM）+ 自主控制循环（Harness）+ 外部能力扩展（工具 · 记忆 · 感知）

语言模型不再只是回答问题，而是坐在一个循环中，反复进行观察 → 推理 → 行动 → 再观察的迭代，直到完成任务。这个循环使得语言模型从"对话工具"变成了"自主行动体"。

4.1 统一架构

所有 LLM-based Agent，不管它叫"AI Agent"还是"Agentic AI"，不管它的应用场景是编程、搜索还是自动化，底层架构高度一致：

LLM-based Agent 的统一架构。所有现代 AI Agent 共享同一个 LLM 语言中枢，真正的差异化来自 Harness 层的设计选择。

4.2 为什么所有主流"AI Agent"本质上都是 LLM-based Agent？

当我们审视今天被广泛称为"AI Agent"的产品和框架——无论是编程助手（Claude Code、Codex）、通用 Agent 框架（LangChain、LangGraph）、多 Agent 编排系统（AutoGen、CrewAI）——它们共享一个不可忽视的共同特征：核心推理回路是一个语言模型，所有异构信息在进入推理回路前被投影到语言空间。

视觉信息被编码为文本描述，工具调用被序列化为函数名和参数，数据库查询结果被格式化为文本段落。无论外围挂载了多少模块，最终的推理决策发生在语言空间中。这就是这些系统被称为"AI Agent"但本质是"LLM-based Agent"的根本原因。

那为什么不直接叫"LLM-based Agent"？两个原因：

  • 术语惯性："AI Agent"自 1980 年代就已存在，产业界只是将"传统 AI Agent"替换为"LLM-based AI Agent"，命名没有同步更新
  • 商业考量："AI Agent"听起来更通用、更宏大，而"LLM-based Agent"似乎限制了想象空间

但精确的术语有助于精确地理解问题。当我们清楚地说出"我们研究的是 LLM-based Agent"时，我们就知道：这个系统的能力天花板取决于 LLM 的推理质量，扩展能力需要通过工具接口和记忆系统来实现，下一步的关键突破是让模型能够持续学习而不是每个任务都从零开始。

4.3 多样性从哪来？Harness 层的设计空间

如果核心都是 LLM，那不同 Agent 之间的差异从何而来？答案在 Harness 层——LLM 之外的"骨架代码"。Harness 的设计选择决定了 Agent 的行为特征和适用场景。

Harness 维度设计选项影响
控制循环ReAct / Plan-Execute / Tree Search / 组合决定推理深度和灵活性
工具数量0 — 37+ 个决定能力边界
记忆策略工作记忆 / RAG / 情景记忆 / 无记忆决定信息持久性
上下文管理滑动窗口 / 摘要压缩 / 结构化缩减决定长任务能力
编排拓扑单 Agent / 顺序管道 / 层级编排 / 网状决定协作模式
模型路由单模型 / 多模型切换 / 级联决定成本与质量权衡
重要洞察：对 Harness 层的研究还处在早期阶段。现有系统在控制循环、工具数量、记忆策略上的差异远大于在 LLM 选择上的差异。这意味着在模型能力接近天花板后，Harness 层的创新将是推动 Agent 能力进步的主要驱动力。

4.4 Agent 的四种核心能力

LLM-based Agent 之所以能完成语言模型无法独立完成的任务，是因为它在架构层面集成了四种核心能力：

工具调用（Tool Use）：Agent 可以调用外部工具（搜索引擎、代码执行器、文件系统、数据库）来获取信息或执行操作。MCP（Model Context Protocol）的出现标志着工具接口正在走向标准化。

规划（Planning）：在开始执行之前或执行过程中，Agent 可以将复杂任务分解为子步骤，形成执行计划。Plan-and-Execute 模式将规划与执行分离，使得每一步的执行都可以基于上一步的结果动态调整。

记忆（Memory）：Agent 可以维护短期工作记忆（当前对话上下文）和长期记忆（通过 RAG 检索的知识库）。记忆机制使 Agent 的行为有了"历史感"——它知道之前做过什么、学到了什么。

反思（Reflection）：Agent 可以评估自己的输出，发现错误并纠正。Reflexion 模式让 Agent 在每次行动后记录经验反馈，在后续决策中参考。这是 Agent 具备"学习能力"的雏形。

LLM-based Agent 的四种核心能力。这四种能力共同构成了 Agent 的完整行为模式。

五、第四阶：持续学习——下一个瓶颈

LLM-based Agent 已经能够完成令人惊叹的任务——编写代码、撰写报告、分析数据、自动化工作流。但它仍然无法替代人类员工。原因只有一个：它不能像人一样持续学习。

核心差距：你招一个员工，他花两个月熟悉公司环境、了解业务、认识同事之后就能独立工作。但 AI 没有这两个月的"学习期"——每次对话都是一次全新的开始。你必须把所有的上下文（"小王是谁、负责什么、邮件地址是什么"）都塞进提示词里。

这个"无状态"问题是当前 LLM-based Agent 的根本局限。尽管 RAG 和记忆系统在一定程度上缓解了信息获取的问题，但真正的持续学习意味着：Agent 能够从每一次交互中提取经验，转化为可复用的知识，并在未来的任务中自发地应用这些知识。

持续学习包含三个层次：

层次当前状态AGI 所需
事实积累✅ RAG 可检索✅ 基本满足
技能习得❌ 不会从工具使用经验中改进需要跨 session 的技能内化
策略进化❌ 不会根据历史结果调整行为模式需要反思 → 经验 → 策略的闭环

解决了持续学习，AI 就具备了人类最基本的成长能力。这正是它走向"奇点"的跳板。

六、第五阶：AI 自我迭代——奇点

当一个 AI 系统具备了持续学习能力之后，它能做什么？最关键的——它能参与 AI 研究本身。

这不是科幻。当 AI 能够阅读研究论文、理解实验方法、编写代码、测试假设、分析结果——并且能够从每一次实验中持续学习——它就能在两个层面上加速 AI 的发展：

  • 效率层面：自动化实验流程，24/7 不间断运行
  • 能力层面：发现人类研究者可能忽略的模式和联系

这就是"奇点"的含义——当 AI 能够研究 AI，进步的速率就不再受限于人类研究者的速度和数量，而只受限于计算资源。这个阶段的 AI 已经能做人类能做的所有事情，并且能自己开发下一代更强的 AI 模型。

需要强调的是：这个阶段不是自动到来的。它依赖于第④阶（持续学习）的真正突破，以及足够强大的第③阶（LLM-based Agent）作为执行载体。没有前两阶的基础，自我迭代就是空中楼阁。

七、第六阶：具身智能

路线图的最后一步：AI 走进物理世界。

具身智能（Embodied Intelligence）指的是 AI 系统不再局限于数字世界，而是通过机器人等物理载体在现实世界中感知、行动和交互。它可以做家务、照顾老人、操作设备、建造物体。

为什么把它放在最后？因为物理世界的交互要求认知能力先成熟——一个连数字世界都无法自主操作的 AI，不可能安全地操作物理设备。具身智能是 AGI 的"毕业项目"：在认知能力完备之后，把智能扩展到物理维度。

六阶梯的依赖链：认知能力（①—⑤）走在前面，具身化（⑥）是认知成熟之后的自然延伸。

八、支线一：多模态——AI 如何"看"世界

前面六阶路线图在讨论 Agent 时提到过：Agent 的感知模块可以接收视觉信息。但有一个更深层的问题没有展开：AI 到底是怎么"看"图片和视频的？它跟人眼看东西是一回事吗？

答案可能会让你意外：目前的多模态大模型（比如 GPT-4V、Claude Vision）跟人眼的"看"完全不同。 它不是真的在看，而是在——读。

8.1 人是怎么"看"的

人的视觉系统经过了数亿年的演化，是一条高度专用的处理通道：

  • 视网膜接收光信号
  • 初级视觉皮层（V1）检测边缘和线条方向
  • 高级视觉皮层组合边缘为形状、形状为物体、物体为场景
  • 顶叶和颞叶处理空间关系和物体识别

这个过程中，人不是一次性"截屏"整张图。人眼会快速扫视（saccade），目光在不同区域之间跳跃，大脑将多次注视的信息拼接成完整的场景理解。

更重要的是，人的视觉思考是独立于语言的。你想象一个苹果旋转 90 度后的样子时，你的视觉皮层在工作，你的语言区几乎不参与。这就是为什么即使你"说不出话来"，也仍然能"看得懂"——视觉和语言是两套并行的认知系统。

8.2 多模态模型是怎么"看"的

多模态大模型的视觉处理流程完全不同。我们一步步拆解：

多模态模型的视觉处理流程。每一步都在做"翻译"：图片 → 小方块 → 数字列表 → 参与语言推理。

具体来说：

  • 第一步：切图。 把一张图片切成十几个到几百个小方块（patch），每个方块 16×16 像素。
  • 第二步：编码。 每个小方块经过 Vision Encoder（一个神经网络），变成一个Embedding——其实就是一长串数字。
  • 第三步：混合。 这些数字序列被放进 Transformer（LLM 的核心架构）的输入中，和文本的 token 放在一起。
  • 第四步：推理。 Transformer 在这些数字和文本之间做 attention（注意力计算），"理解"图片内容，然后生成文字回答。

8.3 所以 Embedding 到底是什么？

这是理解 AI 最核心也最容易困惑的概念。请记住这个比喻：

Embedding = 一个东西的"数字身份证"。 只不过这张身份证上写的不是文字，而是一长串数字。这些数字编码了这个东西的"含义"——它是什么、它跟什么有关、它像什么。两个相似的"东西"会有相似的数字串。

举个例子：如果我们要给三种水果做 Embedding——

  • "苹果"的 Embedding 可能类似于：[0.2, 0.8, -0.3, 0.1, ...]
  • "梨"的 Embedding 可能接近于：[0.3, 0.7, -0.2, 0.0, ...]（和苹果很接近）
  • "手机"的 Embedding 则完全不同：[-0.9, 0.1, 0.8, -0.6, ...]（和苹果相距很远）

在 AI 内部，所有东西都被转换成了这种数字形式——文字、图片、声音、代码。然后 AI 通过计算这些数字之间的距离来判断"它们是不是相关的"。这就是为什么多模态模型能"看懂"图片：它把图片也翻译成了同一种数字语言。

一句话总结：多模态模型不是真的在"看"图片，而是把图片翻译成跟文本一样的"数字语言"，然后在同一个数字空间里做推理。视觉信息在进入推理核心之前，已经被"语言化"了。

8.4 多模态在六阶梯中的位置

理解多模态的运作机制后，你会发现一个重要的规律：

在当前的 AI 架构中，视觉不是独立于语言的推理通道——它是语言推理的一个输入源。 图片和文字最终在同一个 Embedding 空间中汇合，由同一个 Transformer 统一处理。这与人类的认知结构（视觉→视觉皮层独立处理，语言→语言区独立处理，两者在高层融合）有根本性的不同。

这个现象反过来支撑了本文的核心论点：语言是当前 AI 的唯一推理介质。 不管是文字对话、代码生成，还是图片理解、视频分析——所有的信息在进入推理核心之前，都被翻译成语言空间的表示。视觉没有自己的"思考回路"。

这也意味着：第③阶（LLM-based Agent）加挂视觉感知的能力，本质上是在 Agent 的语言推理引擎上再接一个"翻译器"——把摄像头信号翻译成 Embedding，供语言模型理解。这与人类视觉系统的工作方式有本质区别，但在工程层面非常有效。

九、支线二：世界模型——AI 如何"预测"世界

六阶梯之路的终点是第⑥阶（具身智能）——AI 走进物理世界，操控机器人。但涉及物理世界，一个关键的缺失能力就浮现出来了：AI 需要理解物理世界的因果规律。

一个简单的例子：如果你看到一个杯子放在桌边，你马上能判断"再推一下就会掉下去摔碎"。这个判断你不需要试错就能做出——因为你的大脑里有一个世界模型，它告诉你"悬空的东西会下落"、"玻璃碰到硬地会碎"。你把这个模型应用到了当前场景中，预测了结果。

9.1 世界模型是什么？一个直观理解

想象你在玩一个超级马里奥的游戏。你按"跳"键，马里奥跳起来；你按"右"键，马里奥向右移动。你之所以能玩这个游戏，是因为你的大脑在玩的过程中建立了一个简化的世界模型：

  • "按跳跃键 → 人物上升 → 重力作用下落"
  • "掉到坑里 → 死亡"
  • "踩到蘑菇怪 → 怪物消失"

你不需要知道游戏源代码，也不需要逐帧计算物理方程。你的大脑内部有一个简化的因果模拟器——这就是世界模型的核心思想。

世界模型 = AI 内部的一个"因果模拟器"。 它能回答一个问题："如果我做 A，接下来会发生什么？" 不需要真实地执行 A，只需要在"脑中"模拟一遍。

更技术一点的定义：世界模型是一个能根据当前状态和智能体的行动，预测下一时刻世界状态的系统。

世界模型的工作方式：先模拟，再行动。不用试错也能做出正确决策。

这跟大语言模型有什么区别？

大语言模型（LLM）世界模型
预测对象下一个文本 token下一个世界状态
推理介质语言（文字序列）潜在状态（连续数字空间）
能处理什么文本可描述的一切有物理规律的空间和时间
强项知识、对话、创作、推理物理因果、空间关系、运动预测
弱项不理解物理世界难以处理抽象知识

9.2 为什么世界模型很重要？

你可能会问：LLM 已经能做这么多了，为什么还需要世界模型？两个原因：

  • 语言模型不理解物理世界。 它能回答"杯子会掉下去"是因为在训练数据中见过这句话，不是因为它理解重力、材质、硬度和碰撞——它的知识来自文本统计，不是因果理解。
  • 物理世界需要因果推理。 当你让一个机器人端水杯时，它需要的不是"该怎么回答"，而是"怎么移动手臂、手指施加多少力、保持平衡、避开障碍物"。这些都是物理问题，不是语言问题。

世界模型就是为了解决这个问题而生的——它是 AI 理解物理世界的关键组件。

9.3 现在的进展如何？卡在哪？

目前世界模型的研究进展可以用一句话概括：

在简单环境中有进展，在复杂世界中还差得远。 目前的几个代表性工作：
  • DreamerV3（Google DeepMind，2023）： 在 Minecraft、Atari 等游戏环境中，让 AI 先在"梦境"（模拟的世界模型）中训练，再在实际环境中执行。在简单游戏中效果显著。
  • Daydreamer（Google，2023）： 同样的思路应用于机器人控制——机器人在"闭眼想象"中练习走路，比不用的机器人学得更快。
  • JEPA（Yann LeCun / Meta，2022-至今）： 提出"在潜在空间而非像素空间做预测"的思路——不预测具体的画面，只预测抽象的表示。目标是让世界模型更高效。目前还在研究阶段。

卡住的瓶颈有两个：

  • 计算的代价太高。 要预测一帧高清画面，需要的计算量远大于预测一个文本 token。虽然在"潜在空间"做预测可以降低计算成本，但代价是精度和信息量的损失。
  • 世界的复杂度太高。 文字世界的规律是相对稳定的（语法规则不变、知识变化慢），而物理世界的状态空间是无穷的——每一帧画面、每一个物体、每一种材质、每一种光的反射都不一样。

产业界的投入也很有限。 相比于大语言模型和 Agent 系统的万亿美元级投资，世界模型赛道的研究投入要小几个数量级。大部分资金和人才在更容易变现的领域——对话模型、AI Agent、代码助手。

9.4 世界模型与六阶梯的关系

世界模型在 AGI 路线图中是一个补充性的研究方向，而不是与六阶梯竞争的另一条路径。两者在未来可能融合：

  • 在第③阶 LLM-based Agent 阶段，世界模型的主要作用是辅助 Agent 进行物理世界的规划——比如让 Agent 在行动之前先"想象"结果。目前这个思路主要停留在实验室。
  • 在第⑥阶具身智能阶段，世界模型几乎是必不可少的。没有世界模型的机器人就是"盲操作"——每次伸手、走路、抓取都需要实时计算，没有预测能力。有了世界模型，机器人可以在行动之前在内部模拟中"试验"不同的方案，选择最安全的。
  • 远期理想：语言模型（处理抽象知识和推理）+ 世界模型（处理物理因果和空间） + Agent（自主行动和控制循环），三者融合为统一的智能系统。
理想的 AGI = 语言模型（抽象推理）+ 世界模型（物理因果）+ Agent 系统（自主行动）。三者各司其职，形成完整的智能系统。

但这只是理想。现实中，世界模型的研究进度远远落后于语言模型。产业界有句玩笑话："世界模型离实用大约还需要两个世界模型突破。"短期内，AGI 路线的核心推进力仍然来自语言模型和 Agent 系统的快速迭代，世界模型则是一个关键但还未成熟的补充。

十、路线图的启示

回顾整条路线图，我们可以提炼出几个核心启示：

第一，AGI 不是单一突破，而是递进阶梯。 它不会在某一天突然出现，而是沿着清晰的路径逐步实现。每一阶都有明确的科学问题和工程挑战。认识这条路径，有助于我们判断当前工作的优先级：我们是否在解决当前阶段最关键的问题？

第二，当前的重心在 LLM-based Agent。 大规模的模型预训练红利正在放缓，真正的增量创新正在向 Agent 层迁移——工具接口的标准化（MCP）、Harness 架构的创新、多 Agent 协作的编排、记忆系统的深度整合。这些才是接下来 1-2 年的主战场。

第三，持续学习是通往 AGI 的"最后一公里瓶颈"。 在 Agent 能力日趋成熟之后，下一个必须攻克的难关就是让 AI 具备持续学习的能力。这个问题的解决，将直接触发第五阶（自我迭代）的出现，从而启动自我加速的飞轮。

第四，这条路径的"必然性"源于语言的地位。 语言是人类认知的唯一已知载体，也是 AI 与人类交互、传承知识、表达推理过程的天然媒介。以 LLM 为核心的 Agent 架构不是偶然的工程选择——它是当前通往 AGI 的唯一已知路径，就像内燃机不是汽车的唯一可能动力，但在当时的工程技术条件下，它是最可行的选择。AI 的"内燃机"就是语言模型。

当前的时间线焦点：第③阶 LLM-based Agent 正在快速成熟，第④阶持续学习是决定 AGI 能否加速推进的关键。

总结：AGI 不是靠某一次"大统一理论"式的突破（如爱因斯坦的统一场论）来实现的，它更像是一条工程阶梯——每一级都需要扎实的科学突破和工程技术，上一级为下一级铺路。我们现在站在第③级（LLM-based Agent）上，已经能看到第④级（持续学习）的轮廓。路还很长，但方向已经清晰。
