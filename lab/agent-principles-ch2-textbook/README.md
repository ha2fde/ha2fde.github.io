## 一、这一版的组织方式

**不讲一条贯穿全章的主线，按知识块罗列。**

- **每一页自成一个完整知识块**：定义 + 公式 + 关键数字 + 对照表 + 什么时候会失效，都在同一页上给完，不需要翻回前面。
- **逻辑在页内，不在页间**。页内固定按「是什么 → 怎么算 → 什么时候用 → 什么时候会错」排；页与页之间允许跳跃（比如深度学习直接跳到 Transformer）。
- **跨页引用只做指路，不做前提**（如「见第 38 页」），任何一页单独拿出来看都成立。
- 模块之间可以任意顺序阅读，也可以只查其中一页。

## 四、格式与核查

- CSS 底盘、播放器脚本**逐字节沿用**线上 `ch2.html`，可以整文件替换。
- 1280×720 固定舞台，页眉 72 / 正文 608 / 页脚 40 / 左右边距 56，版心 1168×608。
- 六档字号（44/30/21/18/15/13），每页语义色 ≤3（蓝=数据流 绿=产出 橙=工程 紫=模型 红=坑）。
- 全部为内联 SVG，无 ASCII 图；SVG 字号 ≥12px，描边 ≥1.5。
- **溢出核查**：1920×1080 / 1400×900 / 980×660 三个视口，46 页全部无溢出。
- **二轮校对（2026-08-14）修掉的四处**：
  - 三处内联 SVG 的 `<text>` 里混用了 HTML `<b>` 标签 —— HTML 解析器遇到它会**直接退出 SVG 上下文**，图会散。已全部换成 `<tspan font-weight="700">`。
  - p32 的 8B 参数账：注意力一行按 MHA 算（6700 万），但总计按 GQA 收口，加起来对不上。已统一到 GQA 口径（每层 4200 万 → 32 层约 70 亿 → 总计约 80 亿）。
  - p39 把 3930 万 GPU 小时记在 Llama 3 405B 头上 —— 那是整个 Llama 3 系列的合计。已改为 16,384 卡 × 54 天 ≈ 2100 万。
  - p40 LoRA 省下的显存写成 12 字节/参数，实际是梯度 2 + FP32 主权重 4 + 优化器状态 8 = 14。
  - 另外把 p14 的层号上标 `a⁽ˡ⁾` 改成 `a^(l)` —— 上标小写 l 和 1 在正文字体里几乎分不出来。
- 关键数字核对到一手来源（AlexNet 15.3% / 次名 26.2%，Chinchilla 20 tok/param，FineWeb 15T token / 96 个 CC 快照，Llama 3 405B 16,384×H100 / 54 天 / 466 次中断 / 419 次非计划，cl100k 约 10 万词表、Llama 3 为 128,256）。核对日期 2026-08-13。
