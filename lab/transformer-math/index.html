Transformer 的数学

不讲比喻，只写式子。从一串 token 编号到一个损失值，中间每一步的公式和形状；哪些矩阵是参数；反向传播时每个式子怎么倒着算回去。
看完能自己从零推一遍，并且知道每个数字存在哪、要花多少算力。
前向 · 参数 · 反向　·　17 页
← → 翻页　·　O 概览　·　F 全屏

先把记号定死：形状对了，式子就跑不掉

全篇只用这一套记号。判断一个式子对不对，先看形状能不能拼上——这是最省事的检查方法，后面反向传播时尤其好用。
六个尺寸，全篇只有这六个
n这次输入有几个 token。每次都不一样，不属于模型
d模型宽度。训练前定死，例 4096
h注意力头数，例 32
d_k每个头的宽度，d_k = d / h，例 128
V词表大小，例 128000
N层数，例 32
只有 n 是「运行时」的
其余五个都是超参数，训完就刻死了。没有任何一个参数矩阵的形状里带 n——这就是同一个模型能吃任意长度输入的全部原因。
另外四个符号，后面反复出现
⊙ 逐元素相乘，两个同形矩阵对应位置相乘 ᵀ 转置 ‖ 横向拼接 1 全 1 的向量，用来把一个数广播成一整行
行向量约定：一行一个 token
X : n × d 第 i 行 = 第 i 个 token 的向量 W : d × k 参数矩阵，写在右边 Y = X W (n×d)(d×k) = n × k
教科书上常写 y = Wx（列向量）。这里一律用行向量、右乘，因为代码里张量的第一维就是序列，两边对得上，读实现时不用在脑子里转置。
梯度记号：一个字母顶一串偏导
对任意张量 T，记 dT ≡ ∂L / ∂T L 是一个标量（这一批的损失） ⇒ dT 永远和 T 形状完全相同
dX 是「损失对 X 的敏感度」，一个数一个数地对应。形状相同这条在后面每一页都会用来验算。

前向全景：从一串编号到一个数

一层的全部方程（Pre-LN，今天的标准写法）
U = LN(X) Q = U W_Q K = U W_K V = U W_V S = Q Kᵀ / √d_k + M A = softmax(S) O = A V X' = X + O W_O Z = LN(X') H = φ(Z W₁ + b₁) X'' = X' + H W₂ + b₂
是参数W_Q W_K W_V W_O W₁ b₁ W₂ b₂ γ¹β¹ γ²β²
是中间量U Q K V S A O X' Z H X''
参数存进模型文件；中间量算完就扔——但训练时得先留着，反向要用（第 16 页）。
这九行里，只有三处是「新东西」
第 3 行的 QKᵀ（位置之间打分）、第 3 行的 M（掩码）、以及把它们接成 A V。其余六行——LN、矩阵乘、φ、残差——是通用深度学习零件。
两个残差，把这一层切成两段
前六行是注意力子层，后三行是 FFN 子层。每段都是 x + f(LN(x)) 的形状——主干上那个 x 一路不被碰，子层只往上加东西。
X'' 和 X 同形，所以能一路叠上去
n × d 进，n × d 出。第 ℓ 层的 X'' 就是第 ℓ+1 层的 X。N 层用的是 N 组不同的参数，式子完全一样。
φ 和那个 4
φ 是逐元素激活，今天普遍用 GELU 或 SwiGLU。中间层宽度按惯例取 4d——W₁ : d × 4d，W₂ : 4d × d。这个 4 没有理论，是实验挑出来的。

注意力：一行公式，拆成五步

Attention(Q, K, V) = softmax( Q Kᵀ / √d_k + M ) V
五步，每步的形状
式子形状这一步在干什么
Q = U W_Q
K = U W_K
V = U W_V		n × d_k同一个 U 投三次。W 都是 d × d_k，三组互不相同的参数
S = Q Kᵀ / √d_kn × n每一对位置 (i, j) 算一个分数：S_ij = q_i · k_j / √d_k
S ← S + Mn × n把不许看的位置改成 −∞
A = softmax(S)n × n逐行做，每一行加起来正好是 1
O = A Vn × d_ko_i = Σ_j A_ij v_j，按权重把 V 的各行混起来
进来 n × d，中间胀成 n × n，出去又回到 n × d_k。整个 Transformer 里唯一按长度平方增长的东西，就是中间这个方阵。
为什么非得除 √d_k
设 q、k 各分量独立、零均值、方差 1，则
Var( q · k ) = Var( Σ q_t k_t ) = d_k 标准差 = √d_k d_k = 128 时约 11
分数散布在 ±11 这个量级，softmax 直接被推进饱和区（几乎是 one-hot），而它的雅可比 diag(a) − aaᵀ → 0，梯度全没了。除以 √d_k 把方差拉回 1。
M 为什么是「加 −∞」，不是「乘 0」
M_ij = 0 (j ≤ i) M_ij = −∞ (j > i)
必须在 softmax 之前加：exp(−∞) = 0，于是归一化时那些位置连分母都不参与，权重严格为 0。若在 softmax 之后乘 0，行和就不是 1 了。工程上用一个大负数（如 dtype 的最小值）代替 −∞。
A 不是对称矩阵
A_ij ≠ A_ji：i 听 j 的比例，和 j 听 i 的比例是两回事——分母不同（各自那一行）。加了因果掩码后，A 是下三角。

多头：把 d 维切成 h 份，各算各的，最后拌一次

式子与形状
head_i = Attention( U W_Q^i , U W_K^i , U W_V^i ) MHA(U) = [ head_1 ‖ head_2 ‖ … ‖ head_h ] W_O W_Q^i , W_K^i , W_V^i : d × d_k W_O : d × d
只有一个头W_Q 是 d × d参数 d²
拆成 h 个头W_Q^i 是 d × d_k，共 h 个h · d · (d/h) = d²
拆头不增不减参数量。W_Q W_K W_V W_O 各 d²，一层注意力一共 4d²。
实现里根本没有 h 个小矩阵
存的就是一个 d × d 的 W_Q。算出 U W_Q（n × d）之后 reshape 成 (n, h, d_k)，h 份注意力批量算完再拼回去。数学上的「h 个小矩阵」= 实现里一个大矩阵的 h 个纵列块。
W_O 不是可有可无的收尾
把 W_O 按行切成 h 个 d_k × d 的横条，则 [head₁‖…‖head_h] W_O = Σ_i head_i W_O⁽ⁱ⁾。没有它，第 i 个头的结果只会待在输出向量的第 i 段坐标上，永远进不了别的段。W_O 是各头之间唯一的通道。
为什么要拆
一个头只有一个 A，一个位置就只能有一种「听法」。拆成 h 个头就有 h 个不同的 A，同一次前向里同时表达多种关系。代价是每个头只剩 d_k = d/h 维可用——h 太大反而不够表达。
算力也没变
单头 d 维：QKᵀ 和 AV 各 2n²d，共 4n²d。h 个头：每头 4n²d_k，乘 h 还是 4n²d。多头是把同样的算力切开用，不是额外开销。

剩下的三个零件：LayerNorm、FFN、残差

这三个都不是 Transformer 发明的，是通用深度学习零件。但式子必须写清楚，因为反向传播时它们各有各的算法。
LayerNorm：沿 d 维做，一行一行地做
μ = (1/d) Σ_j x_j 这一行 d 个数的均值 σ² = (1/d) Σ_j ( x_j − μ )² x̂ = ( x − μ ) / √( σ² + ε ) 均值 0，方差 1 y = γ ⊙ x̂ + β γ, β ∈ R^d，是参数
x 是 X 的某一行。n × d 的矩阵有 n 组不同的 (μ, σ²)，但只有一组 (γ, β)——每行现算的统计量用完就扔，γ β 存进模型文件。
今天多数模型用的是 RMSNorm
y = γ ⊙ x / √( mean(x²) + ε )
不减均值，也不要 β。效果几乎一样，少一遍求和、少 d 个参数，反向的式子也短一截（第 12 页会看到减均值那一项有多贵）。
标准化之后，每行只剩 d−2 个自由度
x̂ 恒满足 Σ_j x̂_j = 0 和 Σ_j x̂_j² = d 两条约束，被锁在一个 d−2 维的球面上。第 12 页反向式子里那两个减项，就是这两条约束的直接后果——不是凑出来的。
FFN：每个位置各过各的，两层
H = φ( Z W₁ + b₁ ) W₁ : d × 4d → H : n × 4d FFN(Z) = H W₂ + b₂ W₂ : 4d × d → n × d
φ 是逐元素激活（GELU / SwiGLU）。中间宽度取 4d 是实验挑的，没有理论。参数量 d·4d + 4d·d = 8d²——比注意力的 4d² 还多一倍。
「逐位置」的意思是行与行完全隔离
FFN 对 Z 的每一行单独作用，第 i 行的输出只和第 i 行的输入有关。整个 Transformer 里跨位置搬信息的只有注意力一处，FFN 只负责在单个位置上做非线性加工。
残差：LN 摆在子层前面还是后面
Post-LN（原论文） X' = LN( X + F(X) ) Pre-LN （今天） X' = X + F( LN(X) )
Pre-LN 的主干上那个 X 一路不被任何东西碰过。前向看只是形状不变，真正的作用在反向（第 14 页）。

出口：从 n × d 变成一个损失值

Y = LN(X_N) W_U　　　P = softmax(Y)　　　L = − (1/n) Σ_i log P[ i , t_i ]
三步，每步的形状
式子形状说明
Y = LN(X_N) W_Un × VW_U 是 d × V。Y 叫 logits，可正可负、不归一
P = softmax(Y)n × V逐行做。第 i 行 = 第 i 个位置上「下一个词」的概率分布
L = −(1/n) Σ log P[i,t_i]标量每行只取正确答案那一格，取 log，加负号，再平均
t_i 是第 i 个位置上正确的下一个 token 编号。标签就是输入自己右移一位，不需要人来标。
一次前向拿到 n 个训练信号
因果掩码保证第 i 行只看得见前 i 个 token，所以 n 个位置的预测互不污染，可以同时算 n 个损失再平均。这就是 teacher forcing——训练时喂进去的一直是真答案，不是模型自己上一步猜的。
生成的时候只用最后一行
推理时前 n−1 行的 logits 全是白算，所以只拿 X_N 的最后一行乘 W_U（n × V 变成 1 × V），并把前面算过的 K、V 缓存下来。同一套式子，训练和推理的用法完全不同。
−log p 这个数怎么读
p = 1 → L = 0 完全猜对 p = 0.1 → L = 2.30 p → 0 → L → +∞ 猜错要付无穷大的代价
exp(L) 就是困惑度 PPL：模型平均在几个词之间犹豫。L = 2.3 ⇒ PPL ≈ 10。
softmax 必须先减掉每行最大值
softmax(y) = softmax( y − max_j y_j )
数学上完全相同，数值上不可少：e^y 在 y 稍大时就溢出成 inf。工程上还会把 softmax 和交叉熵合成一个算子（log_softmax + nll），连 P 都不显式算出来——既稳定，也因为它俩的联合导数干净得离谱（第 11 页）。
W_U 和词嵌入常常是同一个矩阵
weight tying：令 W_U = Eᵀ，入口出口共用一份权重。省下 V·d 个参数——7B 规模上是五亿多，不是小数目。

整张表里没有出现过 n
参数量和你喂多长的输入完全无关。会随 n 变的是激活（中间量），那是显存的另一笔账，第 16 页算。
O(d) 的项可以直接不算
每层的零头一共 9d ≈ 3.7 万，对着 2.01 亿，是万分之二。今天不少模型干脆把 b₁ b₂ 全去掉，再把 LayerNorm 换成只有 γ 的 RMSNorm——精度不掉，式子还更短。
KV cache 不在这张表里
推理时缓存的 K、V 是中间量，随对话长度线性长，占显存但不进模型文件。参数是「训完就不动的」，缓存是「这一次对话才有的」。

反向传播的机制：每个算子只回答两个问题

一个算子的反向，只有两问
前向 Y = f( X ; W ) 反向 已知 dY，求两样东西： dX = ? ← 往回传，成为上一个算子的 dY dW = ? ← 交给优化器，这一步就结束了
整个反向传播就是把这两问沿着链倒着问一遍。起点是 dL/dL = 1，终点是所有的 dW。中间量的梯度用完即弃。
梯度在汇合处要相加，不是覆盖
一个张量被下游用了几次，它的梯度就是几条路径之和：残差里的 X 走了两条路，注意力里的 U 同时喂给了 Q、K、V 三条路。实现上对应 += 而不是 =。
为什么不直接写雅可比矩阵
X 是 n × d、Y 是 n × k，那么 ∂Y/∂X 是一个 nk × nd 的矩阵。n = 2048、d = 4096 时它有 10¹⁴ 个元素——存不下，也算不动。但我们要的从来不是这个矩阵，只是它和 dY 的一次乘积。每个算子直接给出这个乘积的闭式，雅可比自始至终没被构造出来。
形状是最好用的验算工具
dT 永远和 T 同形。写完一个反向式子，先数形状：对不上就一定错了。下一页会看到，矩阵乘的反向压根不用背——只有一种拼法能拼上。
反向的工作量大约是前向的两倍
前向每个矩阵乘只算一个乘积；反向要算 dX 和 dW 两个。所以「一次训练 ≈ 三次前向」，第 16 页的 6PD 就是从这条来的。

零件的反向 ①：矩阵乘、偏置、逐元素、残差

算子前向回传给输入参数梯度
矩阵乘Y = X WdX = dY WᵀdW = Xᵀ dY
加偏置Y = X + 1 bᵀdX = dYdb = 1ᵀ dY　按列求和
逐元素激活Y = φ(X)dX = dY ⊙ φ′(X)无参数
残差相加Y = X + FdX = dY　　dF = dY无参数
数乘Y = c XdX = c · dYc 是常数
转置Y = XᵀdX = dYᵀ—
拼接Y = [ A ‖ B ]dA、dB = dY 对应的列块切开就行
矩阵乘的反向不用背：只有一种拼法能拼上
Y = X W X : n×d W : d×k Y : n×k dX = dY Wᵀ (n×k)(k×d) = n×d ✓ 和 X 同形 dW = Xᵀ dY (d×n)(n×k) = d×k ✓ 和 W 同形
手上只有 dY、X、W 三个东西，形状一约束，两个式子就唯一确定了。转置摆哪、谁乘谁，全都不用记。
dW = Xᵀ dY 里出现了前向的 X
所以每一层的输入都必须留在显存里，等着反向来取。这就是训练比推理吃显存的根本原因——推理算完一层就能把中间量扔掉，训练不行（第 16 页）。
残差那一行是全表最重要的一行
dX = dY：一个字都没改，原样透传。不管 F 那一支里的梯度衰减成什么样，主干上这一条恒等通路始终把 dY 完整送到上一层。第 14 页会看到这条为什么决定了深网络能不能训。

零件的反向 ②：softmax 的两副面孔

接了交叉熵的那个：中间全约掉了
看一行：y ∈ R^V，p = softmax(y)，正确答案是第 t 格 L = − log p_t = − y_t + log Σ_j e^{y_j} ∂L/∂y_j = − 1[j=t] + e^{y_j} / Σ_k e^{y_k} ∂L/∂y_j = p_j − 1[j=t] 整个矩阵： dY = ( P − T ) / n T 是 one-hot 标签矩阵
「猜的分布 减去 正确答案」。exp、log、除以分母全部消掉，反向的起手式就是一次减法。除以 n 是因为 L 对 n 个位置取了平均。
框架把这两步合成一个算子
既为数值稳定（不显式算 P），也为了直接吐出 P − T。如果你把 softmax 和交叉熵分开写，这个约分就发生不了，得走完整的雅可比，又慢又容易溢出。
注意力里的那个：后面没有交叉熵，约不掉
看一行：a = softmax(s) ∂a_i/∂s_j = a_i ( δ_ij − a_j ) J = diag(a) − a aᵀ 这才是真雅可比 ds = J da = a ⊙ ( da − (aᵀ da) 1 ) 整个矩阵： dS = A ⊙ ( dA − rowsum(A ⊙ dA) 1ᵀ )
形式上还是「减去一个按行的加权平均」，但这里的权就是 A 自己。被掩码盖住的位置上 A = 0，dS 自动也是 0，反向不用再补一次掩码。
J → 0 就是第 4 页那个坑
当 a 接近 one-hot 时，diag(a) − aaᵀ 整体趋于零矩阵，dS 也就趋于零——这一层学不动了。除以 √d_k 把分数的方差压回 1，就是为了让 a 别那么早变尖。前向的那个常数，理由完全在反向这一侧。
同一个算子，为什么两边的反向式子差这么远
∂L/∂p = −1/p_t · e_t × ∂p/∂y = diag(p) − p pᵀ ⇒ −1/p_t · ( p_t e_t − p_t p ) = p − e_t
不是 softmax 变了，是它后面接的东西变了：交叉熵求导给出的 1/p_t 正好约掉雅可比里的 p_t；注意力后面接的是 A V，没东西可约，只能老实过 J。反向式子取决于整条下游路径，不只取决于算子本身。

零件的反向 ③：LayerNorm 的三项

对某一行 x ∈ R^d，前向与反向
前向 σ = √( σ² + ε ) x̂ = ( x − μ ) / σ y = γ ⊙ x̂ + β 参数（把 n 行全加起来，各得一个 d 维向量） dγ = Σ_行 ( dy ⊙ x̂ ) dβ = Σ_行 dy 输入（先剥掉 γ：令 g = dy ⊙ γ） dx = (1/σ) [ g − mean(g) − x̂ ⊙ mean( g ⊙ x̂ ) ]
三项各有出处：动一下 x 的某个分量，橙色那项是它直接改变自己的输出；紫色两项是因为它同时改变了整行的 μ 和 σ，从而牵动这一行的其它 d−1 个分量。
RMSNorm 少的正是中间那一项
不减均值 ⇒ 没有 mean(g) 这一项，也没有 dβ。少一遍全行求和、少一个参数向量，反向短了整整三分之一——这就是它今天更常见的实际理由。
dx 天生正交于两个方向
Σ_j dx_j = 0 对「整行一起加个数」不敏感 Σ_j dx_j x̂_j = 0 对「整行一起放大」不敏感
这两条是恒等式，不是近似。LayerNorm 把「整体平移」和「整体缩放」这两个方向的梯度彻底滤掉了——上一层再怎么把输出整体拉大拉小，都传不出信号，尺度漂移就此止步。第 6 页说的 d−2 个自由度，在这里兑现。
反向要用到 x̂ 和 σ
所以前向必须把它们存下来（或只存 x，反向时现推一遍，用时间换显存）。这是所有归一化层共同的代价。
γ、β 的梯度是「全批次一起攒」
dW 类的梯度都要沿 batch 和序列两个维度求和：n × d 的 dy 压成一个 d 维向量。所以 γ 收到的梯度比任何单个位置都稳，参数少的层反而不容易训崩。
最常见的错法：把 μ、σ 当成常数
错 dx = g / σ 相当于假装 μ、σ 和 x 没关系 对 dx = (1/σ) [ g − mean(g) − x̂ ⊙ mean( g ⊙ x̂ ) ]
写成上面那行，LN 就退化成一个固定的仿射变换，前面那两条正交性质全部失效。代码照样能跑、损失照样会降，但归一化真正的作用没了——它的全部价值恰恰来自被减掉的这两项。

注意力的反向：把五步倒着走一遍

　前向这一步反向对应的式子（从 dO 出发，一路往上）
⑤O = A VdV = Aᵀ dO　　　　dA = dO Vᵀ
④A = softmax(S)dS = A ⊙ ( dA − rowsum(A ⊙ dA) 1ᵀ )　上一页那个
③S ← S + MM 是常数，dS 原样穿过；被盖住的位置 A = 0，dS 自动也是 0
②S = Q Kᵀ / √d_kdQ = dS K / √d_k　　dK = dSᵀ Q / √d_k
①Q = U W_Q（K、V 同理）dW_Q = Uᵀ dQ　　dU += dQ W_Qᵀ + dK W_Kᵀ + dV W_Vᵀ
还是靠形状认式子
A : n×n V : n×d_k O : n×d_k S : n×n dV = Aᵀ dO (n×n)(n×d_k) = n×d_k ✓ dA = dO Vᵀ (n×d_k)(d_k×n) = n×n ✓ dQ = dS K (n×n)(n×d_k) = n×d_k ✓ dK = dSᵀ Q (n×n)(n×d_k) = n×d_k ✓
注意 dK 要转置：S 的第 (i,j) 格由 q_i 和 k_j 共同决定，所以 K 的梯度要沿列汇总，而 Q 沿行。
dU 是三条路加起来的
U 被同时喂给了 Q、K、V 三个投影，是典型的汇合点。三份都要加，漏一份不会报错，只会训练得莫名其妙地差——这类 bug 最难查。
反向要用到 A，而 A 是 n × n 的
n = 8192 时，一层一个头的 A 就有 6700 万个数。FlashAttention 干脆不存 A，只留归一化常数，反向时分块重算。
h 个头之间彼此无关
上面这五步对每个头各做一遍，互不影响，天然可以批量并行。梯度直到 dU 和 dW_O 那一步才汇到一起。
整页其实只用到两条规则
矩阵乘 dX = dY Wᵀ ， dW = Xᵀ dY　　　　softmax dS = A ⊙ ( dA − rowsum(A ⊙ dA) 1ᵀ )
五步里四步都是第一条的反复套用。注意力的反向没有任何新机制——它看着复杂，只是因为一个前向式子里塞了五个算子。

一层串起来，以及残差为什么决定成败

一层的反向，完整顺序（已知 dX''）
── FFN 子层 ────────────────────────── dX' += dX'' 残差直通 dH = dX'' W₂ᵀ dW₂ = Hᵀ dX'' db₂ = 1ᵀ dX'' dR = dH ⊙ φ′(Z W₁ + b₁) dZ = dR W₁ᵀ dW₁ = Zᵀ dR db₁ = 1ᵀ dR dX' += LN_back( dZ ) 汇合，第二条路 ── 注意力子层 ──────────────────────── dX += dX' 残差直通 dO = dX' W_Oᵀ dW_O = Oᵀ dX' （上一页的五步，拿到 dU 和 dW_Q dW_K dW_V） dX += LN_back( dU ) 汇合，第二条路
dX 交给上一层当 dX''，循环 N 次。绿色两行是恒等直通，橙色两行是子层绕出去又绕回来的那一支——每个残差点上，梯度都是这两支相加。
残差在反向里到底做了什么
有残差 X' = X + F(X) ⇒ dX = dX' ( I + J_F ) 没残差 X' = F(X) ⇒ dX = dX' J_F 叠 N 层： 有 ∏ ( I + J_ℓ ) = I + Σ J_ℓ + … 恒有一条通路 无 ∏ J_ℓ ‖J‖<1 就 N 次方衰减
‖J‖ = 0.9、N = 32 时，0.9³² ≈ 0.034——最前面几层收到的梯度只剩三十分之一。有了那个 I，乘积里永远保留一条不衰减的路，第 1 层和第 32 层拿到的梯度在同一个量级。
这就是「深」能成立的全部技术前提
1000 层的网络也照训。深度学习的「深」不是想深就能深，是 2015 年残差把这条路打通之后才成立的。Transformer 只是恰好站在了这个结论上。
前向存了什么，反向就得取什么
X U Q K V A O X' Z H ＋每个 LN 的 x̂ 和 σ
上面每一个反向式子右边出现过的前向量，都要在显存里等着。这一整串乘以 N 层再乘以 batch，就是训练的激活显存账（第 16 页）。
怎么确认自己的反向没写错
∂L/∂w ≈ ( L(w+ε) − L(w−ε) ) / 2ε ε = 1e−4，用 float64
挑几个参数，用数值差分和解析梯度对一下，相对误差应当在 1e−6 量级。这是唯一靠谱的验证手段——反向写错了通常不会报错，只会让模型学得莫名其妙地差。

有了梯度之后：Adam 的六行

每一步对每个参数逐元素做
g = dW 这一批算出来的梯度 m ← β₁ m + (1−β₁) g 一阶矩：方向的滑动平均 v ← β₂ v + (1−β₂) g² 二阶矩：幅度的滑动平均 m̂ = m / (1 − β₁ᵗ) 偏差修正，t 是第几步 v̂ = v / (1 − β₂ᵗ) W ← W − η · m̂ / ( √v̂ + ε )
m 和 v 都和 W 同形，是训练过程中额外维护的状态。整个循环就是：前向算 L → 反向算 dW → 这六行更新 W → 换下一批数据重来。
分母 √v̂ 才是 Adam 的关键
m̂ / √v̂ 是把梯度按自己的历史幅度归一化：一个参数梯度一直很大，它的步子反而被压小；一直很小的，步子被放大。等于给每个参数配了一份自己的学习率——纯 SGD 里所有参数共用一个 η，稀疏的方向根本学不动。
偏差修正是为了开头那几步
m 和 v 都从 0 出发，前几步严重偏小。1 − β₁ᵗ 在 t = 1 时是 0.1，把 m 放大十倍拉回正常量级；t 大了以后这个因子趋于 1，自动失效。
weight decay 不能加进 g
错 g ← g + λW 会被 √v̂ 除掉，衰减失真 对 W ← W − η( m̂/(√v̂+ε) + λW )
这就是 Adam 和 AdamW 的全部区别。今天训大模型一律用后者。
配套的两件事
梯度裁剪：更新前把 ‖g‖ 截到某个上限（常取 1.0），挡住偶发的爆炸批次。
学习率日程：先 warmup 线性升上去，再按 cosine 降下来。开头 m、v 还没攒够统计量，直接上大 η 容易崩。
实际用的数字
β₁ 0.9　β₂ 0.95　ε 1e-8
峰值 η 约 3e-4，裁剪 1.0，衰减 0.1。
β₂ 为什么从 0.999 调到 0.95
0.999 的等效窗口约 1000 步，梯度分布变得快时跟不上；0.95 约 20 步。代价是 v 更抖。
这已经是最便宜的二阶了
牛顿法要 Hessian，7B 下是 4.9e19 个数，存不下。√v̂ 只取对角线，一份 P 就够。

两笔账：要多少算力，要多少显存

算力：为什么是 6 × 参数量 × token 数
每个参数在每个 token 上：一次乘、一次加 前向 = 2 P FLOPs / token 反向 dX 一次、dW 一次 = 4 P FLOPs / token ────────────────────────────── C ≈ 6 · P · D P 参数量，D 训练 token 总数
7B × 2T token6 × 7e9 × 2e12 = 8.4e22 FLOPs
1024 张 H100≈ 4e14 FLOPS / 卡（约 40% 利用率）
大约要跑8.4e22 / 4.1e17 ≈ 2.4 天
这个式子只数了参数矩阵乘。注意力那部分是额外的，见下面。
显存：参数只是四分之一
参数 W P 梯度 dW P Adam 的 m P Adam 的 v P ────────────────── 共 4P，fp32 下 = 16 字节 / 参数 7B ⇒ 约 112 GB，一张 80G 卡放不下
这还没算激活。第 14 页那一串前向中间量要全部留着等反向，量级是 batch × n × d × N × 常数——它才是训练时真正吃显存的大头，而且随序列长度线性涨。
注意力什么时候才变成瓶颈
注意力 / 参数 = 4Nnd / 24Nd² = n / 6d
d = 4096 时要 n > 24576 注意力才追平参数矩阵乘。普通长度下它根本不是算力大头——但它是显存大头，因为 A 是 n × n。
梯度检查点：拿时间换显存
只保留每层的输入，层内的中间量全扔；反向到这一层时再前向重算一遍。激活显存从 O(N) 降到 O(1)（分段做则是 O(√N)），代价是多一次前向，6PD → 8PD。
推理便宜在哪
没有反向，2P FLOPs / token，是训练的三分之一；不用存梯度和优化器状态，也不用留激活。代价是要维护 KV cache——那是随对话长度线性增长的另一笔账。
反过来用：模型该做多大，是这两笔账解出来的
计算最优的经验规律是 D ≈ 20P，代回 C = 6PD = 120P²，得 P = √(C/120)。1024 卡跑 30 天 ⇒ C ≈ 1.1e24 ⇒ P ≈ 94B、D ≈ 1.9T。参数量不是拍脑袋定的。
