机器学习是什么：一个定义，四类任务

定义（Tom Mitchell, 1997）
一个程序在任务 T 上，以度量 P 衡量的表现，随着经验 E 的积累而提高，就说它从 E 中学到了关于 T 的东西。
这个定义的价值在于：它把「学习」变成了三个必须先说清楚的量。任何一个真实项目卡住，多半是 T、P、E 里有一个没定义好 —— 尤其是 P。
和传统编程的分工
　人提供机器产出
传统编程规则 + 输入输出
机器学习输入 + 期望输出规则（模型参数）
所以机器学习适用的场景是：你知道对错，但写不出规则。能写出规则的（税率计算、排序、编译）不要用机器学习。
这些名词的包含关系
人工智能 ⊃ 机器学习 ⊃ 表示学习 ⊃ 深度学习 ⊃ 大模型。机器学习是人工智能里「靠数据获得能力」的那一支；深度学习是机器学习里「用多层神经网络自动学出特征」的那一支；大模型则是深度学习里以 Transformer 为骨架、以自监督预训练为方法的那一支。
另外两个常一起出现的词：统计学习基本是机器学习的同义词，只是更强调数学基础；数据挖掘侧重从大数据里找有价值的模式，方法上大量借用机器学习，但目标是发现知识，不是造一个能预测的模型。
四类任务：按「监督信号从哪儿来」分
类型给机器的数据要它学出什么
监督学习(x, y) 成对，y 由人标映射 x→y。分类（y 离散）与回归（y 连续）
无监督学习只有 x数据自身的结构：聚类、降维、密度估计
自监督学习只有 x，但从 x 里造出 y遮住一部分去预测它。今天所有大模型都出自这一类
强化学习环境 + 奖励信号策略：什么状态下做什么动作，使长期回报最大
自监督为什么单列
形式上它是监督学习（有 x 有 y，用同一套损失和优化器），但 y 不花人力 —— 「预测下一个词」的答案就写在原文里。标注量不再是瓶颈，数据规模因此可以放大四五个数量级。这一条是大模型能出现的直接前提，第 40 页会完整展开。

任何一个学习算法，都由三件东西唯一确定

这是李航《统计学习方法》给出的拆法，通用性极强：模型 + 策略 + 算法。看到任何一个陌生方法，先把它这三格填出来，就不会晕。
① 模型 — 假设空间 H
候选答案的集合。你先规定「答案长什么样」：
· 一条直线 y = wᵀx + b
· 一棵深度 ≤ 5 的决策树
· 一个 32 层的 Transformer
H 越大，能表达的规律越多，但也越容易把噪声当规律。这个大小有个正式的度量，见第 14 页。
② 策略 — 拿什么衡量好坏
损失函数 L(y, f(x))：单个样本错了多少。
经验风险：训练集上损失的平均。
结构风险 = 经验风险 + λ·Ω(f)，后一项是正则化，惩罚复杂模型。
真正想最小化的是期望风险（全分布上的期望损失），但它算不出来 —— 整门学科的技术含量都在这道缝里。
③ 算法 — 怎么找到那个最优解
在 H 里搜使风险最小的那个 f：
· 解析解：直接求导置零（线性回归）
· 凸优化：有全局最优保证（SVM、逻辑回归）
· 梯度下降：只能找到局部最优（神经网络，第 20 页）
· 贪心搜索：每步选最优切分（决策树）
常见损失函数速查
损失形式用在哪
平方损失(y − ŷ)²回归；对应高斯噪声假设，怕离群点
绝对值 / Huber|y − ŷ| / 分段回归；对离群点稳健
交叉熵−Σ y log ŷ分类的默认选择，含所有语言模型
合页损失max(0, 1 − y·ŷ)SVM；只惩罚「不够有把握」的那些点
损失函数不是评分标准，是你的分布假设
从最大似然的角度看：假设噪声是高斯的，最大化似然就等价于最小化平方损失；假设输出服从多项分布，最大化似然就等价于最小化交叉熵。
所以「选哪个损失」实质是「你认为数据是怎么生成的」。选错损失比选错模型更致命 —— 它悄悄改掉了你在优化的目标。

参数就是知识：训练在调它，推理不动它

上一页的「模型」是一个假设空间，一组具体的参数值就是空间里的一个点。学习从头到尾只做一件事：把这个点挪到该在的位置。

参数（权重）训练过程自己定每步都变，练完固定w、b；后面会看到的 W_Q、W_K、W_V、γ、β、Embedding 表

「模型有多大」说的是第一行
一个模型标称多少参数，数的就是第一行那些数字一共有多少个。超参数只有几十个，中间结果根本不存盘，两者都不计入。
所以「70 亿参数」= 训练结束时被冻住、写进文件里的 70 亿个浮点数。模型文件大小 ≈ 参数个数 × 每个数占的字节数；第 36 页会把一个 8B 模型逐项拆开数一遍。

归纳偏置与「没有免费的午餐」

追问一句：在训练集上全对的候选函数有几个？—— 不是一个，是无穷多个。数据只约束了见过的那些点，点与点之间怎么走，样本一个字也没说。那么凭什么挑？
归纳偏置 inductive bias
学习算法在「同样能解释数据的多个假设」之间做取舍时，所依据的那些不来自数据的假定。

它不是缺陷，是学习成为可能的前提 —— 没有它，「学习」这个动作在数学上无法定义。
没有免费的午餐定理（Wolpert, 1996）
在所有可能的目标函数上取平均，任意两个学习算法的期望表现完全相同 —— 包括「瞎猜」。
口径要看清：前提是「所有目标函数等可能」。真实世界显然不是这样（世界是平滑的、有局部性的、有层次结构的）。所以这条定理的正确用法不是「算法都一样」，而是：你的算法之所以有效，一定是因为它内建的偏好恰好和这个世界的规律对上了。

误差从哪儿来：偏差-方差分解

泛化误差可以拆成三块
E(f;D) = bias²(x) + var(x) + ε²
偏差 bias　模型的期望预测与真实值的差 —— 学习算法本身的拟合能力不够。
方差 var　换一批同样大小的训练数据，预测结果的抖动 —— 对数据扰动太敏感。
噪声 ε　任何模型都到不了的下限，由问题本身决定。
实践中怎么看出来
学习曲线　一张图上画训练误差与验证误差两条线。都高且紧贴 → 偏差主导；训练低、验证高、中间一道大缝 → 方差主导，缝会随数据量增加收窄。
k 折交叉验证　训练集切 k 份（常取 5 或 10），轮流留一份验证取平均，数据不多时比单次留出稳得多，也是选超参数的标准做法。代价是训 k 遍。
这套框架的实用价值：诊断和对症下药
症状诊断该做什么
训练误差就很高偏差主导换更大的模型、加特征、训久一点、降低正则强度
训练很低、验证很高方差主导加数据（最有效）、加正则、Dropout、早停、集成
两者都低但线上崩分布偏移不是偏差方差问题 —— 是训练分布 ≠ 线上分布
模型容量增大 → 偏差降、方差升。传统的做法是在两者之间找平衡点，这就是那条经典的 U 型曲线。
重要：这条 U 型曲线在深度学习区间不成立
当模型大到足以完全插值训练集（训练误差压到 0）之后再继续变大，测试误差会先升后降，出现第二个下降段 —— 这叫双下降（Belkin et al., 2019）。
今天所有的大模型都工作在这条曲线的第二段。也就是说：「参数多于样本 = 必然过拟合」这个直觉，在这里是错的。细节见第 23 页。
三个容易混用的词
损失 vs 误差　损失是在一批样本上算出来、用来求梯度的那个数；误差指在整个数据集上的整体表现。优化的是损失，关心的是误差。
泛化误差 vs 测试误差　前者是理论量（对真实分布的期望，算不出来），后者是它的一个估计值 —— 测试集越小越不可信。
分解的适用范围　上面那个等式严格成立于平方损失；分类任务下有多个推广版本，形式不唯一，但方向一致。

一条今天仍然成立的事实
在结构化表格数据上，梯度提升树至今常常仍强于神经网络，还快得多。这类特征本就是人挑好的、语义明确、维度不高，深度学习「自动学表示」的优势用不上，代价一样不少。先跑一个 XGBoost 当基线。

方法目标 / 用途

PAC 学习框架（Valiant, 1984）与 VC 维
Probably Approximately Correct：以至少 1−δ 的概率，学到一个误差不超过 ε 的模型。两个「不完美」都是必须的——样本是随机抽的，只能大概率对；样本是有限的，只能近似对。
VC 维＝假设空间能打散的最大样本数（无论标记怎么排列都能全分对）。二维平面上的直线 VC 维 = 3。VC 维越大越有表达力，也越容易过拟合。
泛化误差 ≤ 训练误差 + O( √( (VC维 + log(1/δ)) / m ) )
右边第二项是你为模型复杂度付的税：样本量 m 越大税越低（加数据永远有用），模型容量越大税越高。这就是「模型复杂度和样本量要匹配」的严格版本。
诚实的边界：这套理论解释不了深度学习
上千亿参数的网络，VC 维大到让这个界完全空洞（右边远大于 1，等于什么都没说），但它实际泛化得很好。
Zhang et al. (2017)：把标签完全打乱成随机，同一个网络照样训到训练集 100% 正确——容量确实足以记住一切；换成真标签又能正常泛化。
泛化不能只由「模型有多大」解释，还取决于数据结构、优化算法的隐式偏好。这仍是开放问题——第 23 页会把这条线接下去。
维度灾难：为什么非降维不可
维度一高，样本变得极端稀疏（保持同样采样密度，样本量需随维度指数增长），且距离失去区分度（最近点与最远点趋于等距，kNN、k-means 一起失效）。「特征越多越好」是错的。

三个必须分清的概念
概念是什么
前向传播把输入按上面那行公式一层层算到输出，得到预测值 ŷ。推理时只做这一步。
深度 / 宽度深度 = 层数 L；宽度 = 每层神经元个数。同样的参数量，深比宽更有效（见下）
参数量Σ (本层宽 × 上层宽 + 本层宽)。这是「多少亿参数」这个数字的来源
万能逼近定理（Cybenko 1989 / Hornik 1991）
只要有一个隐藏层，神经元足够多，前馈网络就能以任意精度逼近任何连续函数。
但这个定理几乎没有实用价值，因为它三件事都没说：需要多少个神经元（可能指数多）、怎么找到那组权重、找到之后泛化好不好。
它只保证了「表达力不是瓶颈」。真正的瓶颈从来是优化和泛化。
那为什么要「深」
因为世界本身是组合式的：像素 → 边缘 → 纹理 → 部件 → 物体。深度让网络复用中间结果 —— 浅而宽要把每种组合单独记一遍，深而窄可以搭积木。同样的表达力，深度网络所需的神经元数可以少指数级。

激活函数：没有它，一百层等于一层

去掉 σ，每层就只是一次线性变换。而线性套线性还是线性 —— W₃(W₂(W₁x)) = (W₃W₂W₁)x，一百层能被一个矩阵完全替代。非线性是「深度」这件事存在的唯一理由。
函数形式性质今天用在哪
Sigmoid1/(1+e⁻ˣ)输出压到 (0,1)；两端梯度趋近 0 → 梯度消失；输出非零中心只用在二分类输出层和门控里，不再做隐藏层激活
Tanh(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)输出 (−1,1)，零中心；仍有梯度消失LSTM 内部；RNN 时代的主力
ReLUmax(0, x)正半轴梯度恒为 1 → 彻底缓解梯度消失；算得极快；带来稀疏性。缺点：负半轴梯度为 0，神经元可能永久死亡CNN 与绝大多数网络的默认选择。AlexNet 靠它把训练加速约 6 倍
Leaky ReLU / PReLUmax(αx, x)给负半轴留一点斜率，治「死亡 ReLU」需要时替换 ReLU，代价为零
GELUx·Φ(x)ReLU 的平滑版，负值区不硬截断，梯度更稳BERT / GPT 系列的默认激活
SwiGLU(xW₁ ⊗ swish(xW₂))W₃门控结构：一路当内容，一路当开关。多一个矩阵，通常把中间维度调小以保住算量2026 年主流大模型 FFN 的标准选择（Llama、Qwen、DeepSeek）
Softmaxeˣⁱ/Σeˣʲ把一组实数变成和为 1 的概率分布。不是隐藏层激活多分类输出层；注意力里的权重归一化
怎么选
隐藏层：不知道选什么就用 ReLU，训 Transformer 用 GELU 或 SwiGLU。输出层由任务决定：回归不加激活、二分类 Sigmoid、多分类 Softmax，且必须和损失函数配对（下一页）。

输出层与损失，必须成对出现

三种任务的标准配法
任务输出层损失
回归不加激活，直接输出实数MSE（或 Huber）
二分类1 个单元 + Sigmoid二元交叉熵 BCE
多分类K 个单元 + Softmax交叉熵 CE
配错会怎样：Sigmoid + MSE 时，输出饱和区的梯度里会多出一个趋近 0 的 σ′ 因子，错得越离谱梯度反而越小，训练卡死。换成交叉熵，这个因子刚好被约掉，梯度正比于 (ŷ − y) —— 错多少，就推多大力。
语言模型是一次巨大的多分类
「预测下一个词」= 在整个词表（约 10 万个 token）上做一次 10 万类分类。
输出层给出 10 万个分数（logits）→ Softmax 变成概率 → 与真实的下一个 token 算交叉熵。
所以整个大模型的训练目标，写出来就是一行交叉熵。没有第二个损失函数。
交叉熵到底在算什么
L = − Σ y_i · log(ŷ_i)
y 是one-hot 的（正确类别为 1，其余为 0），所以这个求和实际上只剩一项：
L = − log(模型给正确答案的概率)。

模型给正确答案 0.9 → 损失 0.105；给 0.1 → 损失 2.30；给 0.001 → 损失 6.91。越自信地答错，罚得越狠，而且是无上界的。
顺带记住两个由此而来的量
困惑度 PPL= e^(平均交叉熵)。直观含义：模型在每一步平均在多少个候选之间犹豫。PPL=1 表示完全确定，PPL=100 表示相当于在 100 个词里瞎猜。语言模型的经典指标
logitsSoftmax 之前的原始分数。采样温度、top-k、top-p 都作用在这一层上（第 43 页）
一句话串起来
你在新闻里看到的 loss 曲线往下掉，掉的就是这个「−log 正确答案的概率」的平均值。它从 ln(100000)≈11.5（完全随机）一路降到 1.5–2 左右。

反向传播：名字唬人，其实是链式法则加一本账

要解决的问题
损失 L 是一个数。网络里有 N 个参数。想知道每个参数该往哪个方向调、调多少，就要求出 N 个偏导 ∂L/∂wᵢ。
笨办法：把每个参数动一点点，各跑一次前向看 L 变多少 —— 要跑 N 次前向。N = 80 亿时这条路完全不通。
反向传播的做法
利用链式法则，从输出往回走一遍，就把全部 N 个偏导一次算齐。
代价：约等于一次前向的两倍。与参数量 N 无关 —— 这是深度学习在计算上可行的根本原因。
1986 年 Rumelhart、Hinton、Williams 的论文让它进入主流。
「账」指的是什么
反向要用到前向的中间结果，所以必须把每一层的激活值存下来。这就是训练时显存被吃掉的大头（第 41 页会算这笔账），也是「梯度检查点」这类技术要省的东西。
拆开看：一条链上发生了什么
前向： x ──W₁──▸ z₁ ──σ──▸ a₁ ──W₂──▸ z₂ ──σ──▸ ŷ ──▸ L 反向： ∂L/∂ŷ ∂L/∂z₂ = ∂L/∂ŷ · σ′(z₂) ∂L/∂W₂ = ∂L/∂z₂ · a₁ᵀ ← 要用到前向存的 a₁ ∂L/∂a₁ = W₂ᵀ · ∂L/∂z₂ ← 误差继续往回传 ∂L/∂z₁ = ∂L/∂a₁ · σ′(z₁) ∂L/∂W₁ = ∂L/∂z₁ · xᵀ
看这个结构：每往回一层，就乘一次 Wᵀ、再乘一次 σ′。全部规律都藏在这句话里 ——
· σ′ 长期小于 1（Sigmoid 最大只有 0.25）→ 连乘 L 次后趋近 0 → 梯度消失
· 权重初始化偏大 → 连乘放大 → 梯度爆炸
0.950 ≈ 0.005（消失）　　1.150 ≈ 117（爆炸）
这就是为什么 1986 年就有的算法，要等到 2012 年前后才真正训得动几十层的网络。解药在下一页。

解药 ① 初始化：让每层输出的方差保持一致
Xavier / Glorot（配 tanh、sigmoid）与 He / Kaiming（配 ReLU，因为 ReLU 砍掉一半信号，方差要乘 2 补回来）。
这两个初始化把「连乘因子」尽量摆到 1 附近。全零初始化是错的 —— 所有神经元会完全对称，永远学到同一个东西。
解药 ② 梯度裁剪
梯度范数超过阈值就等比缩回去。治爆炸最直接，几乎零成本。大模型训练里是标配，常设 1.0。
解药 ③ 归一化：把每层的输入重新拉回稳定区间
方法沿哪个方向统计用在哪
BatchNorm同一批样本里，对每个特征做归一CNN。依赖 batch 大小，训练/推理行为不同
LayerNorm单个样本内，对该层所有维度做归一Transformer。与 batch 无关，适合变长序列
RMSNorm同 LayerNorm，但省掉减均值，只除以均方根2026 主流大模型的默认，更快且相当
归一化不止让训练稳，还让网络对学习率不那么敏感 —— 可以开更大的学习率。
解药 ④ 残差连接：一行加法解决退化
y = x + F(x)
让每一层去学「要在输入上改动什么」，而不是「输出应该是什么」。
· 不需要改时把 F 压到 0 即可 —— 深网络至少不会比浅网络差，退化消失。
· 反向时多了一条恒等的梯度高速通道（∂y/∂x = 1 + ∂F/∂x），不受连乘衰减。
ResNet（2015）用它把网络从 20 层解锁到 1000 层以上。今天几乎没有一个深网络不用残差，包括每一个 Transformer block。

有了梯度往哪走，以及怎么不让它跑偏

优化器：有了梯度，往哪走、走多远
w ← w − η · ∂L/∂w
η 是学习率。梯度是「上升最快的方向」，取负号就是下降最快的方向。像浓雾里下山：摸脚下的坡度，朝最陡的方向迈一步，再重新摸。
优化器加了什么解决什么
SGD—基线，收敛慢
Momentum累积历史梯度的惯性抑制震荡
RMSProp按梯度平方的滑动平均缩放 η自适应步长
Adam上面两个合体又快又稳
AdamW权重衰减从梯度里拆出来单独做训大模型的默认
代价：Adam / AdamW 要为每个参数多存一阶矩、二阶矩两个状态，占的显存是参数本身的两倍，是训练显存账里最大的一项。
η 是最重要的一个超参数，而且它不是常数
太大：来回弹跳甚至发散（loss 震荡或变 NaN → 调小）。太小：慢到训不完。
warmup + cosine 是大模型训练的标准配方：开头几百到几千步让 η 从 0 升上去（此时参数还是随机的，梯度方向极不可靠），后期再衰减下来精修。
正则化：五种手段，同一件事——用一点训练误差换泛化误差
手段具体做法为什么有用
L2 / 权重衰减损失里加 λ‖w‖²，逼参数变小参数小 → 函数更平滑 → 对扰动不敏感
L1损失里加 λ‖w‖₁把部分权重压到恰好 0，自动选特征
Dropout训练时随机让部分神经元临时失效（p=0.1–0.5），推理时必须关掉逼网络不依赖任何单个神经元，近似免费集成了一堆子网络
数据增广做保持标签不变的变换：图像翻转裁剪、文本回译同义替换把「什么变化不该影响结果」这条先验直接教给模型
早停验证误差连续 n 轮不再下降就停在模型开始记噪声之前叫停，零成本
最强的「正则化」其实不在这张表里
是加数据。所有正则化手段都是数据不够时的补救，数据够多时收益迅速变小——这也是为什么大模型预训练几乎不用 Dropout。
另外：BatchNorm / LayerNorm 不是正则化，它们是为了让训练稳定和加速（上一页那四味解药之一）。

CNN 与 RNN：两套写进结构里的先验，和它们的极限

这两类最该记的不是细节，是把领域先验写进网络结构这个做法——Transformer 继承了它，只换了一套先验。
CNN：三条内建假设，就是它的归纳偏置
假设机制带来的好处
局部性每个神经元只连接输入的一小块（3×3、5×5）参数量大幅下降
平移不变权重共享：同一个卷积核扫过全图猫在左上还是右下，用同一套检测器
层次组合层层堆叠，感受野递增边缘 → 纹理 → 部件 → 物体
对比全连接：224×224×3 的图接 1000 维全连接要 1.5 亿参数，一个 3×3×3×64 的卷积核只要 1728 个。更少参数＝更强约束＝更好的泛化。
几个零件：卷积核＝检测某种局部图案的小窗口，一层几十到几百个，输出通道数＝核的个数；池化＝窗口内取最大或平均，降尺寸、增大感受野；1×1 卷积＝只在通道维做线性组合，用来升降维。
一个必须记住的年份
AlexNet，2012：ImageNet top-5 错误率 15.3%，次名 26.2%，深度学习时代的起点。2015 年 ResNet 用残差连接把 152 层解锁——那个「加号」在 Transformer 里还会再见。
RNN：维护一个隐状态，读一个更新一次
hₜ = tanh( W·hₜ₋₁ + U·xₜ + b )　　yₜ = V·hₜ
h 是「到目前为止读到的东西的摘要」。每一步用同一组权重 W、U、V——这就是 RNN 的归纳偏置（时间上的平移不变）。
LSTM（1997）装了遗忘/输入/输出三道门，核心是那条细胞状态：信息能近乎无损地一路传下去（本质上又是一条残差通道）。它把可用依赖长度推到几百步，但没有从根上解决问题。
两个死穴
① 长程依赖仍然压不住。信息从第 1 个词传到第 500 个词要穿过 500 次矩阵乘法和非线性，反传回去同样连乘 500 次。句子一长，早期信息就被稀释掉。
② 天生串行，吃不下并行算力。hₜ 依赖 hₜ₋₁，第 t 步必须等第 t−1 步算完；而 GPU 的全部优势在于同时算几万个数。第二条更致命——第一条是效果问题，第二条是「有钱也买不到更快」。
这两条直接定义了继任者的设计目标
需要一个机制：① 任意两个位置之间一步可达；② 全序列可以一次并行算完。
Transformer 就是对这两条的直接回应——见第 24 页。

表示学习：文字怎么变成有意义的向量

起点：one-hot 的两个致命缺陷
词表 10 万，每个词表示成一个 10 万维、只有一位是 1 的向量。
① 维度爆炸且极端稀疏。
② 任意两个词都正交 —— 「猫」和「狗」的相似度，与「猫」和「螺丝刀」完全一样，都是 0。语义信息一点没有。
word2vec（2013）：用上下文定义词义
出发点是语言学里那句老话：「一个词的意思，由它周围经常出现哪些词决定。」
训练方式极简单 —— CBOW 用周围词预测中心词，Skip-gram 用中心词预测周围词。训完之后要的不是这个预测任务，而是中间那张权重表：每个词一行，几百维的稠密向量。
这是自监督学习的早期范例：标签是从文本自己身上造出来的。
学出来的向量空间有几何结构
vec(国王) − vec(男) + vec(女) ≈ vec(女王) vec(巴黎) − vec(法国) + vec(意大利) ≈ vec(罗马)
「性别」「首都关系」这些概念，变成了空间里一个可加减的方向。没有人教过它这些 —— 全是从「谁和谁常一起出现」里长出来的。
相似度用余弦相似度（两向量夹角）度量。今天的向量检索、RAG，用的就是同一套东西。
它的局限，以及下一步
word2vec 给每个词一个固定向量。可是「苹果」在「吃苹果」和「苹果发布会」里根本不是一个意思，一个向量装不下。
于是有了上下文相关的表示：同一个词在不同句子里拿到不同的向量。ELMo（2018，双向 LSTM）先做到，BERT / GPT 用 Transformer 做得更好。
今天大模型里的 embedding 层，就是这套东西的直系后代 —— 只不过它不再是训练的产物，而是整个模型的第一层，和其余部分一起端到端训练（第 38 页）。
「表示学习」这个词的意思
让模型自己学出「数据该用什么形式表达」，而不是由人设计。这是深度学习区别于传统机器学习最实质的一点。

四个反直觉的经验事实

深度学习里有一批被反复验证、但和经典理论直觉相冲突的现象。知道它们存在，比会推导它们更重要 —— 它们解释了今天大模型的很多做法为什么合理。
① 双下降 double descent
模型大到刚好能记住全部训练数据时，测试误差冲到最高；再继续变大，它又开始下降。所以「参数比样本多 = 必然过拟合」在这里不成立。
② 随机标签也能背下来
Zhang et al. (2017)：把 ImageNet 标签完全打乱，同一个网络照样训到训练集 100% 正确。说明容量根本不是限制因素 —— 泛化必然还有别的来源（数据结构、SGD 的隐式偏好等）。这至今没有完整解释。
③ 彩票假说 lottery ticket
Frankle & Carbin (2019)：一个随机初始化的大网络里，存在一个很小的子网络，单独把它拿出来、用原来的初始值训练，能达到和整个大网络相当的效果。
解读：训练大网络，某种程度上是在并行地买很多张彩票，然后让优化过程挑出中奖的那张。这是模型剪枝和蒸馏的理论依据。
④ 规模本身会带来质变
在小模型上完全做不了、准确率等于随机的任务（多步算术、复杂推理），在模型规模跨过某个点之后突然可用。
但这里有个重要修正：后续研究指出，很多所谓「涌现」是评测指标不连续造成的错觉 —— 用「完全正确才算分」这类阈值指标去看，曲线自然是突变的；换成连续指标（如逐 token 的对数似然）后，提升其实是平滑的。
下次看到「涌现能力」，先问一句用的是什么指标。

注意力：让任意两个位置一步直达

2017 年论文《Attention Is All You Need》。标题里的 all 是关键 —— 它不是给 RNN 加一个注意力模块，而是把循环结构整个删掉，只留注意力。
它一次解决了 RNN 的两个死穴
RNN 的问题注意力的做法
信息要走 n 步才能从头传到尾任意两个位置直接连一条边，路径长度恒为 1，与距离无关
第 t 步必须等第 t−1 步整个序列一次矩阵乘法算完，天然并行，吃满 GPU
代价也很直接：n 个位置两两相连是 n² 条边。算量和显存都随序列长度平方增长 —— 这个窟窿至今没有被真正填上，只是被工程手段压住了（第 29 页）。
还必须补两样东西
删掉循环，也就删掉了「顺序」这个信息。注意力本身是置换不变的 —— 把句子的词打乱，它算出来完全一样。
所以必须外挂 位置编码（第 27 页）。

另外，注意力只做「加权求和」，是线性的，所以每层后面还要接一个 FFN 提供非线性和存储容量。
直觉：一次「带着问题去查资料」
句子：「那只猫没跳上桌子，因为它太胖了」
要理解「它」，模型得知道「它」指的是猫还是桌子。
Query「它」这个位置发出的提问：我在找一个会「胖」的东西
Key每个位置挂出的标签：我是一个动物 / 我是一件家具
Value每个位置真正携带的内容，被选中后要交出去的东西
拿 Query 去和所有 Key 做匹配 → 得到一组匹配分数 → 归一化成权重 → 按权重把所有 Value 加权求和。
「猫」的 Key 与这个 Query 匹配度高，于是「它」这个位置的新表示里，绝大部分内容来自「猫」。
注意：Q、K、V 都是从同一份输入用三个不同的权重矩阵变换出来的。「自注意力」的「自」就是这个意思 —— 提问的和被查的是同一个序列。

自注意力：五步，一个公式

公式
Attention(Q,K,V) = softmax( QKᵀ / √d_k ) V
为什么要除以 √d_k：d_k 越大，QKᵀ 这个点积的方差越大，数值被推到 Softmax 的饱和区，梯度趋近 0 训不动。除以 √d_k 把方差拉回 1 附近。
所以这一步叫「缩放点积注意力」，缩放两个字不是修辞。
形状对照（单头）
输入 Xn × d
W_Q,W_K,W_Vd × d_k
Q, K, Vn × d_k
QKᵀ（分数矩阵）n × n ← 平方项在这
输出n × d_k
n = 序列长度，d = 模型维度。参数量与 n 无关，所以同一个模型能吃任意长度 —— 只是显存吃不消。
五步，一步不多
#做什么细节
1算 Q、K、VQ = XW_Q，K = XW_K，V = XW_V。三个矩阵是要学的参数，训练前随机初始化
2算相关性分数score(i,j) = qᵢ · kⱼ。点积越大表示越相关。得到一张 n×n 的表：第 i 行第 j 列 = 位置 i 有多想看位置 j
3缩放 + 掩码除以 √d_k；需要遮住的位置把分数设成 −∞（下一页）
4Softmax 逐行归一每一行变成一个和为 1 的权重分布。这就是常见热力图里那些亮点
5加权求和 Valueoutᵢ = Σⱼ 权重(i,j)·vⱼ。每个位置的新表示 = 它认为该看的那些位置的内容的混合
关键性质
权重是按输入现场算出来的，不是训练时固定下来的。同一个模型，遇到不同句子会连出完全不同的连接图。「该看哪里」这件事本身成了模型的输出，而不是人写死的结构。
别过度解读注意力图
注意力权重不等于模型的解释。多项研究显示，同样的预测可以由差别很大的注意力分布得到，权重高的位置未必是因果上重要的位置。当示意可以，当证据不行。

多头与掩码：两个必要的补丁

补丁一：多头注意力 Multi-Head
问题：一次 Softmax 只能给出一种权重分布。可是「它」这个词，既需要看指代关系，也需要看语法角色、看情感、看主题 —— 一张表装不下这么多种关系。
做法：把 d 维切成 h 份，每份独立做一次上一页的完整流程，最后把 h 个输出拼起来再过一个 W_O 融合。
d = 4096, h = 32 → 每头 d_k = 128
算量几乎不变（切开算 h 次小的 ≈ 算一次大的），但表达力大幅上升。可以粗略理解成「同时用 h 种视角看同一句话」。
可解释性研究确实发现有些头专管句法、有些管指代 —— 但不是每个头都有清晰分工，且很多头可以被剪掉而几乎不掉点。
补丁二：掩码 Mask
掩码的实现只有一句：在 Softmax 之前，把不该看的位置的分数设成 −∞。过完 Softmax 它的权重就精确等于 0。
种类遮什么 / 为什么
因果掩码
causal		遮住所有未来位置。训练时整句话都在眼前，不遮的话模型直接抄下一个词，学不到任何东西。这是 GPT 类模型能并行训练又不作弊的关键
填充掩码
padding		一个 batch 里句子长短不一，短的补 0 凑齐。遮住这些补位，别让它们参与计算
无掩码BERT 类模型双向可见，每个位置都能看到全句
因果掩码是「自回归」这件事在实现层面的全部内容。有它，一次前向就能同时算出 n 个位置各自的「下一个词」预测，n 个训练信号一次拿到手 —— 训练效率相比 RNN 提升了一个数量级。
顺带记住三个词
自注意力：Q、K、V 来自同一个序列。交叉注意力：Q 来自解码器，K/V 来自编码器 —— 翻译模型靠它把译文对齐到原文，今天多模态模型也用它把文本对齐到图像。因果 / 双向：指的就是有没有加因果掩码。

位置编码：把「顺序」重新装回去

注意力是加权求和，加法不分先后。「猫追狗」和「狗追猫」在纯注意力眼里完全一样。位置信息必须单独注入 —— 这是 Transformer 唯一一处需要人工设计先验的地方，也是过去八年被改得最多的地方。
方案做法优点问题 / 现状
正弦位置编码
原版 2017		用不同频率的 sin/cos 生成一个固定向量，加到 token embedding 上不需要训练；理论上可外推到训练时没见过的长度实测外推效果差；已被淘汰
可学习位置编码
BERT / GPT-2		每个位置一个可训练向量，同样是加上去简单，效果好最大长度写死，超过训练长度直接没有对应向量
RoPE 旋转位置编码
2021 → 今天的标准		不加到输入上，而是在算注意力时把 Q 和 K 按位置旋转一个角度。点积后自然只剩相对位置 m−n 的依赖把相对位置直接写进注意力；可以通过调整旋转基频（NTK / YaRN 等）扩展上下文Llama、Qwen、DeepSeek、Mistral 等主流模型全部在用
ALiBi不加编码，直接在注意力分数上按距离减去一个线性惩罚：越远扣分越多实现极简；长度外推能力强本质是硬编码「近的更重要」这条先验，部分任务上受限
为什么「相对」比「绝对」好
语言里真正重要的是词与词的距离和顺序，不是它在文档里的绝对下标。同一个短语出现在第 5 个词还是第 5000 个词，内部结构应该一样。RoPE 把这条先验直接编进了注意力的计算方式里，而不是指望模型自己从数据里学出来。
长上下文不是免费的
把 RoPE 的基频调大，模型确实能吃下 128K 甚至 1M token，但「能读进去」不等于「读得懂」。大海捞针式测试上表现好，不代表跨长距离的多步推理也好；实测普遍存在「中间部分被忽略」的现象。标称上下文长度要和实际有效长度分开看。

同一套积木的三种搭法，和那个 n² 的窟窿

三者唯一的实质差别是看不看得见未来，剩下的零件三家完全一样。下半页那四类补法要分清：FlashAttention 是精确的工程优化，换了它结果一模一样；稀疏注意力和 MoE 改了模型本身，是用效果换成本。
Encoder-only ｜ BERT, 2018
不加掩码，每个位置都看得到左右两边。
目标：遮住约 15% 的词让它猜回来（MLM）。
擅长：分类、情感、实体识别、相似度。
不会生成——它没有「下一个词」的概念。
今天仍是检索/排序编码器的主力（RAG 的 embedding 模型多是这一支）。1–3 亿参数。
Decoder-only ｜ 今天几乎所有大模型
加因果掩码，每个位置只看得到自己和左边。
目标：预测下一个 token，就这一个。
为什么它赢了：任何无标注文本都是训练数据；训练与推理形式一致；扩规模收益最持续；任何任务都能写成文字接龙。
几十亿到上万亿参数，上下文 12.8 万起步。
Encoder-Decoder ｜ 原版、T5
编码器读完整输入，解码器边生成边用交叉注意力回看。
擅长：翻译、摘要这类输入输出边界清晰的任务。
为什么让位：参数近乎翻倍，而 decoder-only 把输入放进上下文就能干同样的事。
但交叉注意力活了下来——多模态模型接图像/音频用的就是它。
窟窿：注意力的算量是 O(n²·d)
序列 1,024 → n×n 分数矩阵约 100 万个数；32,768 → 10.7 亿；1,000,000 → 约 1 万亿。朴素实现还要把整张表写进显存再读回来——长上下文的瓶颈往往不是算力，是显存带宽。
三个真正的约束：① KV cache 随长度线性增长，长对话常是显存先撑不住；② 长上下文贵在「读」不在「写」；③ 能装下 ≠ 用得上，信息放中间时召回率明显下降。

这张图最该带走的两件事

④ 算来算去，算出来的到底是什么

这一问是六问里的枢纽：一旦知道出口处那个东西是什么类型，训练和推理会同时通。答案很短——是整个词表上的一个概率分布。
训练时，这张表接着做什么
拿它跟真答案比：真答案是「正确的那个词概率应该是 1」。差距用交叉熵算成一个数，再反向传播回去把所有 W 调一点点。（这正是第 17 页「输出层与损失必须成对」的那一对）
推理时，这张表接着做什么
不比对、不算损失、不动任何一个参数。只按解码策略从表里挑一个词，接到输入末尾，再算下一轮。（第 8 页那两个阶段的区别，在这里第一次变得具体）
如果是理解类模型呢
BERT 这类不接 W_out 出口，它要的是中间产物：每个词被改写成一个融合了上下文的新向量。同一个「苹果」，在「吃苹果」和「苹果发布会」里出来的向量不一样——这就是「读懂了」在数字上的样子。
把这一问的答案压成一句话
公式是流程，W 是知识，概率是产出，选词是动作，循环是生成。——这五个词各归各位之后，「大模型在干什么」就没有剩下的神秘部分了。

⑤ 公式里哪些是要学的：所有符号分成三堆

「那些参数是要算的，我理解就是权重吧」——方向是对的，但公式里的符号其实有三种，混在一起才是看不懂的主因。
一、要学的参数 —— 训练调的就是这些
符号形状与个数
W_Q, W_K, W_V各 d × d_k，每层每头都有一组；总数 = 层数 × 头数 × 3
W_Od × d，每层一个（多头拼接之后的那次线性）
W₁, b₁, W₂, b₂d×4d 与 4d×d，每层一组。参数量的大头，约占全模型 2/3
γ, β各 d 维，每个 LayerNorm 一对
Embedding 表V × d，全模型一张（V ≈ 5 万）
W_outd × V，很大；常与 Embedding 共享同一份权重

符号它是什么
PE原论文用 sin/cos 算出来的固定表。注意：现代大模型多改用 RoPE 或可学习位置编码，那时它就挪进第一堆
√d_k一个常数。d_k = 64 时它就是 8

符号它是什么
X, H这一次输入的词向量、加过位置的输入

最容易混的一处，就在 LayerNorm 这一个式子里
LN(x) = γ ⊙ (x − μ) / √(σ² + ε) + β
γ、β 是学出来的参数，μ、σ² 是这一次输入当场算出来的统计量——同一行公式里两种都有，看错就会以为归一化「也在学」。
「GPT-3 有 1750 亿参数」数的是哪一堆
只数第一堆。第二堆是常数和函数，第三堆每次输入都重算、根本不存盘，两者一个都不计入。
这也解释了模型文件为什么大、跑起来显存为什么还要更大：文件装第一堆，运行还得给第三堆腾地方。第 36 页会拆一个 8B 模型。

分词：模型眼里的世界不是字，是 token

为什么不能直接按字或按词
按词词表爆炸，且永远会遇到没见过的词（OOV）。中文还得先分词
按字符没有 OOV，但序列变得极长，n² 的代价吃不消，语义单位也太碎
按子词折中方案，今天的标准。常见词整块保留，罕见词拆成有意义的片段
BPE：字节对编码
训练时反复做一件事：统计当前语料里最常一起出现的相邻两个单元，把它们合并成一个新单元。重复几万次，就得到一张词表。
l o w e r · l o w e s t · n e w e s t → 合并最频繁的 (e,s) → es → 再合并 (es,t) → est → 词表里出现了「est」这个后缀
变体：GPT 系用字节级 BPE（在 UTF-8 字节上跑，任何字符都不会 OOV）；也有 WordPiece（BERT）、SentencePiece / Unigram（多语言常用）。
几个必须知道的数
项典型值
词表大小GPT-4 系 cl100k 约 10 万；Llama 3 为 128,256；多语言模型常到 25 万
英文约 1 token ≈ 0.75 个单词，即 4 个字符左右
中文约 1 个汉字 ≈ 1–2 token，取决于分词器。同样一句话，中文往往比英文更费 token —— 上下文窗口和 API 计价都受影响
代码缩进、括号会吃掉不少 token，所以新一代分词器专门优化了连续空格
分词直接造成的几个「模型好蠢」现象
数不清字母问「strawberry 里有几个 r」常出错 —— 这个词被切成几个 token，模型根本看不见单个字母
算术不稳数字切法不一致（「1234」可能是一个 token，也可能是「12」「34」），位值难对齐。新模型多改成逐位数字单独成 token
罕见词失灵被切成一堆碎片后，语义信息在拼接中损失
多语言不公平低资源语言被切得更碎 → 同样内容更费 token → 成本更高、有效上下文更短
这些不是「模型不够聪明」，是输入表示层面的信息损失。知道这一点，就知道哪些任务不该指望它硬算，而该交给工具。

数据：全流程里最重的一道工序

在架构基本收敛、算力可以买到的今天，拉开模型差距的主要变量是数据。这一道工序的产出物是一串 token 流，但做法上更像工业提纯。
流水线的六道
1采集：Common Crawl 网页快照、代码仓库、书籍、论文、百科、许可数据
2抽正文：从 HTML 里剥掉导航、广告、样板文字
3语种识别与过滤
4质量筛：启发式规则（长度、符号比例、重复率）+ 分类器打分
5去重：URL 级、文档级、段落级；常用 MinHash 做近似去重
6去毒 / 去隐私 / 去评测集污染，再按领域配比混合
一个可验证的公开例子：FineWeb（2024）
规模15 万亿 token，来自 96 个 Common Crawl 快照
方法只做数据处理，不动模型结构，用同一套小模型做对照实验
结果在相同训练预算下，超过当时同类的公开数据集
最反直觉的发现「去重去得越狠越好」是错的。他们发现按快照分别去重，效果好于把全部 96 个快照放在一起做全局去重 —— 全局去重会把高质量的、被反复引用的内容当成冗余删掉，剩下的反而是长尾垃圾
这个例子的价值在于：它把「数据处理」变成了可以做消融实验的科学问题，而不是各家闭门的手艺。
配比也是个决策
代码占比高 → 推理和结构化能力更强（即便你不考它写代码）；多语言占比 → 决定非英语表现；书籍/论文 → 长文连贯性。这些比例是超参数，要靠小规模实验定。
两条硬约束
评测集污染：训练数据里混进了测试题，跑分虚高。必须主动清洗，且要公布方法。
高质量数据快见底：所以合成数据、多轮筛选、以及「同样的数据训更多遍」都成了现实选项。

预训练：一个目标，一条曲线

一个目标：让文本自己当标注
L = − Σ log P( xₜ | x₁ … xₜ₋₁ )
最大化「给定前文时，真实的下一个 token」的概率。这是自监督：标签就是文本自己的下一个字，不需要任何人工标注。ImageNet 那 120 万张图是几万人标了两年多——标注这个瓶颈不是被扩产解决的，是被绕过去了。
于是互联网上所有的文本一下子全部变成了训练数据。又因为有因果掩码，一条长度 n 的序列一次前向就产生 n 个训练信号——这是相比 RNN 真正的训练效率代差。
为什么这个「低级」目标能逼出高级能力
因为「下一个词是什么」取决于一切。梯度会去找任何能降低损失的规律：

压缩和理解在这里是同一件事：要把文本预测得足够准，等价于要把产生它的规律学到手。
整个预训练就是「取一批 → 前向 → 算损失 → 反向 → 更新」跑几十万次，数学上没有新东西，难的全部在工程——下一页。
一条曲线：这条路上唯一的经验定律
损失 L 与参数量 N、数据量 D、算力 C 呈幂律，双对数坐标上是一条直线。它不是定理，是拟合出来的经验规律，但稳到可以拿来做几亿美元的预算决定：先用一批小模型拟合，外推出大模型能到哪儿，再决定投不投。
C ≈ 6 · N · D
算力（FLOPs）≈ 6 × 参数量 × 训练 token 数，要记住的一个式子。口径：只算矩阵乘、忽略注意力本身的开销，长上下文时会明显低估。
Chinchilla
2022		训了 400 多个模型做对照：给定算力，N 和 D 要同比例增长，约 20 token / 参数。同算力下 70B × 1.4T 全面胜过 280B 的 Gopher，此前的大模型普遍严重欠训
今天的做法普遍远超 20 倍，即「超训」。Chinchilla 只优化了训练算力，可模型训完要被调用几十亿次，推理成本随参数量走——算进去，最优点就大幅移向更小的模型 + 更多的数据。Llama-3 8B 用 15T token ≈ 1875 tok/参数；2026 年推理时算力也能换性能，天平进一步偏向超训
该记的不是 20 这个数，是这句话：参数和数据必须一起长，往哪边偏取决于你打算训一次、用多少次。另外幂律预测的是损失，损失和你关心的能力之间还隔着一层。
一个反直觉的细节
预训练一般只跑 1 个 epoch 左右甚至不到，每条数据只见一次——「过拟合」在这里基本不是问题，Dropout 普遍不用，与小数据集上的直觉正好相反。

工程实况：装不下、算不完、还老是坏

上一页说「数学上没有新东西」。那难在哪里？难在这三件事上，而它们全都不是数学问题。
一、装不下：先算一笔显存账
8B 模型，AdamW + 混合精度：
项B/参数8B 合计
参数 BF16216 GB
梯度 BF16216 GB
FP32 主权重432 GB
优化器两个状态864 GB
小计16128 GB
激活值另计，随 batch × 序列长度线性涨。一张 H100 只有 80 GB——哪怕 8B 这种「小」模型，全量训练也装不进一张卡。
两个省显存的常规手段
混合精度：BF16 算、FP32 存主权重；BF16 指数位与 FP32 相同，比 FP16 抗溢出。
梯度检查点：前向不存激活、反向按需重算，用约 30% 算力换显存。
二、算不完：四种并行，切的是不同的东西
数据并行
DP		切数据。每卡一份完整模型，各算各的 batch 再汇总梯度。最简单，但每卡都要装下整个模型
ZeRO
FSDP		切状态。优化器状态、梯度、参数分片到各卡，用时再聚合。128 GB 直接摊薄，今天最常用
张量并行
TP		切矩阵。一层里的大矩阵按行列切到多卡，一次前向多次通信，只在单机 NVLink 内用
流水线
PP		切层。1–8 层在卡 A、9–16 层在卡 B，像装配线。会有气泡（空转），靠微批来填
MoE 还有专家并行 EP（切专家，按路由发 token）。实际都是组合：典型「机内 TP + 机间 PP + 全局 ZeRO」，叫 3D 并行。
真正的难点是那一次求和
每步都要把所有卡的梯度汇总成同一个数（all-reduce）。上万张卡时，决定效率的往往不是算力而是网络。
三、老是坏：Llama 3 405B 的 54 天
集群 / 时长16,384 张 H100，连续 54 天，约 2100 万 GPU 小时，吃 15.6 万亿 token
意外中断466 次，其中 419 次非计划——平均每 3 小时坏一次
故障来源78% 归因到硬件：GPU 本身 58.7%，HBM3 显存 17.2%
人工介入整个 54 天只有 3 次，其余全部自动恢复；有效训练时间 >90%
硬件故障在这个规模上不是异常事件，是必然事件。检查点存太密影响吞吐、太稀则一次故障赔掉几小时算力——这个频率是要认真权衡的工程参数。
还有一种坏法：损失尖峰
loss 突然垂直飙升，模型可能就此训废，规模越大越容易发生且无法事前预测。PaLM 540B 出现过 20 多次，处置：回滚到尖峰前约 100 步的检查点 → 跳过那 200–500 个批次 → 继续。同样的数据换个顺序就不再触发——不是数据「有毒」，是数据顺序 × 参数状态的特定组合出了事。

后训练：把「会续写」变成「会听话、还合你意」

练完出来的，是一个只会续写的东西
输入「中国的首都是哪里？」，它可能续写出「……B. 上海　C. 广州　D. 深圳」——它没有错，语料里这句后面确实常跟着选项。Base model 只会续写最像训练数据的东西，它不知道「你在问它」。
SFT：同一个目标，换一批数据
继续用完全相同的目标（预测下一个 token）训练，只是把数据换成人写的「指令 → 理想回答」对，并套上对话模板。
<|system|> 你是一个有用的助手 <|user|> 中国的首都是哪里？ <|assistant|> 中国的首都是北京。
关键细节：只对 assistant 部分算损失，否则模型会顺带学会「编用户的问题」。数据量几万到几百万条，相比预训练的十万亿 token 是极小的量——够了，因为要教的只是格式和习惯，不是知识。
全量微调太贵：LoRA 与它的边界
全量微调 8B 要 128 GB。LoRA 冻住原模型全部参数，只在每个权重矩阵旁挂一对小矩阵 W′ = W + B·A（r 取 8–64），要训的参数量降到千分之几，省掉的正是最贵的那 14 字节/参数。QLoRA 再把底座 4-bit 量化，单卡就能微调几十 B 的模型。
但微调不擅长灌入新的事实知识：少量数据压不过预训练学到的分布，还容易灾难性遗忘。私有资料先考虑 RAG。
偏好对齐：SFT 只能教「一个正确答案」
可很多问题有无数个都对的答案，差别在哪个人更想要。这种偏好写不成标注，只能靠比较：给两个回答，问人更喜欢哪个。
RLHF
（PPO）
2022		① 用人类排序数据训一个奖励模型打分　② 用强化学习让模型最大化这个分数，同时用 KL 惩罚拴住它。ChatGPT 的原始方案，但要同时在显存里放四个模型，超参敏感、复现困难
DPO
2023		证明那个 RL 目标存在闭式解，可改写成偏好对上的一个分类损失：不用奖励模型也不用跑 RL，像 SFT 一样梯度下降。开源社区默认。局限：只能用离线固定数据，无法探索新回答
GRPO
2024–		回到在线 RL，但对同一问题采样一组回答，拿组内相对好坏当优势信号，删掉价值网络。显存与复杂度大降又保住在线探索；DeepSeek 用它训出强推理模型后成为主流
RLVR换奖励来源：不用人类偏好，改用可自动验证的结果——数学题对不对、代码过不过测试。奖励客观、可无限扩展，是当前推理模型提升的主要来源；前提是任务可验证
这条线的规律：每一代都在删掉一个组件。PPO 删手工奖励函数 → DPO 删奖励模型 → GRPO 删价值网络 → RLVR 删人类标注。方向始终一致：让训练信号更便宜、更可扩展。
共同的、尚未解决的问题：奖励攻陷
模型会找到让评分变高但并没真变好的捷径：写得又长又客气、迎合提问者的预设、猜格式而不是真解题。这是当前对齐研究最核心的开放问题，没有通用解法。

推理与部署：训练是一次性支出，推理是每次请求都要付的钱

一、生成天然是串行的
不是一次算完，而是一次只出一个 token，再接回输入重算，直到出现结束符。
「今天」 → 天气 「今天天气」 → 很 「今天天气很」→ 好
输出 200 个 token 就要跑 200 次前向。这是延迟的根源，也是所有推理优化的战场。
KV cache：最重要的一个优化
每步重算全部历史的 K、V 是纯浪费——它们根本不会变。缓存下来，每步只算新 token 那一份，复杂度从每步 O(n²) 降到 O(n)。
代价是显存：缓存大小 ∝ 层数 × 头数 × 序列长度 × batch。长上下文下 KV cache 会超过模型参数本身占的显存——GQA、MLA、FP8 KV cache 要解决的就是它。
用户感知的「快不快」，是这两个数
首 token 延迟 TTFT 由 prefill 决定，每秒输出 token 数 TPS 由 decode 决定。它们分别对应右边那两个阶段，优化手段完全不同。
二、拿到概率分布之后怎么选
贪心永远取概率最高的那个。确定性任务用，但容易重复、死板
温度 Tsoftmax 前把 logits 除以 T。T<1 更保守，T>1 更发散，T→0 退化成贪心。控制创造性的总开关
Top-k只在概率最高的 k 个里采样，砍掉长尾胡话
Top-p
核采样		按概率从高到低累加，够 p（如 0.9）就截断。候选个数随分布形状自动变，比固定 k 更合理，今天的默认
重复惩罚对已出现过的 token 降分，抑制复读
同一个模型，换解码参数就是两种性格。写代码用 T≈0，写文案用 T≈0.8–1.0。这一层完全不涉及训练——很多「模型不稳定」的抱怨其实来自这里。
推理时算力也能换性能
思维链：先写推理过程再给答案，把「一步算出来」摊成多步。自洽性：同一问题采样多次取多数。都不改一个参数，只花更多推理算力。
三、先分清两个阶段，否则优化无从下手
预填充 prefill：整个提示词一次算完，算力受限。解码 decode：一个一个吐字，显存带宽受限——每出一个 token 要把全部权重读一遍。批处理救 decode，前缀缓存救 prefill。

评测与失效：知道它什么时候不该被信

怎么评
标准基准MMLU（多学科知识）、GSM8K / MATH（数学）、HumanEval（代码）、长上下文与工具调用类基准
人类偏好盲测对战按胜率排名（如 Arena 类榜单）。更贴近真实体验，但受回答长度、格式等表面因素影响
模型当裁判用强模型给回答打分。便宜、可扩展，但有明显偏好偏差（偏长、偏自家风格）

五种典型失效，以及它们的成因
现象为什么会这样
幻觉训练目标是「让下一个 token 概率最大」，从来不是「说真话」。模型没有「我不知道」这个内建状态，流畅地编造与流畅地陈述事实，在目标函数眼里是一回事
知识过期参数里的知识冻结在预训练截止那天。这是 RAG 与工具调用存在的根本理由
算不对 / 数不清部分源于分词（第 38 页），部分源于它做的是模式匹配而非符号运算。该交给计算器，不该硬算
迎合用户偏好训练奖励「让人满意」。用户一质疑就改口，是被训出来的行为，不是理解不够
提示注入模型无法可靠区分「系统指令」和「数据里夹带的指令」。这是 Agent 接入外部内容时最现实的安全风险，目前没有彻底解法，只能靠权限隔离和输出校验
对齐税
对齐做得越强，模型往往在某些能力上越保守：拒答变多、创造性下降、某些基准掉点。安全与能力之间存在真实的权衡，各家产品在这条线上的取舍不同 —— 这解释了为什么同代模型「感觉」差别很大。

问题它最后结在哪一句话上在
①公式到底有哪些一层就是「多头注意力 → Add&Norm → FFN → Add&Norm」，外面套 N 次；前面加嵌入与位置，后面接输出层。四个最容易错的地方：√d_k 不能省、LayerNorm 沿特征维、掩码要用 −∞、Post-LN 与 Pre-LN 不是同一个东西30
②用人话讲这都在干嘛每个式子都在完成一个动作：定身份、给座位、发问、应答、定听谁的比例、调音量、分组听、把原样留住、把量纲拉齐、关起门消化一遍31
③一步一步在算什么把它当程序看：每一步拿到什么形状、产出什么形状。n 个字进去、n 个向量出来，中间那张 n×n 的表是唯一让位置之间互相看见的地方32
④算出来的到底是什么公式是流程，W 是知识，概率是产出，选词是动作，循环是生成。出口处永远是整个词表上的一个概率分布——训练时拿它比对，推理时拿它采样33
⑤哪些参数是要学的符号分三堆：要学的、写死的、每次输入重算的。「1750 亿参数」只数第一堆；同一行 LayerNorm 里 γ、β 属第一堆，μ、σ² 属第三堆34
