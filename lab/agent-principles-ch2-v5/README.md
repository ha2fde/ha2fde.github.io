## 和对外那一版的区别

对外版是**正着写**的：机器学习 → 深度学习 → Transformer → 大模型，按学科顺序铺。

这一版是**倒着写**的。终点先定死：真正坐下来啃 Transformer 公式时会问出来的那六个问题——

1. 一层里到底有哪几个式子
2. 用人话讲这些式子都在干嘛
3. 一步一步在算什么（形状怎么变）
4. 算来算去，算出来的到底是什么
5. 公式里哪些符号是要学的
6. 用具体的数走一遍

从这六个问题往前推一层，是**深度学习**里绕不过去的核心点；再往前推一层，是**机器学习**里绕不过去的核心点。脉络仍然是 ML → DL → Transformer → LLM（和对外版一致），但每一段的取舍以「这六个问题需要什么」为准，权重重新分配过。

- 第 3 页：把六个问题摆出来（这一章的终点）
- 第 4 页：倒推表，六个问题各自往前挂着哪些前置知识、在第几页
- 第 30–35 页：六个问题各自一页，正面回答
- 第 47 页：回到起点，六个问题各自结在哪一句话上
