## v0 · 从图灵到 Transformer（33 页）

按**时间顺序**讲：图灵 → 符号主义 → 感知机 → 反向传播 → 深度学习 → 词向量 →
RNN → 注意力 → Transformer。

**问题：讲成了编年史。** 每个零件都出现了，但都是"某年某人提出了 X"，
读完知道发生过什么，不知道**为什么非得是这样**。而且 33 页太长。

## v1 · Transformer 的每个零件，都是被问题问出来的（18 页）

改成**问题 → 解法**的链条：八个问题，解掉一个下一个立刻冒出来。
去掉了大部分年份，主题清楚了很多。

**问题：是转述，不是推导。** 每页的形状都是
"当时卡住了 → 有人想了个办法 → 这个办法叫 X"。
Q/K/V、多头、位置编码全是**被报告的**，不是**被推出来的**——
读者没法问"那为什么不能是别的做法"。

原话反馈：**「读起来还是觉得隔靴搔痒，雾里看花」**。

## v2 · 公理推导版（18 页，废弃）

想学几何证明：立三条公理 A1/A2/A3，四条约束 C1–C4，
每个零件挂一个"由 C1 + A1 + C4 推出"的标签，最后一张 QED 对照表。

**彻底失败。原话反馈：「完全看不懂。毫无逻辑性」。** 三个硬伤：

1. **假形式化。** A1/C4 这种标签看着像数学，但读者**看不见** C4 是什么，
   只能硬背七个抽象代号、跨十五页来回对照。
   这比白话叙述**认知负担更重，不是更轻**。把形式当成了逻辑。
2. **前七页全是前提。** 到第 8 页才发生第一件具体的事，
   三分之一篇幅里读者手上空无一物，线断了。
3. **把图挪走了。** 几何题直观，是因为**图一直在眼前**，
   每一步都是在图上做一个看得见的动作。
   这一章的"图"就是那两句猫/桌子的话——v2 把它降级成第 6 页的一个例子，
   开头改成摆公理。

## v3 · 机器怎么读懂一句话（14 页）

从 v2 的残骸里只保留一条教训：**严谨感来自"排除"，不来自标签。**

三条规则：

1. **全章只有一道题**，而且这道题从第 2 页挂到最后：

   ```
   那只猫没跳上桌子，因为它太胖了。
   那只猫没跳上桌子，因为它太高了。
   ```

   不是"举个例子"，是唯一的题。后面每一页都在这句话上做动作。

2. **每页标题是一个问题，每页只答一个，答完剩下的那个问题——逐字就是下一页的标题。**
   每页底下一条"↓ 下一个问题"，链条肉眼可见。不需要记任何编号或代号。

3. **每个零件出场前，先摆出能想到的做法为什么行不通，剩下的那条才是答案。**
   例：意思怎么随句子变 → 排掉"挑最相关那一个"（全有全无，拧不动）、
   排掉"全句平均"（每个位置都一样）→ 只剩"按比重混" = 注意力。

另外埋了两条贯穿全章的伏笔，替代 v2 那些编号标签：
"它只会**错一点、改一点**"（第 4 页立，第 7、11 页各兑现一次）、
"几十万像素一次铺开，**谁也不等谁**"（第 5 页立，第 12、13 页兑现）。

## 一句话结论

三版都想做到"有逻辑"。
v1 输在**只有顺序没有必然性**，v2 输在**把形式当逻辑**。
真正管用的是：**题一直在眼前，每一步都是在题上排除掉一条路。**

## 后记：这条路线最后没有上线

v1–v3 的目标一直是「把 Transformer 讲通」，靠的是一条越收越紧的叙事线。
问题是这条线越紧，**能装进去的知识就越少** —— v3 收到 14 页，
机器学习基础、训练流程、部署评测全都进不来。

线上最终换成了另一种东西：**不讲主线，按知识块罗列，每页自成一块**。
46 页，从「什么是学习」一路铺到「一个大模型怎么练出来、怎么送到用户面前」。
两条路线解决的不是同一个问题 —— 这一条要的是**读一遍就懂**，
那一条要的是**放在手边随时能查**。
