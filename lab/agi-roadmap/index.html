从这里到 AGI：八个词的地图

继续 scaling、RL+可验证环境、连续学习、多 agent 分工、世界模型、具身智能、AGI、RSI。这八个词不在一个层级上——先把它们摆到该在的位置，再看每条路线在解什么、卡在哪、彼此怎么依赖。

先摆位置：这八个词不在一个层级上

最上面一层是「要什么」
AGI 是目标，不是方案。它的定义直接决定下面选哪条路——按「覆盖多少经济价值工作」定义，和按「能不能自己学新领域」定义，优先级完全不同。
中间那层是「怎么自己长」
RSI 横跨所有路线：它要的不是某一项能力更强，而是把能力接回到产生能力的过程上。缺任何一环，环就闭不上。
下面那排才是真正的技术分歧
五条路线各自补一个不同的缺口。它们不是互斥的候选项，实际是并行推进、互相供料的关系——第 14 页会画出依赖图。
把这四层分开，讨论才不会打架
「多 agent 能不能通向 AGI」这类问题之所以吵不出结果，是因为把工程手段和能力来源放在同一层比较。先问一句「这个词是目标、是机制、是能力来源，还是组织方式」，一半的争论会自己消失。

共同的出发点：今天的模型到底缺什么

五条路线不是凭空冒出来的。它们各自在补今天这套「预训练 + 后训练 + 冻结权重上线」范式的一个具体缺口——先看缺口，路线就不需要背了。
缺口具体表现为什么这套范式天生解不了谁来补
不会变强上线之后权重就是常数，用一万次和用一次一样聪明训练和推理是两个分离的阶段，推理路径上根本没有梯度连续学习
没有信号写作、研究、决策这类任务，做完了也不知道做得对不对人类偏好标注贵且会被 hack，规模上不去RL + 可验证环境
没有后果只见过文字描述的世界，没有「动一下会怎样」的经验语料里全是别人行动的结果，没有自己行动的因果世界模型 · 具身
料要见底高质量公开文本是有限的，重复训收益迅速下降预训练的燃料是存量语料，不随算力增长继续 scaling 的转向
四个缺口其实是两类
前两个是信号问题：不知道自己做得对不对，也没有通道把「对不对」写回权重。后两个是经验问题：没有第一人称的、带后果的数据。
后面每一条路线，往回追都会落到这两类之一。
今天的补丁都在模型外面
上下文窗口、RAG、记忆文件、工具调用、agent 框架——全是外挂：绕过模型不能变的事实，而不是解决它。外挂有用，而且短期性价比最高，但它有一个硬上限：一切都得塞进上下文，而上下文不是长期记忆。

路线一 · 继续 scaling：红利没结束，但换了一根轴

两根曲线的形状完全不同。蓝的在变平——不是失效，是每多一分能力要付的算力在指数上涨；橙的刚起步，同一个模型多想一会儿就能明显更准。「scaling 撞墙了」这句话只对蓝的成立。
预训练 scaling 的账
经验规律是 D ≈ 20P，算力 C = 6PD。要让能力再上一个台阶，参数和数据得同步放大——于是算力按平方涨，而数据这一头根本跟不上。
数据是存量，不是流量
算力可以造，芯片可以扩产，但人类写过的高质量文本是一个固定的数。重复训同一批数据，收益衰减得很快。合成数据、多模态、私域数据是三种续命方式，都不改变量级。
推理时 scaling 是真的新轴
让模型多想、多采样、自我检查，准确率随思考长度的对数上升。它把「知识存在权重里」换成「答案现场搜出来」——绕开了数据墙，代价是每次调用都要付。
这一轴现在的量级还剩多少空间成本结构
预训练算力前沿训练约 1e26 FLOPs 量级还能涨，卡在电力、芯片供给和建设周期一次性投入，之后每次推理都便宜
高质量数据公开文本约 1e13 token 量级接近见底，靠合成与多模态续，量级不变买不来也造不出，是硬约束
推理时算力一次回答 1e2 ~ 1e6 token刚开始，曲线还很陡每次调用都付，规模化后是大头
为什么「撞墙了」和「根本没撞」的人都对
他们说的不是同一根轴。预训练那根确实在变平——同样的投入换来的提升一年比一年小，这是事实；而模型的总能力还在快速涨，也是事实，因为增量来自另外两根：推理时算力，以及下一页的 RLVR。「scaling 还灵不灵」是个坏问题，好问题是「现在的边际收益在哪根轴上最高」。

路线二 · RL + 可验证环境：奖励从哪来

强化学习不是新东西，卡了十年的从来不是算法，是奖励。这条路线的全部内容就一句话：把「学出来的奖励」换成「算出来的奖励」。
RLHF：奖励是一个学出来的模型
人标注偏好 → 训一个 奖励模型 R̂ 策略去最大化 R̂，不是最大化真实好坏 于是： R̂ 越被优化，它越不准
这是 reward hacking 的数学根源：R̂ 只在标注数据的分布附近可信，而策略优化会主动把自己推到那个分布之外。所以 RLHF 必须加 KL 约束把策略拴住——拴住的同时也限死了能学多远。
人标注还有一个规模问题
标注质量的上限是标注者的水平。模型一旦在某个领域超过人类标注者，人类偏好就不再是有效信号——这是 RLHF 无法把模型带到超人水平的根本原因。
RLVR：奖励是一段代码算出来的
模型给出答案 → 跑一个 检查器 → 0 / 1 检查器可以是： 单元测试　编译器　数学答案比对 形式化证明检查器　游戏胜负　仿真器
奖励不可 hack（除非检查器本身有洞），不要人参与，可以无限量生成。模型比人强也没关系——检查器不是人，它只判对错。这三条合起来，才是这条路线被押注的原因。
瓶颈已经从算法挪到了环境
算法这一侧基本收敛（策略梯度那一族）。真正稀缺的是「能自动判分、难度可调、够多样」的环境。环境工程正在变成新的数据工程——这是当前投入最集中的地方。
0/1 太稀疏，怎么学得动
靠一次采一组：同一题采多条解，用组内的相对好坏当优势，省掉价值网络。
检查器有洞就一定会被钻
模型会写出「让测试通过但没实现功能」的代码。检查器的严密程度，就是这条路线能力的天花板。
难度必须跟着能力走
全对或全错都没有梯度。环境要能自动调难度，把通过率稳在中间——这部分工程量往往比算法本身大。
这条路线最大的未解问题：可验证域上学到的东西，能迁移出去吗
在数学和代码上用 RLVR 练出来的推理能力，看起来会部分溢出到没练过的领域——但溢出多少、靠什么机制溢出，目前没有定论。如果溢出很强，这条路线直通 AGI；如果只在可验证域内有效，它就只是一个很强的专用能力放大器。这一个问题的答案，决定后面四条路线的相对权重。

「可验证」的边界在哪：AGI 要的能力大半在右边

左边这一格已经不是瓶颈
数学和代码上，模型在标准评测上的表现已经很难再靠加难度拉开差距。继续在这一格投入，边际收益在下降。
中间这一格是当前主战场
做法是把模糊判分变成可执行判分：写细则、拆检查点、用模型当评委再交叉验证。本质是把右边的任务往左边挪。
右边这一格才决定 AGI
「什么值得做」这类判断没有检查器。人类靠长周期后果学会它——而长周期后果正是今天最缺的训练信号。
怎么判断一个任务落在哪一格
问一句：能不能写一段程序，只看结果就判定对错，而且不需要人。能，是左边；只能给个分数或排序，是中间；连打分标准都要吵，是右边。
一个反直觉的事实：可验证 ≠ 简单
奥数题和形式化证明都在最左边，它们一点也不简单。「难」和「难验证」是两回事——正因为如此，模型在最左边先超过了人，却在「写得好不好」上还很平庸。
所以这条路线的真正命题不是「RL 行不行」，而是「能把多少任务挪到左边」
每把一类任务从难验证挪到可验证，就等于给它开了一条无限量的训练数据通道。过去两年的进展大半来自这种「挪」，而不是来自更好的 RL 算法。能不能一路挪到最右边——也就是能不能给「判断力」造一个检查器——是这整张地图上最硬的问题。

路线三 · 连续学习：权重不再是只读的

今天的模型上线之后，权重 θ 就是一个常数。它服务一亿次，和服务第一次一样聪明——因为从「用得怎么样」回到 θ 的那条通路根本不存在。
外挂记忆：便宜、可控、上限明确
RAG、记忆文件、长上下文都属于绿线。好处是可审计、可删除、不会训坏；代价是每次都要重新读一遍。
红线难在「可塑性—稳定性」
学新的就容易忘旧的。一次梯度更新改的是全部参数，没法只动「关于这件事」的那一小块。
还有一个安全问题
权重能被在线改，就意味着被投毒的输入可以永久改变模型。这是连续学习没被大规模上线的真实原因之一。
写到哪一层写入方式保持多久容量量级能不能改变模型的「直觉」
上下文窗口直接塞进 prompt一次会话1e5 ~ 1e6 token不能
外部记忆 / RAG写文件、存向量库永久无上限不能，只是检索得更准
权重 θ梯度更新永久1e11 量级参数能——只有这一层能
这条路线的判据很简单：有没有真的动到第三行
大部分叫「记忆」「自我进化」的产品做的都是前两行。它们让模型「查得到」，但没让模型「学会」——区别在于关掉检索之后，模型还会不会。真做到第三行，需要在线的低秩增量、重放缓冲、以及一个能判断「这次该不该学」的信号；而那个信号，正是上一条路线要造的东西。

路线四 · 世界模型：在脑子里试，不用真试

世界模型学的是一件事：给定现在的状态和我要做的动作，接下来会变成什么样。学会它，模型就能在脑子里把方案跑一遍，不用真付代价。
这就是「规划」的全部含义——把试错从真实世界搬进模型内部。AlphaGo 走的是这条路，只不过它的世界模型是围棋规则，规则是精确的、免费的。难点在于：真实世界没有规则书，模型必须自己学，而学出来的一定不准。
卡点：误差会复合
每步误差 ε，往后展开 T 步： P(至少错一次) = 1 − (1−ε)^T ε=1%　T=20 　→　18% ε=1%　T=100　→　63% ε=5%　T=20 　→　64%
想象得越远越是在编故事。可用长度被单步精度卡死。
所以真正的用法是「短程想象 + 频繁校准」
在模型里只往前推几步，然后拿真实反馈拉回来。把 T 压小，是目前唯一有效的对策。
LLM 算不算世界模型
它学的是「人接下来会怎么写」，不是「事情接下来会怎样」。token 级，不是状态级。
为什么现在忽然热起来
视频生成模型被发现顺带学到了物体恒存、遮挡、重力。世界模型也许能从视频里学。
它和上一条路线是同一件事的两面
一个够准的世界模型本身就是仿真器，也就是检查器——RLVR 缺的环境可以由它批量造。
最容易被跳过的一句话：世界模型不解决「该做什么」，只解决「做了会怎样」
它给的是状态转移，不是价值判断。知道每条路通向哪里，和知道哪条路值得走，是两个独立的问题——后者仍然要回到第 6 页最右边那一格。把世界模型当成 AGI 的完整答案，是把「预测」和「取舍」混成了一件事。

路线五 · 具身智能：唯一还能自己造数据的地方

前四条路线争的都是怎么把存量数据榨得更干净。这一条不一样——它是唯一一条能凭空生出新数据的路线，因为动作真的会改变世界。
它补的是「没有后果」那个缺口
语料里全是别人行动的结果。具身给的是第一人称的因果：我推了，它倒了。
卡点一：真机数据贵得离谱
一条轨迹要一台机器、一个场地、一段真实时间。这部分不能靠买卡加速。
卡点二：仿真和真实之间有缝
仿真里可以刷无限数据，但摩擦、形变、光照都对不上。缝有多宽，决定仿真数据值多少钱。
数据来源今天的量级是存量还是流量带不带因果
公开高质量文本1e13 token存量，接近见底没有——记录的是别人行动的结果
网络视频1e9 小时量级存量，还有余量有物理，但没有动作标签
仿真轨迹想刷多少有多少看着像流量，但只在仿真里有因果，但物理对不准
真机交互轨迹1e6 条量级流量，机器越多数据越多有，而且是第一人称的
这条路线的时钟和别的不一样：它受物理时间约束
前四条路线的瓶颈是算力和数据，加钱能换速度；这一条的瓶颈里有一段是真实时间——一台机器一天只能试那么多次，一个抓取动作就是要花三秒。所以它大概率是最慢的一条，但也是唯一一条越走数据越多、不会枯竭的路。上面表里那七个数量级的差距，就是它今天的全部处境。

多 agent 分工：它放大已有能力，不产生新能力

这个词和前面五条不在一层。它不改变模型能做什么，只改变已有能力怎么被组织——判断它有没有用只要问一句：被切开的是什么？
投票到底能省多少错，是一道算得出来的题
三个 agent 各答一次，多数投票。单个错误率 30% 错误完全独立 → 投票后错 21.6% 少了三成 错误完全相关 → 投票后错 30.0% 一点没少 同一个模型、同一份权重，落在哪一端？
唯一真能提质量的情形：查比做容易
一个写、一个查，而且检查这件事本身比生成更容易、更接近可验证——那么第二个 agent 才带来了新信息。这其实就是第 5 页的检查器换了个包装：有用的不是「多一个 agent」，是「多一个独立的判据」。
链一长，误差照样复合
和第 8 页是同一个式子。每步 95% 成功，10 步串起来只剩 0.95¹⁰ ≈ 60%。分工越细、链越长，端到端成功率掉得越快——这就是多 agent 系统最常见的翻车方式。
还有一个常被忽略的硬约束：agent 之间的带宽只有自然语言
同一个模型内部，信息以高维向量流动；一旦拆成两个 agent，中间就只剩一段文字。拆开的代价是把稠密表示压成了几百个 token。人的组织也有这个问题，但人可以长期共事、积累默契和共享上下文；agent 每一次都是从零开始读一段话。所以「像公司一样组织 agent」这个类比，恰恰漏掉了公司里最值钱的那部分。

RSI 递归自我改进：把前面几条接成一个环

RSI 不是第六条路线。它是路线二和路线三接上之后自动出现的性质——一个能判分的信号，加一条把改进写回去的通道，环就闭上了。
环改的是哪一层具体做法今天到哪了天花板在哪
提示与工具（外层）agent 自己写工具、改 prompt、搭流程已经在发生，成本极低模型本身没变，改到头就是模型的上限
数据与课程（中层）自己出题判分，筛出有用样本喂下一轮部分在做：合成数据、拒绝采样判分一旦不可靠，就会把噪声当信号越训越偏
权重与架构（内层）自己设计训练方案、改架构、改优化器基本没发生要跑完一次训练才知道好坏，反馈周期以月计
为什么现在还没有起飞：改进的边际成本一直在涨
把能力的增长率写成 dC/dt = f(C)：f 次线性就是缓慢逼近，f 线性是指数增长，f 超线性才是有限时间内起飞。迄今为止的经验事实是 f 次线性——数据越来越难找、算力越来越贵、剩下的问题越来越硬，每一代改进都比上一代贵。所以真正的问题不是「模型能不能改自己」（那已经在发生了），而是「改完之后，它改自己的能力有没有变强」。这五条路线加起来能不能把 f 推过线性那条线，就是 RSI 的全部悬念。

AGI 这个词，其实有三派互不兼容的定义

前面十页都在讲「怎么走」。但终点画在哪里，会反过来决定该走哪条路——而这个终点，业界从来没谈拢过。
一 · 能力覆盖式
算不算到了：人能干的有经济价值的活，它都能干。
怎么度量：覆盖率 × 任务时长跨度。
它指向：scaling、RLVR、多 agent——先把覆盖率拉满。
二 · 自主式
算不算到了：没人盯着，也能把开放式目标做完。
怎么度量：无人干预下能连续工作多久。
它指向：可靠性、长程一致性、世界模型。
三 · 学习式
算不算到了：进到一个全新领域，能从零学会。
怎么度量：样本效率——学会新事要几个例子。
它指向：连续学习和 RSI，别的都是绕路。
AGI 不是一个开关
三派量的都是连续的东西，没有哪一天忽然「到了」。争「到没到」不如争「哪个数在涨」。
过了某个考试不等于到了
评测会被污染，也会被针对性优化。分数涨了，不一定是能力涨了。
ASI 是另一个问题
超过人类 ≠ 通用。在数学和代码上早就超人了，通用性一点没多。
为什么要先把定义摊开：它直接决定你该盯哪一条路线
三派测的根本不是同一件事。覆盖式关心「会多少」，自主式关心「能扛多久」，学习式关心「会不会学」——一个系统完全可能在前两项上很强、第三项上是零。所以当有人说「AGI 快到了」而另一个人说「还早得很」，八成不是判断不同，是他们心里的终点不在同一个地方。这也是这张地图上最容易被跳过、却最影响结论的一步。

六条路线各自卡在哪：一页对照

前面一条一条讲完了，把它们并排放在一起看。最后一列是这张表里最有用的东西——它是判据，不是描述。
路线现在到哪了卡在哪什么信号出现，说明它真动了
继续 scaling预训练那根在变平，推理时那根刚起步高质量数据是存量；电力、芯片、建设周期同等算力下，预训练损失还按老斜率降
RL + 可验证环境强可验证域已经跑通并且拉不开差距环境不够多；判分做不了的地方过不去弱可验证任务上出现稳定可复现的判分
连续学习只有外挂记忆，权重仍然是冻结的灾难性遗忘、更新是全局的、投毒风险上线模型的权重开始按周更新且不退化
世界模型视频模型被发现顺带学到了一些物理单步误差会复合，长程一致性撑不住想象 100 步之后，仍然和真实对得上
具身智能真机数据比文本少七个数量级数据、sim2real、硬件，还有真实时间一套策略跨机型、跨场景直接能用
多 agent 分工工程上已经普及，收益主要在省上下文带宽只有自然语言、错误相关、链一长就掉端到端成功率随 agent 数上升而上升
RSI只在最外层（改提示与工具）发生判分和写回这两格都还是空的模型自己产出的改进，让下一代改得更快
前三列会过时，最后一列不会
「现在到哪」半年就要重写一遍，但「什么信号说明它动了」是稳定的。盯信号，而不是盯发布会——大部分声称的突破，都对不上最后那一列。
这六行不是六条并行的赛道
它们互相是对方的前置条件。卡住其中一条，会同时卡住另外三条；反过来，某一条松动，收益也会顺着依赖关系传出去——下一页把这张关系图画出来。
同一张表也是一张风险表：卡点的性质，比卡点本身更能预测什么时候松动
scaling 卡在物理供给——能解，只是贵和慢，时间表基本可预测；RLVR 和世界模型卡在方法——可能一篇论文就松开，也可能十年不动，方差最大；具身卡在真实时间——最不可压缩的一种，加钱也换不来；连续学习卡在安全和工程——技术上未必最难，却最容易被低估，因为它动的是已上线系统的权重。
这张表上没有的一行：对齐与可控
六行讲的都是「能力从哪来」，没有一行在讲「能力变强之后，怎么保证它做的是我们想要的」。它不是第七条路线，而是每条路线各自要交的作业：可验证环境要防判分被 hack，连续学习要防在线投毒，RSI 要防目标在自我改进中漂移。能力这一侧走得越快，这门作业就越贵——而它恰恰没有自己的 scaling 曲线。

它们不是竞争关系：真正的瓶颈只有两个

把六条路线的依赖关系画出来，会看到它们其实是一条供料链上的不同环节——决定整体速度的，从来不是最快的那一环。
箭头是有方向的
上游不动，下游就拿不到料。具身不动，世界模型的数据就只剩视频。
两个红格子是同一件事的两半
一个负责判断「改好了没有」，一个负责把改动写回去。缺任何一个，环都闭不上。
多 agent 没有出边
它能让今天的能力更好用，但不会把这张图往右推一格。
所以这张图真正的读法：不是挑一条路线站队，而是找链上最紧的那一环
五条能力路线不是五个候选项，是一条供料链上的五个环节；整体速度由最紧的一环决定，而不是由跑得最快的那一环决定。今天最紧的两环都是红的：既没有足够多、足够严的判分器，也没有把学到的东西写回权重的通道。其他四条路线的所有进展，最后都要经过这两格，才能变成「模型自己会变强」这件事。如果只盯一个问题，就盯这两格什么时候不再是红的。

最后把八个词放回各自的位置。不在一层的东西不该放在一起比——这也是这份材料从头到尾唯一想说清的事。

最硬的一个问题
能不能给「判断力」造一个检查器。第 6 页最右边那一格，今天基本无解。
最值得盯的一个现象
模型自己产出的改进，能不能让下一代改得更快。也就是 f 推过线性那一刻。
最容易被高估的一个词
多 agent 分工。它很有用，但它在依赖图上没有出边，不会把终点往前推。
最后一句
八个词里只有五个在回答「新能力从哪来」，其余三个分别是终点、机制和组织方式。把它们摆回各自的层，大多数关于「AGI 还有多远」的争论，就会变成一个可以查证的具体问题：第 14 页那两个红格子，今天有没有变化。
带走一个自检办法就够了
