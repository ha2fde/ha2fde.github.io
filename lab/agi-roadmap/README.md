# 从这里到 AGI：八个词的地图

内部归档。15 页。

把「继续 scaling / RL+可验证环境 / 连续学习 / 多 agent 分工 / 世界模型 / 具身智能 / AGI / RSI」
这八个词摆回各自的层级——目标（AGI）、元路线（RSI）、五条能力路线、一个工程手段（多 agent）——
然后逐条讲各自在解什么问题、卡在哪、彼此是什么依赖关系。

结论落在第 14 页：五条路线不是竞争关系，是一条供料链；今天最紧的两环是
「RL+可验证环境（评价信号）」和「连续学习（写回通道）」。
