Language Agent：现代 AI Agent 的统一范式与通往 AGI 的必然之路

2026-07-25 · 约 20 分钟
核心论点
  • 当前学术界至少存在 6 套以上并行且互不兼容的 AI Agent 分类体系，这种混乱源于缺少一个统一的分类轴心
  • 但所有体系在实践层面高度一致：几乎全部在讨论以语言模型为推理核心的 Language Agent
  • Claude Code、OpenAI Codex、OpenCode、OpenClaw、LangChain、LangGraph——这些今天被笼统称为"AI Agent"的系统，本质上都是 Language Agent
  • 语言是人类认知的介质，而人类认知是 AGI 唯一的存在证明——以语言为核心的 Agent 架构不是偶然的工程选择，而是通往 AGI 的必然路径
图 1：多重分类体系在 Language Agent 框架下的统一。左侧是 5 种不同的分类视角，右侧是它们共同的本质结构——以 LLM 语言中枢为核心、挂载工具/记忆/感知/行动子系统的统一架构。

一、分类学的困境：六套体系，一个盲区

2025-2026 年，AI Agent 的分类学经历了一次爆发。几乎每个月都有新的综述论文提出新的分类框架。但将这些体系放在一起对比时，一个尴尬的事实浮出水面：它们分类的维度不同、层次不同、粒度不同，彼此之间甚至无法简单地"对应"起来。

我们整理了过去一年最具影响力的六种分类方案：

分类体系来源分类维度典型类别
经典五分类 Russell & Norvig, "AI: A Modern Approach" 认知架构 Simple Reflex → Model-based Reflex → Goal-based → Utility-based → Learning
能力分类 Luo et al., arXiv 2503.21460 (2025), 329 篇综述 功能模块 Planning / Tool Use / Memory / Reasoning / Self-improvement / Perception
概念分类 Sapkota et al., arXiv 2505.10468 / Information Fusion (2025) 范式演进 AI Agents（任务专用模块化） vs. Agentic AI（多 Agent 协同自主）

这种分类的"景观多样性"本身就是有意义的信号。它说明：AI Agent 还是一个尚未被充分理解的新物种——就像一个盲人摸象的寓言，有人摸到鼻子（规划）、有人摸到腿（工具）、有人摸到尾巴（自主性），每个人都在描述自己触碰到的局部，但还没有人摸到整头大象。

关键洞察：仔细审视这六套体系会发现，它们默认的"原型"都是同一个东西——一个以语言模型作为推理核心、以自然语言作为内部表示和通信协议的智能体。没有一套分类是为符号 Agent、纯 RL Agent 或进化 Agent 设计的。它们的分类粒度不同，但分类对象完全相同。

二、"Language Agent"：被忽略的轴心

学术界有一个令人费解的现象：几乎所有被讨论的 AI Agent 本质都是 Language Agent，但几乎没有人用这个术语。

Luo et al. (2025) 的 329 篇论文综述直接以 "Large Language Model Agent: A Survey" 为标题——但在正文中，他们用 "LLM Agent" 而非 "Language Agent"。Sapkota et al. (2025) 区分了 "AI Agents" 和 "Agentic AI"，但两者共享一个前提：推理核心是 LLM。Rombaut (2026) 分析了 13 个开源 coding agent scaffold，所有 13 个都基于 LLM。

这种命名上的空缺不是偶然的。它反映了学术界的"分类惯性"：研究社区习惯于从"模型类型"（LLM-based vs. RL-based vs. symbolic）来定义 agent，而不是从更本质的维度——信息表示方式——来定义。

Language Agent 的定义：一个以自然语言作为内部推理介质和外部接口的自主智能系统。其核心是一组语言模型，负责感知输入、推理规划、生成行动指令；外围挂载工具调用、记忆检索、感知编码、行动执行等子系统。整个系统的信息流以文本 token为主干，结构化数据（代码、数据库记录、API 响应）被序列化为文本后汇入主循环。

从这个定义出发，我们日常接触和使用的"AI Agent"产品本质都是 Language Agent：

这些系统的多样性并不在"是不是 Language Agent"这个层面——它们全都是。多样性在于它们的 Scaffold（控制循环、工具集、记忆策略、编排拓扑）不同，而这恰恰是 Rombaut (2026) 的论文所揭示的核心主题：真正的架构差异化发生在 scaffold 层，而不是模型层。

三、为什么是语言？认知科学的必然性

Language Agent 不是偶然的工程选择。它之所以主导了整个领域，背后有深刻的认知科学原因：语言是人类高级认知的唯一已知载体。

人类大脑中并没有一个"专用推理模块"和一个"专用语言模块"。神经科学的研究表明，大脑的默认模式网络（DMN）、前额叶皮层（PFC）和语言网络在执行复杂推理时高度协同。Vygotsky (1934) 早已指出，内化的"自我对话"（private speech / inner speech）是高级认知功能的基础——儿童从"边做边说"逐渐内化为"内部语言思考"，这个过程就是 ReAct 范式的生物学原型。

更直接地说：人类智能的存在证明只有一种——人类智能本身。而人类智能的核心特征就是：使用语言进行内省、规划、回溯、自我纠错。如果我们要构建 AGI，逻辑上最直接的路径就是让 AI 拥有同样的核心能力，然后围绕它构建 感知-记忆-行动 的完整循环。

图 3：人类认知模块与 Language Agent 架构的直观类比。不是巧合——LLM-based agent 架构是已知唯一与人类认知架构形成系统对应关系的人工智能范式。

四、AGI 之路：Language Agent 何以是必然的中间站

如果我们把 AGI 看作终点，那么历史上曾经有过几条候选路径：

路径代表状态为何未能成为主流
符号 AI（Symbolic）专家系统、Cyc、Soar边缘化无法处理模糊性和开放域问题，知识工程瓶颈
强化学习（RL）AlphaGo、MuZero、SAC子领域在封闭环境中优秀，但无法处理人类知识的多样性和自然语言
进化算法NEAT、CMA-ES边缘化计算量巨大，缺乏人类知识注入的接口
神经符号（Neuro-symbolic）DeepProbLog、Neural Theorem Provers研究阶段可扩展性差，尚未形成通用范式
Language Agent（当前路径）GPT-4o/Claude + Agent Scaffold主流——

为什么 Language Agent 最终胜出了？四个不可替代的优势：

4.1 人类知识的天然接口

人类积累了数千年的人类知识，以自然语言的形式存储在书籍、文档、代码、论文中。Language Agent 可以直接"读懂"这些知识，而符号系统和 RL 系统需要人工翻译和重新编码。这意味着 Language Agent 的"初始化成本"远低于任何其他范式。

4.2 与人类对齐的自然通道

AGI 不仅需要能力，还需要与人类价值观对齐。Language Agent 通过指令微调（Instruction Tuning）和 RLHF 实现对齐——这些方法的核心都是语言。你可以直接"告诉"一个 Language Agent 应该如何行事，无需为它设计复杂的奖励函数或符号规则。

4.3 工具化的可扩展性

Language Agent 通过"教会模型调用工具"而不是"教会模型理解每个领域"来扩展能力。模型不需要知道文件系统的工作原理，只需要知道如何调用 read_file 函数并理解返回值。这种架构使得 Language Agent 的能力扩展基本不受模型本身的限制——MCP 协议的出现标志着这一思路已进入标准化阶段。

4.4 飞轮效应的正反馈循环

2025-2026 年，Language Agent 已经形成了一个自我加速的经济飞轮：更多资本 → 更大算力 → 更强的 LLM → 更好的 Agent → 更多的应用 → 更多的收入 → 更多资本。这个循环的唯一"燃料"是语言模型的能力提升——而提升语言模型能力这件事，本身就是整个行业的核心课题。

图 4：Language Agent 的正反馈飞轮。Scaling Law + Agent 能力提升 + 商业价值形成闭环，这使得其他路径（符号 AI、纯 RL）在经济上难以竞争。

五、来自行业前线的验证：梁文锋的 AGI 阶梯

文章的理论推演至此已经形成了一个完整的逻辑链条。但一个严肃的问题是：这套理论仅仅是我们坐在书桌前的推导，还是被行业一线实践者验证过？

2026 年 7 月，DeepSeek 创始人梁文锋在一场长达 4 小时的投资人闭门会议上，系统阐述了 DeepSeek 对 AGI 实现路径的判断。这场会议的完整记录（118 轮问答）随后在中文和英文媒体广泛传播，被认为是 2026 年最重要的 AI 战略陈述之一。而其中最引人注目的，就是他提出的 AGI 阶梯（AGI Staircase）——一个与本文的分析框架高度吻合的路线图。

梁文锋的原话（根据多家媒体交叉验证的会议实录）：

"AI 的发展，我们可以理解成它是一个阶梯。去年走的阶梯是 CoT（思维链），我们发现通过思维链的方式，可以让智能达到一个更高的水平。今年的阶梯就是 Agent，因为我们发现，用 Agent 的方式，AI 的能力范围会更大，智能上限会更高。为什么是阶梯？因为后面的每一步都是基于前面的基础之上的，Agent 要用到 CoT，CoT 也要用到前面的语言模型，没有一步是白走的。"

他将 AGI 的实现路径明确划分为六个阶段：

这个路线图与本文的论点形成了精彩的互证：

AGI 需要超越语言（具身、持续学习） ⑤⑥ 持续学习 → AI 自我迭代 → 具身智能
关键在于：梁文锋的阶梯中，第③步 "Agent" 完全建立在语言推理之上。他没有把 Agent 看作与语言模型并列的东西——Agent 是语言模型能力的延伸，是"用语言去调用工具、规划步骤、完成任务"的系统。这正是本文所说的 LLM-based AI Agent = Language Agent。当全球最顶尖的 AI 实验室之一用"阶梯"来描述这条路径时，我们的理论推演获得了来自产业一线的强力验证。

更有意思的是梁文锋对"当前最重要的事"的判断：

"国内以目前的情况来看的话，我觉得最合理的做法应该是全力做通用 Agent，其他的 Agent 优先级应该更低，包括金融、医生这些 Agent。要先做 Coding，因为 Coding Agent 能够做到很多。

在 Agent 之后，它还是替代不了人类员工。因为 AI 还差一个地方，叫持续学习。人能持续学习，你招一个员工，他花两个月熟悉公司环境就能上手，但 AI 没有这两个月的学习，你就要把所有的上下文都给它。

持续学习之后，我们可能就会来到一个奇点。当模型能够持续学习之后，它已经能做人类能做的所有事情了。它能自己开发自己的版本，自己做研究去开发下一个更强的人工智能模型。这一步走完之后，才是具身智能。"

这段话精练地概括了本文的核心论点：Language Agent 是当前的"最佳生态位"——它足够强大以产生巨大的商业和技术价值，但距离真正的 AGI 还差一个关键能力（持续学习）。而 DeepSeek 这样的公司，正在押注解决这个缺口后，AI 将进入自我加速的"奇点"阶段。

六、但这不等于 AGI：Language Agent 的边界

Language Agent 是通往 AGI 的必然路径，但它本身还不是 AGI。当前 Language Agent 面临几个根本性限制：

5.1 没有真正的"理解"

LLM 的推理本质是基于统计分布的预测。虽然没有严格的理论证明语言模型"不可能"有理解，但当前的经验证据表明：模型的"理解"是脆弱的，在分布外（OOD）场景下极易崩塌。Sapkota et al. (2025) 将这个问题归入 Agentic AI 的核心挑战类别。

5.2 缺乏持续自我改进机制

人类智能的核心特征之一是持续的自我改进——你可以不断从经验中学习，昨天的任务完成方式会影响明天的策略。当前的 Language Agent 基本是"无状态的"：每个任务启动时，Agent 的记忆库为空或只包含静态的知识库。Rombaut (2026) 分析的 13 个 coding agent 中，没有一个实现了跨任务的持续学习。

5.3 记忆架构的瓶颈

Shichun-Liu et al. (2025) 的综述"Memory in the Age of AI Agents"提出了一种统一的 Agent 记忆分类：事实性记忆（Factual）、经验性记忆（Experiential）和工作记忆（Working）。当前的 Language Agent 在工具层面已经有了一定的工作记忆管理（context window 管理、token 压缩），但在经验性记忆（跨 session 的学习）方面几乎空白。这也是 LangChain 和 LangGraph 等框架正在试图解决的问题——通过持久化状态图来替代无状态的对话式记忆。

关键观察：Language Agent vs. AGI 的区别，本质上就是"能用语言推理"vs."能通过语言学习并持续进化"的区别。前者是实现后者的必要条件，不是充分条件。

六、为什么要说"Language Agent"而不是"AI Agent"？

现在让我们回到这个被回避的问题：为什么市场不使用"Language Agent"这个更精确的术语？

原因有三：

第一，术语惯性。 "AI Agent" 是 1980 年代就存在的概念，产业界只是把"传统 AI Agent"替换成了"LLM-based AI Agent"。ChatGPT 的爆发让整个行业习惯了大模型的能力，当 Agent 框架（LangChain / AutoGPT）在 2023 年兴起时，"AI Agent"是最自然的继承词。没有人会刻意说"Language Agent"——就像没有人说"Internal-Combustion-Engine Car"一样。

第二，技术栈的混合性。 今天的 Agent 不像纯粹的 Language Agent。它调用代码解释器（RL 训练的符号执行器）、运行视觉模型（Vision Transformer）、使用向量数据库（非语言数据结构）。说"Language Agent"似乎低估了这些非语言组件的贡献。但 Sapkota et al. (2025) 的论文已经清楚阐明：核心推理回路仍然是语言驱动的——视觉信息被编码为文本描述，工具调用被序列化为函数名和参数，所有异构数据在进入推理循环前被投影到语言空间。

第三，商业定位。 "AI Agent"听起来比"Language Agent"更广泛、更宏大。在一个融资驱动的市场中，用更大的概念装产品是天然动机。Presenc AI 的 5-tier 分类中，Tier 4 以上的 Agent 正在努力摆脱"语言驱动"的印象——"Autonomous"比"Language-based"听起来更像真正的智能。

但区分是有用的。 说"Language Agent"而不是"AI Agent"，不是为了缩小范围，而是为了精确描述本质。它帮助我们理解：为什么这些系统的能力天花板取决于 LLM 的推理质量？为什么工具调用协议（MCP、Function Calling）如此重要？为什么记忆和持续学习是下一个关键突破点？因为核心是一个语言推理引擎，所有外围组件都在为这个引擎服务。

综合我们讨论的所有材料，可以提炼出一个简洁的分析框架：

图 6：Language Agent 的统一分析框架——从必然性到当前状态到 AGI 的缺口。

核心命题：Language Agent 不是 AI Agent 的一个子类，而是当前所有有实际影响力的 AI Agent 的本质共性。不管你用 Presenc 的 5-tier 分级、Luo et al. 的能力分类、Sapkota et al. 的概念分类，还是 Rombaut 的 scaffold 分析，分类对象始终是同一个——以语言为推理介质的智能系统。承认这个共性，不是为了收窄视野，而是为了更清晰地看到：这个范式的能力边界在哪里，需要什么突破才能迈向 AGI。

未来展望：Language Agent + 持续自我改进 + 长期经验性记忆 ≈ Agentic AI → AGI。语言是种子，但大树需要更多。
