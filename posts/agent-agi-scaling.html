Agent 与 AGI：数据、缩放定律与下一个「预测下一个词」

2026-07-27 · 约 30 分钟

2026 年中，AI Agent 已从 2024 年的概念泡沫进入生产就绪的早期阶段。然而一个根本问题始终悬而未决：Agent 技术到底在通向 AGI（通用人工智能）的道路上扮演什么角色？ 本文从 smolagents 架构图出发，对照 Sutton 的「苦教训」、EdgeBench 缩放定律、Orca 世界模型等 2025–2026 年学术界和工业界最新研究发现，系统性地梳理这一问题的答案。

核心问题只有一个：AI Agent 技术到底在通向 AGI 的道路上扮演什么角色？

一、Agent 技术的当前成熟度

2026 年中，AI Agent 已度过 2024 年的泡沫顶端，进入「生产就绪的早期」，但远未成熟。

  • 57.3% 的受访组织已有 Agent 在生产环境运行（LangChain State of AI Agents 2026, n=1,300+）
  • 但生产中的 Agent 大多保守可控：68% 执行不超过 10 步就有人工介入，74% 依赖人工评估
  • Gartner 预测 40%+ 的 Agent 项目将在 2027 前被取消，原因：成本高企、价值不明、风控不足
  • 97% 企业预期 12 个月内会发生 Agent 安全事件（State of AI Agents Q2 2026），但仅 6% 安全预算投向此领域
  • McKinsey 2026 AI Trust 调查：平均 RAI 成熟度仅从 2.0 升至 2.3（5 分制），治理与 Agent 控制维度最落后

一句话总结：Agent 的能力已超过组织准备好接纳它们的速度。瓶颈从「模型不够强」转移到了「如何安全可靠地治理它」。

三、核心论证：Agent 对 AGI 的四种价值

3.1 架构层的价值：Agent 是 AGI 的「操作系统」

回看人类自身：我们有通用智能，但仍然需要工具（计算器、电脑）、记忆系统（笔记、Notion）、安全边界（法律、公司制度）、行动执行层（手、嘴、工具）、观察反馈循环。这些是什么？正是 Agent 架构的核心组件——感知→推理→行动→观察→迭代。

一个真正通用的智能，放在现实世界中做事，天然就需要 Agent 这一层。AGI 会吃掉「推理和规划不需要人帮」的那一侧，但 Agent 架构中的身份、权限、工具交互、记忆治理、安全护栏——这些从来不是模型的缺陷补偿，而是任何智能体在现实世界中的生存必需品。

用 Sutton 的「苦教训」（The Bitter Lesson, 2019）框架看：Agent 框架中的手工工程（ReAct prompt 模板、tool schema 定义、记忆管理策略）大概率会被 scaling 淘汰。但工具调用接口、安全边界、身份与审计——这些是智能体在真实世界中运作的基础设施，不随模型能力提升而消失，只会被吸收进系统架构的更底层。

3.2 数据的价值：Agent 生产 AGI 所需的「交互轨迹数据」

这是本节最核心的论点。传统 LLM 训练数据是人类静态产出的快照——互联网文本记录的是「结果」而非「过程」。模型从文本上学习「如何写代码」，但在训练中从未体验过「执行代码 → 看报错 → 修复」的闭环。

Agent 产生的数据跟传统数据有本质区别：

  • 错误数据：什么情况下 Agent 会犯错？为什么？
  • 恢复数据：犯错之后怎么发现、怎么回滚、怎么修正？
  • 工具交互数据：API 返回什么格式、什么错误码、什么超时行为？
  • 长程依赖数据：第 1 步的动作在第 15 步才产生影响，模型能否追踪因果？
  • 环境反馈数据：shell 输出、网页渲染、数据库错误——多模态环境信号

2026 年 ACL 的 TDScaling 工作（Chen et al., ACL 2026 Findings）进一步证明：轨迹数据的多样性比数量更重要——在固定训练预算下，增加轨迹多样性带来的收益远大于单纯堆量。这提示我们，Agent 交互数据的结构化多样性是 scaling 的关键维度，而非简单的「越多越好」。

3.3 缩放定律的价值：环境学习遵循可预测的数学规律

EdgeBench（arXiv:2607.05155, 2026）在 134 个真实世界任务、约 38,000 小时的 Agent 环境交互数据中，发现了令人震惊的结果：

  • 环境学习遵循精确的 log-sigmoid 缩放定律（R² = 0.998），与预训练的幂律缩放具有相同的数学形式
  • Agent 学习速度大约每三个月翻一番——从 2025 年 9 月的 GPT-5-Codex 到 2026 年 4 月的 GPT-5.5，学习速度提升了约 8 倍
  • Agent 从环境中积累和复用经验带来的提升，远超独立重新采样（12 小时后 +6.9 分）

ACL 2026 的另一项系统性研究（Scaling Behaviors of LLM RL Post-Training）在 63 次实验、横跨 0.5B–72B 参数的规模上证实：RL 后训练同样遵循可预测的幂律关系，且更大的模型具有更高的计算和数据效率。学习效率随模型规模增长呈现饱和趋势——边际收益在 32B 参数以上递减。

这些发现共同说明：Agent 在环境中通过交互学习，不是一个黑箱过程，而是一个可测量、可预测、可优化的缩放对象。

3.4 「预测下一个词」的类比：下一个可能是「预测下一个状态」

「预测下一个 token」之所以能产生 GPT-3 的所有涌现能力，取决于三个特性：自监督（数据就是标签）、任务均匀性（所有文本是同一格式）、压缩即智能（为准确预测不得不学会语言的全部隐结构）。

Agent 时代的候选等价物是「预测下一个观测（Next-State Prediction）」：

  • 自监督：Agent 执行动作 A 后真实结果是 O——模型的任务是预测 O，预测错了就更新
  • 任务均匀性：不管是调用 API、执行代码还是移动鼠标，都是 (状态, 动作) → 下一个观测
  • 压缩即因果：为准确预测「如果我把这个文件删除，会发生什么」——模型必须学习文件系统原理、权限模型、甚至用户心理模型

2026 年的多项前沿工作正在验证这个方向：

  • Orca（arXiv:2606.30534）明确将建模目标从 next-token/frame/action 转移到 Next-State-Prediction，学习统一的世界隐空间，通过无意识学习（连续视频的自然状态转换）和有意识学习（语言描述的事件）两种范式互补
  • NE-Dreamer（ICLR 2026）在 MBRL 中用因果 Transformer 预测下一个编码器嵌入，在记忆密集型任务上大幅超越 DreamerV3
  • WorldEvolver（arXiv:2606.30639）展示了世界模型可以通过测试时的情景记忆和语义记忆自我进化，而不需要更新模型参数
  • ACL 2026 的 From Word to World 工作证明，在文本环境中，LLM 可以作为隐式世界模型，通过 next-state prediction 改善下游 Agent 性能（WebShop 上 GPT-4o 提升 5.5%，ScienceWorld 上 warm-started RL 提升 15%）

这些工作共同指向一条清晰的路径：「预测下一个 token」让模型学到了语言的隐结构；「预测下一个观测」让模型学到世界的因果结构。两者加在一起，可能就是通用智能的全部。

四、关键辩驳与修正

以下是本文在论证过程中遇到的几个关键质疑，以及对照权威来源后的回答：

4.1 特斯拉的自动驾驶数据为什么不够？

真正区分 Tesla 数据和 Agent 数据的不是「数字 vs 物理」，而是动作空间的通用性和 reward signal 的生成速度：

维度Tesla FSDAgent（如 smolagents CodeAgent）
动作空间3–5 自由度连续控制（转向/加速/刹车）任意 Python 代码 + 任意工具 + 任意文本
观测空间语义闭合（道路、车辆、行人）语义无限开放（shell、网页、API、数据库错误）
reward 信号二元且延迟长（没撞＝好）语义丰富（编译通过、测试绿了、用户满意）
数据生成速度物理线性，1 车 1 小时＝1 小时数据可编程并行，一台机器生成百万条轨迹

特斯拉证明了「即使有数十亿英里的闭环交互数据，只要动作空间闭合，就不会涌现通用智能」。Agent 的动作空间是语言 + 代码 + 工具——这是人类知识的通用接口。

但这反过来也暴露了 Agent 的弱点：动作空间虽广但深度浅（几步就断、记忆临时、反馈回路脆弱），特斯拉虽窄但深（稳定执行毫秒级连续控制）。完美的 AGI 可能需要两者兼具。

4.2 AlphaGo Zero 为什么没有通向 AGI？

区别不在「循环是否足够多」，而在任务空间的开放性：

维度AlphaGo ZeroAgent 自我进化
目标函数固定：赢棋开放：任意自然语言目标
动作空间19×19 = 361 个点组合爆炸：任意代码 + 工具
环境模拟完全已知的规则系统部分已知、大量未知（真实 API、网络、代码行为）
反馈信号二元：胜/负模糊：编译过了但逻辑对吗？用户满意吗？

Agent 自我进化的任务空间是开放且不断扩展的——你今天写一个新的 API，Agent 明天就得学会用它。这种开放性才是 AGI 需要的压力。

4.3 Sutton 的「苦教训」在 2025 年的重要更新

2019 年，Richard Sutton 发表了著名的「苦教训」（The Bitter Lesson），核心论点是：通用方法 + 算力 scaling 永远会战胜注入人类知识的方法——围棋、语音识别、计算机视觉无不如此。

但在 2025 年，Sutton 本人做出了一个关键修正。在与 David Silver 合著的 Welcome to the Era of Experience 中，他提出：今天的 LLM 并不真正满足苦教训——它们通过模仿固定的人类文本来学习（mimicry），而不是从自身的交互经验中学习。真正的智能，来自 Agent 在环境中持续学习的能力。

这个修正的意义重大：它不是否定 Agent 的价值，而恰恰是反向肯定了 Agent 的必要性——如果 LLM 的「静态文本学习」已经走到天花板，那么下一步必须通过 Agent 的「交互式环境学习」来突破。

五、未来展望

5.1 短期（2027）：治理与标准化

  • Agent-to-Agent 经济：交易量达 $10B，Agent 自动发现、协商、消费第三方服务
  • 持久化 Agent 成标配：从「临时执行」到「持续运行、主动监控」
  • EU AI Act 全面执法：首批 Agent 领域重大执法案例
  • MCP + A2A 成为基础设施：像 REST/TLS 一样普遍
  • Agent 身份认证层成型：组织证书 + 能力证明 + 委托链

5.2 中期（2028–2029）：自主 Agent 纪元

  • Agent 从「执行任务」进化为「设定目标」——自己能定义目标和策略
  • 自我改进：Agent 自主发现优化方向并实施改进
  • 80–90% 的运营决策由 Agent 自主完成

5.3 长期（2030+）：Agent-Native 企业

  • 自组织 Agent 网络：生态系统有机形成与演化
  • Agent 经济：Agent 独立创造、交易、消费价值
  • Agent-人类混合劳动力：无缝协作成为组织常态
  • Gartner 预测到 2030 年，约 $2340 亿企业应用软件支出将受到 Agent 化影响

六、结论：Agent 不是通往 AGI 的弯路，而是它的「必要中间层」

历史上的每个重大技术跃迁都有这样一个阶段：

  • 飞行器的扑翼机阶段——在一个「错误」的方向上大量试错，但在这个过程中学会了材料、控制、空气动力学
  • AI 的专家系统阶段——没能做出真正的智能，但形成了知识表示、推理引擎这些可迁移的工程遗产

Agent 就是 LLM 时代的扑翼机。它大概率不是 AGI 的最终形态，但它在做一件无可替代的事：把通往 AGI 路上必须解决的问题暴露出来——长程推理、记忆整合、安全边界、身份信任、与物理世界的接口——然后倒逼这些领域前进。

用数据-算力-缩放定律的语言重新表述：

Agent 是人类第一次有能力大规模产生「智能体在真实数字世界中完整行动轨迹」的系统。这种数据在 2023 年之前不存在——互联网上找不到「调试 3 小时最终解决的完整 shell 日志」。2026 年的研究已经证明，这种环境学习遵循精确的缩放定律，学习速度本身也在加速。

如果「预测下一个观测」确实是 Agent 时代的「预测下一个词」，那么需要回看整个历史叠层才能理解它为什么在今天成为可能：

  • PC 贡献了通用可编程硬件——Agent 动作空间「任意代码」的物理基础
  • 互联网 贡献了人类知识的大规模数字化——LLM 的预训练语料
  • 移动互联网 贡献了十亿级用户规模——支撑千亿美金 GPU 投入的市场经济学
  • Agent 贡献了行动-观察-反馈的闭环——前面三层全部到位后才变得可能

整条链是：通用计算 → 通用信息 → 通用交互 → 通用行动 → 通用智能。每一步都把「通用」二字往外推了一层。Agent 不是这条链的终点，但它所在的位置，刚好是前面所有「通用化」收网的节点。

关于标准：不会有一个所有人都同意的 AGI「达成时刻」。就像意识一样——当系统覆盖了你关心的所有场景，你就认了；当它在某个你没注意的维度上犯错，你就说还不够。AGI 是逐步承认的，不是一刀切的。
