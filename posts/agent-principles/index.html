Agent 原理与实践

六章。每一章各自成篇，可以单独看，顺序随你。
  1. 01
    装上你的第一个 Agent
    客户端和模型是两回事，可以自由组合——怎么装、怎么换、要花多少钱，以及哪几条底线不能越。
    零基础 · 不写代码也能跟
  2. 02
    从机器学习到大模型
    Agent 底下压着的那套知识，一页讲透一块——机器学习、神经网络、Transformer，以及一个大模型怎么练出来、怎么送到用户面前。
    参考章 · 哪块不清楚翻哪块
  3. 03
    从 Chat 到 Agent
    一个只会续写的模型，是怎么一步步变成能自己干活的东西的——预训练、对齐、思维链、工具调用、上下文工程。
    工程课 · 讲清每一步加了什么
  4. 04
    Agent 的协议层
    tools、MCP、CLI、Skills、A2A 分别在解决什么问题——真实报文、角色关系，以及各自什么时候不该用。
    对接层 · 图和报文为主
  5. 05
    从 Demo 到生产
    先定控制权，再选工具——控制权是一条轴，怎么在轴上给自己定位，以及上线前必须能答上来的那些问题。
    决策型 · 附上线前清单
  6. 06
    从 Agent 到 AGI
    不预测，只讲清楚——Scaling、RL + 可验证环境、世界模型、连续学习、具身智能、RSI，六块拼图各自在补什么缺口、今天卡在哪，以及它们怎么拼成一张通向 AGI 的地图。
    观点型 · 不给时间表
