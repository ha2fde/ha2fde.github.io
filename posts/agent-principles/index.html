A G E N T

Agent 原理与实践

六章。每一章各自成篇，可以单独看，顺序随你。
  1. 01
    装上你的第一个 Agent
    客户端和模型是两回事，可以自由组合——怎么装、怎么换、要花多少钱，以及哪几条底线不能越。
    零基础 · 不写代码也能跟
  2. 02
    从图灵到 Transformer
    每一代都在解决上一代的什么瓶颈——两次寒冬、三大流派的交替，一直讲到自注意力为什么管用。
    概念课 · 一条线讲到底
  3. 03
    从 chat 到 agent
    一个只会续写的模型，是怎么一步步变成能自己干活的东西的——预训练、对齐、思维链、工具调用、上下文工程。
    工程课 · 讲清每一步加了什么
  4. 04
    Agent 的协议层
    tools、MCP、CLI、Skills、A2A 分别在解决什么问题——真实报文、实体关系，以及各自什么时候不该用。
    对接层 · 图和报文为主
  5. 05
    从 demo 到生产
    先定控制权，再选工具——连续谱上怎么给自己定位，以及上线前必须能答上来的那些问题。
    决策型 · 附上线前清单
  6. 06
    从 Agent 到 AGI
    不预测，只梳理路径——五条路线各自的主张、证据、瓶颈，以及如果它对了我们会先看到什么信号。
    观点型 · 不给时间表
