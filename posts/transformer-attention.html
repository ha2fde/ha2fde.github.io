Transformer：Attention Is All You Need——整个 LLM 时代的基石

2026-07-27 · 约 20 分钟 · LLM 进化史 ①

2017 年 6 月，Google 的 Vaswani 等 8 位作者发表了一篇至今仍在改写历史的论文：《Attention Is All You Need》。

这篇论文的核心信息极其简洁：只用注意力机制（Attention），不用 RNN 也不用 CNN，就能在序列建模任务上达到最佳效果。

一句话定位：Transformer 不是 LLM，但它是一切 LLM 的起点。没有 Transformer，就没有 GPT 系列、BERT、ChatGPT——这篇论文是整个深度学习时代的基石。

一、2017 年的困境：RNN 的效率瓶颈

在 Transformer 之前，序列建模（翻译、文本生成、语音识别）几乎完全由 RNN（循环神经网络） 主导。RNN 有两个根本问题：

  • 不能并行：必须从左到右逐个 token 计算，无法利用 GPU 的并行能力
  • 长程依赖困难：序列越长，早期信息越容易「遗忘」（即使有 LSTM/GRU 的改进）

当时有一些用 CNN 做序列建模的尝试（如 ByteNet、ConvS2S），可以部分并行，但要捕捉长程依赖需要堆叠很多层。

Transformer 的洞见：注意力机制本身就足够建模序列中的所有依赖关系——不需要循环，也不需要卷积。

二、核心架构：Encoder-Decoder

图1：Transformer 的 Encoder-Decoder 架构。Encoder 用自注意力理解输入，Decoder 用掩码自注意力生成输出，并通过交叉注意力连接两者。

三、核心创新

多头注意力（Multi-Head Attention）

Transformer 的核心公式就是注意力计算：

Attention(Q, K, V) = softmax(Q × K^T / √d_k) × V

通过把查询（Query）、键（Key）、值（Value）投影到多组不同的子空间并行计算注意力，模型能在不同的位置关注不同类型的语义关系：有的头关注语法关系，有的头关注语义相似性，有的头关注位置邻近性。

位置编码（Positional Encoding）

由于注意力机制本身没有顺序概念（它对所有位置的权重计算是对称的），Transformer 需要在输入中加入位置信息。论文使用正弦/余弦函数生成固定位置编码：

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

这种编码方式的精妙之处：不同位置的编码向量是不同的，且模型可以学会利用相对位置信息。

自注意力（Self-Attention） vs 交叉注意力（Cross-Attention）

  • 自注意力：Q、K、V 来自同一序列——捕捉序列内部的依赖关系
  • 交叉注意力：Q 来自 Decoder，K、V 来自 Encoder——把输入信息融合到生成过程中

四、关键结果

任务之前最佳Transformer提升
WMT 2014 英德翻译28.4 BLEU28.4 BLEU（持平但训练快 3 倍）-
WMT 2014 英法翻译41.0 BLEU41.8 BLEU+0.8
训练速度RNN: 数天12 小时（8 GPU）3-5× 更快

更大的突破在于：Transformer 可以在 GPU 上完全并行训练，这使得扩展到更大的数据、更大的模型成为可能。

五、Transformer 的三条分支

Transformer 架构的妙处在于它的通用性。此后整个 LLM 领域沿着三条分支发展：

图2：Transformer 的三条发展分支。Encoder-Decoder 延续原始设计，Encoder Only 专注理解（BERT），Decoder Only 专注生成（GPT）并最终胜出。

六、为什么这篇文章如此重要

《Attention Is All You Need》是深度学习历史上被引用最多的论文之一（2024 年已超过 10 万次引用）。它的影响力巨大到难以概括：

  • 替代 RNN/CNN：在几乎所有序列建模任务上，Transformer 成为了事实标准
  • 可并行训练：这是大模型得以扩展的先决条件
  • 架构通用性：Encoder-Decoder、Encoder Only、Decoder Only 三种变体覆盖了理解、生成、翻译等所有 NLP 任务
  • 跨界影响：Transformer 不仅用在 NLP——也渗透到了计算机视觉（ViT）、语音、多模态等领域

一句话总结：Transformer 用注意力机制替代了循环和卷积，让序列建模可以并行、可以扩展、可以统一。GPT-1、BERT、GPT-2、GPT-3、ChatGPT、GPT-4——全都是 Transformer。没有它，就没有后面的一切。
