117第六章 · 收束
01 · The Bitter Lesson

计算，终将战胜知识

  • 70 年 AI 研究史，反复证明同一件事：能充分利用计算的通用方法，最终碾压一切依赖人类手工知识的方法。
  • 研究者的本能，是把自己对领域的理解"教"给机器 —— 短期有效，长期却成了天花板。
  • 真正可扩展的杠杆只有两种：搜索（Search） 与 学习（Learning）。
  • 它们的共同点是：不依赖人类先验，吃得下海量算力，随计算规模持续变强。

唯二吃得下算力的武器

在可能性空间里探索

暴力或启发式地遍历海量候选：蒙特卡洛树搜索、规划、采样。算力越大，看得越深、越准。

120第六章 · 收束
01 · The Bitter Lesson

"苦涩"究竟苦在哪

  • 心理上：注入知识让我们有"成就感"和掌控感，却也亲手给系统装上了天花板。
  • 工程上：手工知识不可扩展 —— 计算一增长，它就从资产变成累赘。
  • 规律上：摩尔定律让单位算力成本持续指数下降，"算力红利"永远站在通用方法一边。
  • 结果上：坚持人类知识的路线一次次被反超，这对研究者的自尊，是名副其实的"苦涩"。

123第六章 · 收束
02 · Chat

一个 LLM 是怎么炼成的

从一堆原始文本，到一个会思考、懂配合的助手，要走三道工序。

STEP 1

预训练 Pretrain

在海量文本上做 next-token 预测，炼出"博学但口无遮拦"的基座模型。

STEP 2

对齐 Alignment

SFT 教会它听懂指令，RLHF / DPO 让它更有用、更讨喜、更安全。

STEP 3

推理增强 Reasoning

用思维链和强化学习，赋予模型"想几步再答"的深度推理能力。

下面把这三道工序逐一拆开。

124第六章 · 收束
02 · Chat

Transformer：为规模化而生的架构

核心机制

Self-Attention 自注意力

序列里每个词都能直接"看见"其他所有词，长程依赖一步到位，天然适合大规模并行计算。

关键组件

多头注意力 + 前馈网络

多头捕捉多种关系，LayerNorm 与残差连接保证深层网络可训练；GPT 系采用 Decoder-only 结构。

它把计算的并行度拉满 —— 算力砸得越多，模型长得越快。这正是苦涩教训所预言的"能吃掉海量算力的通用方法"。

—— Attention Is All You Need, 2017
125第六章 · 收束
02 · Chat

预训练：把"学习"这把武器拉满

  • Next-Token Prediction：给定上文预测下一个词 —— 无需人工标注，全网文本皆可为师。
  • Scaling Law：模型性能随 参数量 × 数据量 × 算力 呈幂律提升，可预测、可复制（Kaplan / Chinchilla）。
  • 涌现能力：规模越过临界点后，突然"解锁"上下文学习、指令跟随、初步推理等新能力。
Loss ∝ f(参数 N, 数据 D, 算力 C) 苦涩的教训在 NLP 的最新一次兑现：通用学习 + 海量计算，再次胜出
126第六章 · 收束
02 · Chat

对齐（上）：SFT，从"会续写"到"会对话"

  • 问题：基座模型只会"接着往下编"，不会问答、不懂配合，像个博学的"接话机器"。
  • 做法：用高质量的指令–回答配对数据做监督微调（Supervised Fine-Tuning）。
  • 效果：模型学会听懂指令、扮演"助手"角色，输出更贴合人类期望的格式与语气。
  • 经验：数据质量远重于数量 —— LIMA 实验证明，几千条精选数据即可显著对齐。
127第六章 · 收束
02 · Chat

对齐（下）：RLHF，关键一跃

① SFT

冷启动

先有一个会对话的初始模型。

② 奖励模型

学人类偏好

让人对多个回答排序，训练一个"打分模型"（RM）。

③ PPO 强化

向高分优化

用 RM 当奖励，强化学习打磨输出，更有用、更安全。

  • InstructGPT → ChatGPT 的引爆点，正是 RLHF。
  • DPO：跳过强化学习，直接在偏好数据上做对比优化 —— 更简单、更稳定，已成主流替代。
128第六章 · 收束
02 · Chat

推理：从 CoT 到"会思考"的模型

  • CoT 思维链：提示模型"分步推理再作答"，数学与逻辑能力大幅提升。
  • 推理模型（o1 / R1）：用可验证奖励的强化学习（RLVR），训练模型生成超长思维链，自我检验与纠错。
  • 测试时计算：让模型"想得久一点"，开辟训练之外的新 Scaling 维度。

会深度思考的 Chat，正是下一步 Agent 能够"自主行动"的智能底座。

03 · Agent

Chat 是"说"，Agent 是"做"

一个能自主感知、决策、调用工具并完成任务的系统。

Agent = LLM 大脑 + 工具 Tools + 记忆 Memory + 规划 Planning + 行动循环 语言模型从"对话框"走出来，开始操作真实世界
  • 从被动到主动：不再等你一句句问，而是自己拆解目标、逐步推进。
  • 从文本到动作：输出不再是话，而是对环境的真实操作。
131第六章 · 收束
03 · Agent

ReAct：思考与行动交织的循环

Reasoning + Acting —— 让模型"边想边做，根据反馈再调整"。

🧠

Thought

推理：我现在该做什么？

⚡

Action

行动：调用一个工具/操作

👀

Observation

观察：读取返回的结果

🔁

Loop

带着新信息回到思考

  • 把推理轨迹和外部反馈串成闭环，错误能被即时发现与修正。
  • 这是几乎所有现代 Agent 的底层工作模式。
132第六章 · 收束
03 · Agent

工具调用：给 LLM 装上"手和眼"

能接什么

五花八门的外部能力

搜索、计算器、代码执行、数据库、文件系统、浏览器、各类业务 API…… 模型负责"决定何时用、怎么用"。

怎么接

Function Calling

模型输出结构化调用请求 → 系统真实执行 → 结果回填上下文 → 模型继续推理。MCP 等协议正让工具生态标准化。

本质：LLM 负责决策与编排，确定性的活交给可靠的程序去做。

03 · Agent

规划与记忆：Agent 的"内功"

Planning · 规划

把大目标拆成小步骤

任务分解（Decomposition）、先规划再执行（Plan-and-Execute）、反思与自我批评（Reflection），避免"走一步看一步"。

Memory · 记忆

记住该记住的

短期记忆靠上下文窗口；长期记忆靠向量数据库 + RAG 检索增强，让 Agent 跨会话记住历史与领域知识。

03 · Agent

从单兵到协作：多智能体与工程化

  • 多智能体协作：不同角色分工、辩论、流水线作业，合力完成复杂任务（如"产品经理 + 工程师 + 测试"）。
  • 主流框架：LangChain / LlamaIndex 做编排，AutoGPT 开启自主探索，Claude Code / Manus / Coze 等走向产品化。
  • 工程化要点：可靠的工具封装、清晰的状态管理、可观测的执行轨迹，比"更聪明的模型"更决定成败。

Agent 把"会思考"变成"会做事" —— 这为终章埋了伏笔：当它能在环境中持续行动并从结果学习，智能就迎来了新的跃迁。

136第六章 · 收束
04 · Experience

人类数据的时代，正在触顶

  • 过去：LLM 的强大，本质是模仿人类 —— 吃下人类写下的全部文本。
  • 隐忧：高质量人类数据几乎被"榨干"，增量见顶；而模仿人类，意味着难以超越人类。
  • 拐点：Silver & Sutton 在《The Era of Experience》中断言 —— 下一个时代，数据将主要来自智能体自身的体验。

"AI 正从人类数据的时代，迈向体验的时代。"

—— David Silver & Richard Sutton, 2025
137第六章 · 收束
04 · Experience

经验学习：在环境中自主成长

  • 什么是经验：智能体与环境持续交互，自主产生的数据流 —— 行动、结果、反馈，而非人类现成语料。
  • 为什么更强：经验可以无限生成、量身定制，且能突破人类认知的边界。
  • 最好的例证：AlphaZero 不看一盘人类棋谱，纯靠自我对弈的经验，反超读尽棋谱的 AlphaGo。

这呼应了序章：少注入人类知识，多给计算与经验 —— 苦涩的教训再次应验。

138第六章 · 收束
04 · Experience

强化学习的回归：从"人夸"到"事成"

过去 · RLHF

人类反馈

奖励来自"人觉得这个回答好不好" —— 主观、昂贵、带着人类的天花板。

现在 · RLVR

结果反馈

奖励来自"答案对不对、代码跑没跑通" —— 客观、可自动验证、可无限规模化。

  • 可验证奖励（数学、代码）已引爆推理模型；下一步是把真实世界的成败变成奖励信号。

04 · Experience

通往 AGI：主线从未改变

  • 流式智能体：长期在线、持续学习、自主设定并完成跨天跨月的目标。
  • 世界模型与具身：理解并预测环境，从数字世界走向物理世界。
  • 不变的主线：通用方法 + 海量计算 + 如今的自主经验 —— 正是苦涩教训的延伸。
