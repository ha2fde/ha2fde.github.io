# 整理报销 · 操作手册

## 适用场景
用户提供一批发票/小票记录（文本或表格），要求汇总成一张报销单。

## 执行步骤
1. **收集原始记录**：确认用户提供的发票明细包含 日期 / 项目 / 金额 三要素；缺要素时先向用户追问，不要编造。
2. **运行汇总脚本**：执行 `scripts/fill.py <记录文件>`，它会按项目分类汇总金额并生成 `报销单.csv`。
3. **校验总额**：把脚本输出的总额与原始记录手工核对一遍，不一致时以原始记录为准并提示用户。
4. **交付**：向用户展示分类汇总表，并告知 `报销单.csv` 的位置。

## 注意事项
- 住宿类报销需对照公司标准（一线城市 500 元/晚），超标部分单独标注。
- 金额一律保留两位小数。
- 不要在报销单里添加原始记录中没有的条目。
