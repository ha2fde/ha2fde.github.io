3第一章 · 破冰
第 1 节 · 它们跟 ChatGPT 有啥不一样？

破误解：Agent 是"干活"，不是"回答"

💬 入门者原话："我用过 ChatGPT，这些 Agent 不就是更强的聊天机器人吗？"
直接回答：不是。ChatGPT 给你一段"回答"，Agent 替你"把活干完"——读文件、改代码、跑命令、调工具，从头做到尾。
聊天机器人（ChatGPT 类）AI Agent（Claude Code 类）
你给它一个问题一个任务
它给你一段文字回答干完的结果（文件改好了 / 命令跑完了）
动手能力没有，只能说有：读写文件、跑命令、调工具
工作方式一问一答思考→行动→看结果→再思考，循环到干完
一句话顾问实习生

4第一章 · 破冰
第 1 节 · 它们跟 ChatGPT 有啥不一样？

Agent 的三要素：有手、有脑、有循环

💬 入门者原话："那它凭什么能'干活'？"
直接回答：它比聊天机器人多了三样东西：手（工具）、脑（大模型）、循环（干一步看一步）。

一个任务："帮我把这堆文件整理好"

↓

🧠 有脑

大模型想"下一步该干嘛"

↓

✋ 有手

读写文件 / 跑命令 / 调工具

↓

🔁 有循环

看结果 → 不对就换法子 → 再干，直到干完汇报

对比一下

聊天机器人
只有脑，没有手和循环

AI Agent
脑 + 手 + 循环，三样齐全才能"干活"

5第一章 · 破冰
第 2 节 · 一个壳 + 一个大脑（全篇主线）

通用架构：所有 Agent 工具都是同一张图

💬 入门者原话："Claude Code、OpenCode、WorkBuddy……这么多工具，要一个个学吗？"
直接回答：不用。结构一模一样：一个"壳"（装在电脑上的工具）+ 一个"大脑"（大模型）。学会这张图就懂了全部。

你（说人话：我要什么）

↓

工具壳

Claude Code / OpenCode / Cline / WorkBuddy …
装在电脑上，大多是开源工具

↓

大脑（大模型）

云端 API（按量计费）或 本地模型（自己跑）

↓

壳去执行：读文件 / 写文件 / 跑命令 / 调工具

↺ 循环

壳说："我现在能做什么"
大脑回："下一步做这件事"
执行结果喂回大脑，再想下一步，直到干完为止

6第一章 · 破冰
第 2 节 · 一个壳 + 一个大脑（全篇主线）

为什么能装一堆：壳自己装，大脑另外接

💬 入门者原话："这些东西要花多少钱？"
直接回答：壳是开源工具，装多少个都行；花不花钱取决于大脑走哪条路线——接云端 API 是按量计费，装在自己电脑上只吃硬件。

🧰 壳（工具本体）

多为开源项目，直接下载安装

终端类 / 编辑器类 / 助理类 / 办公类

🧠 大脑（大模型）

路线 A：接云端 API　按量计费，各平台计价规则不同

路线 B：装在自己电脑上　离线、数据不出本机；代价是吃硬件

壳自己装、大脑另外接 —— 后面所有工具都是这个结构

7第一章 · 破冰
第 3 节 · 终端编程 Agent

在黑窗口里干活的 Agent：Claude Code / Codex / OpenCode

💬 入门者原话："程序员朋友圈里刷屏的 Claude Code 到底是个啥？"
直接回答：一类"住在终端（命令行黑窗口）里的编程 Agent"——你说要做什么，它直接改代码、跑命令、看报错、再修，循环到搞定。
工具一句话定位开源？在哪跑最擅长啥
Claude Code终端编程 Agent 的标杆，生态最成熟闭源（Anthropic）本地终端复杂编程任务，工具生态丰富
CodexOpenAI 的编程 Agent，有云端版闭源（OpenAI）本地终端 + 云端与 ChatGPT 生态联动，云端跑长任务
OpenCode开源平替，配置灵活，社区活跃开源本地终端想自由换模型、不想绑死一家的人

它怎么干活：你在终端里打字提需求，它在终端里回话 + 动手。

第 4 节 · 编辑器里的 Agent

不想碰命令行？Agent 也能住在编辑器里（Cline）

💬 入门者原话："我看到黑窗口就发怵，有不打命令的吗？"

终端形态（Claude Code 等）编辑器形态（Cline）
长什么样命令行黑窗口，打字交流VS Code 侧边栏，有按钮有界面
适合谁习惯命令行的人喜欢图形界面、想看着代码被改的人
干活方式边说边干plan 模式出方案 → 你批准 → act 模式执行
共同点都是"壳 + 大脑"，都能读写文件、跑命令

9第一章 · 破冰
第 5 节 · 大脑从哪来（云端）

云端的三种"买脑"方式：专卖店 / 超市 / 全球代购

💬 入门者原话："都说要配 API，API 到底去哪买？"
直接回答：云端大脑有三个"货架"，区别不在"国内 / 国外"四个字，而在你能买到什么模型、谁开票合规、网络稳不稳：① 厂商直供＝单点直连、最透明；② 国内云聚合＝一个 Key 买齐多家国产模型；③ 全球中转网关＝一个 Key 用上 Claude / GPT / Llama 等全球模型。

形态一 · 厂商直供（专卖店）

单点直连，一家一个 Key

  • DeepSeek / Kimi（月之暗面）
  • GLM（智谱）/ MiniMax …
  • 每家用各家的 Key
  • 最透明、最可控、可精挑模型

形态二 · 国内云聚合（超市）

一个 Key 买齐多家国产模型

  • 火山引擎方舟（字节）
  • 阿里云百炼（通义）
  • 统一接口、一个 Key 管多种
  • 合规稳、国内网络快，但仍是国产模型

形态三 · 全球中转网关（代购）

一个 Key 接全球几百个模型

  • OpenRouter 等
  • 能用上国内拿不到的 Claude/GPT/Llama
  • 统一计费、自动路由
  • 代价：走中转、延迟与合规要权衡
三家都有入门额度可以先试。记住：形态二 ≠ 形态三——前者只聚国产模型，后者才通向全球模型。

10第一章 · 破冰
第 5 节 · 大脑从哪来（云端）

三个名词：API Key、Base URL、模型名

💬 入门者原话："教程里老出现 API Key、Base URL，都是啥意思？"
直接回答：记住三句话：API Key 是付款凭证，Base URL 是接口地址，模型名是选哪个大脑。把用云端大脑想成"打电话叫外援"。

📞 Base URL

= 电话号码（打给哪家平台）

厂商的 / 云平台的 / OpenRouter 的，各不一样

🔑 API Key

= 话费账户（付款凭证）

谁拿到都能花你的钱 → 别泄露、别发群聊

🧠 模型名

= 点名要哪个大脑接电话

同一家店里也有很多模型可选

⇒ 任何 Agent 工具配置云端大脑，填的都是这三样。看到教程先找这三个词，找到就看得懂。

第 6 节 · 自己搭大脑：本地运行大模型（重点）

把大脑装在自己电脑上：为什么有人要这么干

💬 入门者原话："模型还能装在我自己电脑上？图什么？"
直接回答：本地跑模型 = 把大脑下载到自己电脑上运行——免费、离线、数据不出本机；代价是吃硬件，能力一般弱于云端旗舰。
本地跑的好处要付的代价
隐私：数据不出本机要硬件：内存 / 显存决定能跑多大的模型
免费：没有按量计费，随便用能力一般弱于云端旗舰模型
离线：断网也能用模型文件占硬盘（几个 GB 起）
完全可控：想换就换、想删就删第一次要下载模型，要等

12第一章 · 破冰
第 6 节 · 自己搭大脑：本地运行大模型（重点）

配置对号入座 + 在哪下、怎么装

💬 入门者原话："我这台电脑跑得动吗？要去哪下模型？"
直接回答：只看一个数——显存（Mac 是统一内存），它决定你能跑多大的模型。8GB 跑得动 8B，24GB 跑得动 32B，70B 要 Mac 128GB；纯 CPU 只适合尝鲜。
① 配置对号入座（按显存 / 内存）
你的硬件跑得动什么（括号是下载后的实际体积）
8–12GB 显存qwen3:8b（5.2GB）——日常问答、简单代码
16GB 显存qwen3:14b（9.3GB）——明显更聪明，够当主力
24GB（3090/4090）
32GB（5090）		qwen3:32b（20GB）或 qwen3-coder:30b（19GB）——写代码流畅
Mac 统一内存64GB 跑 27B~32B 舒服；128GB 才够 llama3.3:70b（43GB）
8GB 内存纯 CPU（不推荐）只能 1B~4B，很慢，尝鲜可以，别当主力

上面的体积都是"量化版"（Q4）的——牺牲一点精度换体积大幅缩小，本地跑基本都用它。另外还要给上下文留 2~3GB 余量。

② 下载渠道与安装方式
渠道一句话怎么装
Ollama ★新手推荐ollama run 模型名 自动下载运行Win/Mac 装安装包，Linux 一条命令
LM Studio图形化界面，点鼠标选模型官网下载安装包
ModelScope 魔搭国内仓库，下载快网页下载配合工具用

通用原则：Windows/Mac 下载安装包，Linux 用命令装；以各官网为准。

第 7 节 · 一个壳，多个大脑

换模型两条路：改环境变量 vs 路由工具

💬 入门者原话："我装好了一个工具，但不想用它默认的模型，能换吗？"
直接回答：能，而且这是常态。简单的直接改环境变量；想随时切换多家，用路由工具 CC Switch。

路线 A · 改环境变量（直连）

例：Claude Code 设两个变量即指向别家

ANTHROPIC_BASE_URL = 新大脑地址
ANTHROPIC_AUTH_TOKEN = 新 Key

适合：只换一家、换完不常动

路线 B · CC Switch 本地路由

有的工具"语言不通"——如 Codex 原生只认 Responses 协议，需要一个"翻译"。

CC Switch 在本机做协议翻译，并在多个供应商之间一键切换。

适合：手里有好几个 Key，想随时换着用

四类免费资源，拼出完整 0 成本方案

🧰 免费的壳（开源随便装）

  • OpenCode：终端编程 Agent

  • Ollama 自跑：一次下载永久免费

"每天早上 8 点提醒我喝水，并给我一句今日天气提示。"

最小权限 ｜ 看清再批准 ｜ 设上限+备份不开"全自动放行"，重要目录别给写权限；它要跑命令前会给你看——看不懂就问"这条命令干什么"；云端设消费上限，改文件前先备份一份
