3第一章 · 破冰
第 1 节 · 它们跟 ChatGPT 有啥不一样？

破误解：Agent 是"干活"，不是"回答"

💬 入门者原话："我用过 ChatGPT，这些 Agent 不就是更强的聊天机器人吗？"
直接回答：不是。ChatGPT 给你一段"回答"，Agent 替你"把活干完"——读文件、改代码、跑命令、调工具，从头做到尾。
聊天机器人（ChatGPT 类）AI Agent（Claude Code 类）
你给它一个问题一个任务
它给你一段文字回答干完的结果（文件改好了 / 命令跑完了）
🧠 脑都有，而且常常是同一批大模型——差别不在这儿
✋ 手没有，只能说有：读写文件、跑命令、调工具
🔁 循环没有，一问一答就结束思考→行动→看结果→再思考，循环到干完
一句话顾问实习生

三个字记住：脑（大模型，负责想）、手（工具，负责动）、循环（干一步看一步，直到干完）。聊天机器人只有脑，三样齐全才叫 Agent。

03 / 28
4第一章 · 破冰
第 2 节 · 一个壳 + 一个大脑（全篇主线）

通用架构：所有 Agent 工具都是同一张图

💬 入门者原话："Claude Code、OpenCode、WorkBuddy……这么多工具，要一个个学吗？"
直接回答：不用。结构一模一样：一个"壳"（装在电脑上的工具）+ 一个"大脑"（大模型）。学会这张图就懂了全部。

你（说人话：我要什么）

↓

工具壳

Claude Code / OpenCode / Cline / WorkBuddy …
装在电脑上，大多是开源工具

↓

大脑（大模型）

云端 API（按量计费）或 本地模型（自己跑）

↓

壳去执行：读文件 / 写文件 / 跑命令 / 调工具

↺ 循环

壳说："我现在能做什么"
大脑回："下一步做这件事"
执行结果喂回大脑，再想下一步，直到干完为止

对照上一页：壳＝手＋循环，大脑＝脑。所以壳可以随便换，大脑也可以随便接。

5第一章 · 破冰
第 2 节 · 一个壳 + 一个大脑（全篇主线）

钱花在哪：壳基本不要钱，大脑有四条路线

💬 入门者原话："这些东西要花多少钱？"
直接回答：壳几乎不花钱——多是开源项目，装多少个都行。钱全花在大脑上，而大脑有四条路线，从 0 元起步。
大脑走哪条路怎么收钱大概量级适合谁
免费额度　先走这条注册赠送、平台常年的免费档0 元，但有速率和用量上限所有新手，先把第一件小活跑通
云端 API 按量计费按处理的字数扣钱，用多少扣多少轻度问答一个月几块到几十块；天天用它写代码可能上百要最强的大脑，又不想买硬件
包月订阅固定月费，额度内随便用各家常见档位每月几十到几百元每天重度使用、怕账单忽高忽低
装在自己电脑上不按次收费，只吃硬件和电用起来 0 元；代价是一次性买设备（第 6 节细讲）隐私优先、要离线、用量特别大
壳自己装、大脑另外接 —— 后面所有工具都是这个结构；换大脑只是改一行配置，不用换工具

价格各家不同且经常调整，上面只给量级，具体以官方页面为准。新手路径：先用免费额度跑通 → 不够用再按量或包月 → 隐私和用量上来了再上本地。

6第一章 · 破冰
第 3 节 · 终端编程 Agent

在黑窗口里干活的 Agent：Claude Code / Codex / OpenCode

💬 入门者原话："程序员朋友圈里刷屏的 Claude Code 到底是个啥？"
直接回答：一类"住在终端（命令行黑窗口）里的编程 Agent"——你说要做什么，它直接改代码、跑命令、看报错、再修，循环到搞定。
工具一句话定位开源？在哪跑最擅长啥
Claude Code终端编程 Agent 的标杆，生态最成熟闭源（Anthropic）本地终端复杂编程任务，工具生态丰富
CodexOpenAI 的编程 Agent，有云端版闭源（OpenAI）本地终端 + 云端与 ChatGPT 生态联动，云端跑长任务
OpenCode开源平替，配置灵活，社区活跃开源本地终端想自由换模型、不想绑死一家的人

它怎么干活：你在终端里打字提需求，它在终端里回话 + 动手。

7第一章 · 破冰
第 4 节 · 编辑器里的 Agent

不想碰命令行？Agent 也能住在编辑器里（Cline）

💬 入门者原话："我看到黑窗口就发怵，有不打命令的吗？"
直接回答：有。Cline 是 VS Code 编辑器里的插件，点鼠标就能用——它先列计划（plan），你点头它才动手（act）。
终端形态（Claude Code 等）编辑器形态（Cline）
长什么样命令行黑窗口，打字交流VS Code 侧边栏，有按钮有界面
适合谁习惯命令行的人喜欢图形界面、想看着代码被改的人
干活方式边说边干plan 模式出方案 → 你批准 → act 模式执行
共同点都是"壳 + 大脑"，都能读写文件、跑命令

8第一章 · 破冰
第 5 节 · 大脑从哪来（云端）

云端的三种"买脑"方式：专卖店 / 超市 / 全球代购

💬 入门者原话："都说要配 API，API 到底去哪买？"
直接回答：云端大脑有三个"货架"，区别不在"国内 / 国外"四个字，而在你能买到什么模型、谁开票合规、网络稳不稳：① 厂商直供＝单点直连、最透明；② 国内云聚合＝一个 Key 买齐多家国产模型；③ 全球中转网关＝一个 Key 用上 Claude / GPT / Llama 等全球模型。

形态一 · 厂商直供（专卖店）

单点直连，一家一个 Key

  • DeepSeek / Kimi（月之暗面）
  • GLM（智谱）/ MiniMax …
  • 每家用各家的 Key
  • 最透明、最可控、可精挑模型

形态二 · 国内云聚合（超市）

一个 Key 买齐多家国产模型

  • 火山引擎方舟（字节）
  • 阿里云百炼（通义）
  • 统一接口、一个 Key 管多种
  • 合规稳、国内网络快，但仍是国产模型

形态三 · 全球中转网关（代购）

一个 Key 接全球几百个模型

  • OpenRouter 等
  • 能用上国内拿不到的 Claude/GPT/Llama
  • 统一计费、自动路由
  • 代价：走中转、延迟与合规要权衡
三家都有入门额度可以先试。记住：形态二 ≠ 形态三——前者只聚国产模型，后者才通向全球模型。

9第一章 · 破冰
第 5 节 · 大脑从哪来（云端）

三个名词：API Key、Base URL、模型名

💬 入门者原话："教程里老出现 API Key、Base URL，都是啥意思？"
直接回答：记住三句话：API Key 是付款凭证，Base URL 是接口地址，模型名是选哪个大脑。把用云端大脑想成"打电话叫外援"。

📞 Base URL

= 电话号码（打给哪家平台）

厂商的 / 云平台的 / OpenRouter 的，各不一样

🔑 API Key

= 话费账户（付款凭证）

谁拿到都能花你的钱 → 别泄露、别发群聊

🧠 模型名

= 点名要哪个大脑接电话

同一家店里也有很多模型可选

⇒ 任何 Agent 工具配置云端大脑，填的都是这三样。看到教程先找这三个词，找到就看得懂。

10第一章 · 破冰
第 6 节 · 自己搭大脑：本地运行大模型（重点）

把大脑装在自己电脑上：为什么有人要这么干

💬 入门者原话："模型还能装在我自己电脑上？图什么？"
直接回答：本地跑模型 = 把大脑下载到自己电脑上运行——免费、离线、数据不出本机；代价是吃硬件，能力一般弱于云端旗舰。
本地跑的好处要付的代价
隐私：数据不出本机要硬件：内存 / 显存决定能跑多大的模型
免费：没有按量计费，随便用能力一般弱于云端旗舰模型
离线：断网也能用模型文件占硬盘（几个 GB 起）
代价里说的"吃硬件"，就是这三个数
这个数是什么决定什么
多少 B参数量。B = billion，8B 就是 80 亿个"旋钮"，越多越聪明也越占地方模型的聪明程度，以及体积多大
显存 / 内存模型跑起来时住的地方。Mac 的"统一内存"是 CPU/GPU 共用，买多大就有多大显存，但系统自己要吃掉几 GB能不能跑——必须整个装进去，装不下就报错或慢十倍
带宽每秒能从内存搬多少 GB。模型每吐一个字都要把参数完整读一遍（MoE 只读被叫醒的那部分），所以带宽就是速度本身跑得多快——10 字/秒勉强跟得上阅读，20 以上才舒服

配置对号入座 + 在哪下、怎么装

直接回答：看两个数：容量决定能不能跑，带宽决定跑得快不快。下面按容量分档；同一档里型号越新、带宽越高，速度也越快。

12第一章 · 破冰
第 6 节 · 自己搭大脑：本地运行大模型（重点）

个人可选模型清单 + 本地大脑接进壳里

💬 入门者原话："模型名字一大堆，我下哪个？本地大脑能给那些 Agent 工具用吗？"
直接回答：中文和写代码都先选通义千问（Qwen3.5/3.6），机器特别小或想要多语言再看 Gemma 4。本地模型能直接当壳的大脑，完全离线。
模型出身一句话本地能下到的规模
Qwen3.5 ★阿里中文最强之一，尺寸最全且都带看图，手机到工作站都覆盖0.8B / 2B / 4B / 9B / 27B / 35B / 122B
Qwen3.6 ★阿里3.5 的升级版，主攻写代码和跑 Agent27B（稠密）/ 35B（MoE）
Gemma 4谷歌Ollama 上下载量第一，多语言，E 系列小到能上手机E2B / E4B / 12B / 26B / 31B
DeepSeek-R1 蒸馏版DeepSeek推理强；但已是 2025 年的模型，正被上面两家追上1.5B ~ 70B
Llama（了解即可）Meta曾经的开源标杆，一年多没出新的本地版本了llama3.3:70b / llama4

MoE（混合专家）：Qwen3.6 的 35B、Gemma 4 的 26B 都是这种——模型拆成很多"专家"，每次只叫醒一小撮干活，于是容量按 35B 算（得全装进显存，因为不知道下次叫谁），速度却按 3B 算，比同体积的稠密模型快好几倍。
旗舰只有云端：新闻里的 GLM-5.2（744B）、Kimi K3（2.8 万亿）、DeepSeek V4 Pro（1.6 万亿），在 Ollama 上都只挂着 cloud 标签，压根没有本地权重可下——不是你机器不行，是它们本来就不给你在本机跑。

换模型两条路：改环境变量 vs 路由工具

💬 入门者原话："我装好了一个工具，但不想用它默认的模型，能换吗？"
直接回答：能，而且这是常态。简单的直接改环境变量；想随时切换多家，用路由工具 CC Switch。

路线 A · 改环境变量（直连）

例：Claude Code 设两个变量即指向别家

ANTHROPIC_BASE_URL = 新大脑地址
ANTHROPIC_AUTH_TOKEN = 新 Key

适合：只换一家、换完不常动

路线 B · CC Switch 本地路由

有的工具"语言不通"——如 Codex 原生只认 Responses 协议，需要一个"翻译"。

CC Switch 在本机做协议翻译，并在多个供应商之间一键切换。

适合：手里有好几个 Key，想随时换着用

第 11 节 · 0 成本上手：免费资源地图

四类免费资源，拼出完整 0 成本方案

💬 入门者原话："说了一堆免费，到底哪些真免费？"
直接回答：四类拼起来就是完整 0 成本方案：免费的壳 + 免费的云端大脑 + 本地自跑 + 办公试用。

🧰 免费的壳（开源随便装）

  • OpenCode：终端编程 Agent
  • Cline：VS Code 插件
  • Hermes / OpenClaw：私人助理
  • CC Switch：换大脑面板

☁️ 免费的云端大脑

  • 厂商 / 云平台：注册赠送、新客福利
  • OpenRouter：常年有免费模型
  • 赠送额度会变化，以官方为准

💻 免费的本地大脑

  • Ollama 自跑：一次下载永久免费
  • 离线可用、数据不出本机
  • Qwen3.5 / Gemma 4 / DeepSeek 蒸馏版全免费

🏢 办公 Agent 试用

  • WorkBuddy：公测期有赠送
  • 千问办公：公测中，注册送积分
  • 其余各家也多有大促 / 试用，以官方为准

用免费资源留三个心眼：赠送额度用完会停或转付费，留意用量提醒；注册时看清有没有勾自动续费，能不绑卡就不绑；免费层的模型不是最强那档，尝鲜够用，重活再考虑付费或本地大模型。

编程类 · OpenCode / Claude Code / Cline

"在当前文件夹写一个 Python 脚本：统计这个文件夹里每种后缀名的文件各有多少个，结果存成 report.txt。"

"帮我把这段会议纪要整理成三条待办，每条一行，标出负责人和截止时间：（贴一段你的纪要）"

助理类 · OpenClaw / Hermes

"每天早上 8 点提醒我喝水，并给我一句今日天气提示。"

底线具体做法
最小权限 ｜ 看清再批准 ｜ 设上限+备份不开"全自动放行"，重要目录别给写权限；它要跑命令前会给你看——看不懂就问"这条命令干什么"；云端设消费上限，改文件前先备份一份
