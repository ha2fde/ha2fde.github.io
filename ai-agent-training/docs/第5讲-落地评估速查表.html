2 · 三句自评评完级，回答这三句

① 当前组织在哪一级？按最弱支柱定级（木桶效应）；可按部门分别评，成熟度不同是常态。
② 下一级差距是什么？对照七支柱简表，逐支柱找出当前级与下一级之间的具体缺口。
③ 首要投资是什么？未来 6~12 个月优先补最弱支柱，而不是继续加强最强支柱。

3 · 四层协议图（文字版）各协议一句话定位

┌────────────────────────────────────────────┐ │ 互连层 A2A Agent 够 Agent：互相发现、通信、协作 │ ├────────────────────────────────────────────┤ │ 流程层 Agent Skills 封装"怎么干"：步骤+提示词+脚本 │ ├────────────────────────────────────────────┤ │ 工具层 MCP Agent 够工具：统一接入，"工具的 USB"│ ├────────────────────────────────────────────┤ │ 模型层 Function Calling 各家 API 原生调工具机制 │ └────────────────────────────────────────────┘
协议一句话定位
Function Calling / Tool Use各家模型 API 原生的"模型请求调工具"机制
MCPAgent 与工具 / 数据源的统一接入协议；Anthropic 提出并开源，主要厂商跟进，已进入标准化托管
Agent Skills把"怎么完成一类任务"打包成可复用技能包，与 MCP 互补
A2AAgent 之间互相发现、通信、协作；Google 提出，已进入标准托管流程
其他OpenAPI＝传统 API 描述老路子；AGNTCY＝Cisco 主导的互操作协议，与 A2A 并存；OAuth＝Agent 代表用户访问资源的授权依据

注：各协议归属、版本与标准化进展变化快，一律以官方 / 标准组织最新公告为准。

4 · 六大能力支柱：一句话 + 落地第一步

支柱一句话落地第一步
记忆短期靠上下文，长期靠外部存储 + 检索列出"值得记住的内容清单"并选定存储
安全防注入、防越权、防泄露给高危工具加"执行前确认"
治理可审计、可审批、可算账打开全量调用留痕（审计日志）
观测每一步调用都可追踪接入 trace，记录工具输入输出
评测没有评测就谈不上上线攒 20~50 个真实任务评测集
人机协同关键闸口留给人定义"必须人工确认"的操作清单
主线一句话：Agent 不能只会"干活"，还得——记得住 · 守得住 · 管得了 · 看得见 · 连得上 · 落得地
核心循环让它会干活，支柱让它可信，协议让它可连，成熟度模型让它可落地
