① 单文件书（HTML）

推荐从这里开始。 七讲整合进一个 HTML 文件 book.html（约 0.49 MB，离线可读），像一本书一样：封面 → 目录（章节 + 嵌套小节）→ 7 章扉页 → 149 内容页连续排版 → 附录（17 个配套脚本内联代码 + 语法高亮）。

  • 左侧书本章节树导航（滚动自动高亮当前章）；Ctrl+F 全书搜索；← → 逐页、Home/End 跳首尾、P 打印；顶部汉堡菜单。
  • 点目录 / 附录里的脚本条目即可展开代码，不用再跳出去找文件。
  • 双击 book.html 即可打开（file:// 正常）；P 或 Ctrl+P 一键导出 16:9 PDF（见下方「PDF 导出」）。

⑥ 构建与导出脚本（Python）

仓库根附三个脚本，便于自行重新生成：

  • build_book.py — 从 slides/ 七讲抽样/正文，作用域隔离（.ch1….ch7），内联 17 个脚本并做 Python 语法高亮，组装成单文件 book.html。
  • export_pdf.py — Headless Chrome 把各讲 HTML 打印为 16:9 PDF。
  • pdf_to_pptx.py — PyMuPDF + python-pptx，把 PDF 封装为整页高清 PPTX（自带页数 / MediaBox 一致性校验）。

依赖：pymupdf + python-pptx + 本地 Chrome（Headless）。
