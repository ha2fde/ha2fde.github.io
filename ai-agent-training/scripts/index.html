配套脚本索引

第 2 / 3 / 4 讲的可运行演示，共 17 个脚本 + 1 个 Skill 示例。全部为教学用途的最小实现，纯 CPU 可跑。

环境准备（一次装好）

pip install torch transformers sentence-transformers mcp fastapi uvicorn requests openai langgraph langchain-openai

Python 3.12+。模型首次运行自动下载（Qwen2.5-0.5B 约 1.5GB，BGE 向量模型约 100MB）；国内网络可取消脚本顶部 HF_ENDPOINT = "https://hf-mirror.com" 一行的注释。第 4 讲脚本需在顶部 CONFIG 区填 BASE_URL / API_KEY / MODEL（兼容任何 Chat Completions 接口，云端或本地均可）。

第 2 讲 · 从计算机到 GPT（3 个）

目录：scripts/lecture2/ ｜ 演示"机器如何一步步学会语言"的三个最小实验

脚本对应内容演示什么运行
embedding_demo.pyembedding：词义 = 向量统计每个词"身边常出现哪些词"（共现向量）：上下文相似的词，向量自动相似——不用人教python embedding_demo.py
ngram_demo.py从 n-gram 起步统计"前 N-1 个字之后最常接哪个字"，生成时不断查表——得到"模仿腔"文本，看清 n-gram 的天花板python ngram_demo.py
tiny_lm_train_demo.py神经网络学规律字 → embedding → 加权变换 → 预测下一个字；错了算 loss、调权重，重复几千次——亲手训一个微型 LMpython tiny_lm_train_demo.py
