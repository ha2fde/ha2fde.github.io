梳理 LLM 进化链上的 9 个关键节点：GPT-1 → GPT-2 → GPT-3 → CoT → InstructGPT → ReAct → ChatGPT → Toolformer → Agent 框架。四 条并行线索贯穿全文：规模缩放、思维推理、人类对齐、工具使用。系列入口。

Transformer：Attention Is All You Need——整个 LLM 时代的基石
2026-07-27 · 约 20 分钟
2017 · 提出 Encoder-Decoder 架构 + 多头注意力 + 位置编码，完全取代 RNN/CNN。可并行训练的特性让大模型扩展成为可能。BERT、GPT、T5——所有后续模型都建立在此基础上。

LLM 进化史
GPT-1：生成式预训练如何统一 NLP 框架
2026-07-27 · 约 15 分钟
2018 · 1.17 亿参数。证明了「预测下一个词」学到的知识比监督学习更好。两阶段框架（预训练+微调）定义了此后所有 LLM 的基本范式。12/12 NLP 任务超越 SOTA。

LLM 进化史
GPT-2：更大即更好的先声——零样本能力从何而来
2026-07-27 · 约 15 分钟
2019 · 15 亿参数。模型大了不用微调也能做任务。发现零样本迁移能力——翻译、问答、摘要皆可。分阶段发布引发 AI 伦理讨论。
④
LLM 进化史
GPT-3：1750 亿参数与「举一反三」的能力从何而来
2026-07-27 · 约 20 分钟
2020 · 1750 亿参数。上下文学习（In-Context Learning）出现，仅凭几个示例无需微调即可完成广泛任务。Scaling Laws 的终极验证，引爆大模型时代。
⑤
LLM 进化史
Chain-of-Thought：让大模型学会「先想再答」
2026-07-27 · 约 15 分钟
2022.01 · 让模型在给出答案前先写推理过程。GSM8K 上从 18% 跃升至 58%。LLM 推理从「直接出答案」变为「白盒推理」，为 Agent 奠定基础。
⑥
LLM 进化史
InstructGPT：RLHF 如何让语言模型学会听人话
2026-07-27 · 约 18 分钟
2022.03 · 用人类反馈微调 GPT-3，13 亿参数模型在指令遵循上超越 1750 亿原始模型。RLHF 三阶段流程：SFT → 奖励模型 → PPO。ChatGPT 的技术基石。
⑦
LLM 进化史
ReAct：LLM Agent 的思考—行动循环
2026-07-27 · 约 15 分钟
2022.10 · 让模型在 Thought ↔ Action ↔ Observation 之间交替。首个 LLM Agent 雏形。今天 Claude Code、Deep Research、AutoGPT 等所有 Agent 的架构原型。

2026-07-27 · 约 12 分钟
